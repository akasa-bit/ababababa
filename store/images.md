# Steam の画像の案

調べた日: 2026-10-20。大きさと決まりは Steamworks の公式の文書で確かめた (出典は各行)。決まりは変わるので、作る前にもう一度見る。

## 1. 要る画像と大きさ

| 画像 | 大きさ [px] | 要る? | 何に使う | 案 |
|---|---|---|---|---|
| ヘッダーカプセル | 920×430 | 要る | ストアのページの上・検索の一覧 | 3 次元の星図を斜めから (国境の色と光の点の航路) + 題字 |
| 小カプセル | 462×174 | 要る | 一覧・ウィッシュリスト (120×45・184×69 は自動で作られる) | 題字だけでほぼ埋める (小さくても読めるように)。背景は天の川を暗く |

### カプセルの決まり (https://partner.steamgames.com/doc/store/assets/rules)

- 入れてよいのは、絵・ゲームの名前・公式の副題だけ。
- 入れてはいけないもの: レビューの点や引用、賞、「セール中」などの割引の文、「ウィッシュリストに入れて」などの呼びかけ、ほかの製品の宣伝、そのほかの文字。
- どのカプセルにも読めるゲームの名前が要る。中身は PG-13 まで。
- 背景の天体写真を使うときは出典を守る (`store/page-ja.md` の 6)。NASA・ESA のロゴは使わない。

## 2. スクリーンショットの案

- 公式の決まり: 1920×1080 以上・16:9・5 枚以上。ゲームの画面だけ (想像図・宣伝の文字・賞は入れない)。**4 枚以上を「全年齢」にする** (血・暴力・性的な表現なし)。このゲームは文字と図だけなので、どれも全年齢にできる。
- 配色はスキン 6 (いまの唯一の配色)。
- **撮る大きさ** (QD-18 で案 1 に決まった): CSS で **1280×720 を 1.5 倍** で撮って、そのまま 1920×1080 にする。横幅は Xiaomi Pad 8 Pro の横の画面 (CSS で 1280×780) と同じなので、画面の並びは同じになる。

| # | 場面 | 見せたいこと (柱) | 撮り方 |
|---|---|---|---|
| 1 | 3 次元の星図を斜めから。いくつもの国の国境の色、航路、交戦中の印 | 実在の星の 3 次元の銀河 | 星間マップで「回す」をオンにし、R で傾けて Z で回す。右の欄は閉じる |
| 2 | 統治体制を選ぶ所と、独立の起きやすさの見通し | 柱 A: 遅れて届く統治 | 遠い家臣の星系の詳細欄の「統治」を開く |
| 3 | 「決めること」が知らせの帯に届いた所 (何年前の知らせかが見える) | 柱 A: 光の遅れ | 遠い星系の要求が届いたところで止める (回 SO3 から、遊んだセーブ `decision` で) |
| 4 | 交易路の網と、荷を運ぶ船 | 柱 B: 光と物質の経済 | 交易路をいくつも結んだあとの星間マップ。帝国 → 交易路タブも候補 |
| 5 | 独立や戦争の原因の内訳 | 柱 C: 理由の分かる歴史 | 政治タブの原因と見通し |
| 6 | 講和会議で条件を選ぶ所 | 柱 C | 戦勝点で勝っている講和 (回 SO3 から、遊んだセーブ `conference` で。条件は「おまかせ」の順に選んだ所で止め、送らない) |
| 7 | 星系マップ (天体と背景の天体写真) | 実在の星系 | 固有名のある星系を開く (いまの銀河の 73 系の中から選ぶ) |

**撮るためのセーブと撮る台本** (回 SO1・B-079): `desktop/shots/shoot.mjs`。何もせずに早送りすると地球の国は 1 星系のままで見せたい場面にならないので、台本がセーブを作る。

```sh
node tools/build.mjs
node desktop/shots/shoot.mjs                      # 遊んでセーブを作り、スクリーンショット 7 枚とカプセルの案 8 枚を desktop/shots/out/ に書く
node desktop/shots/shoot.mjs --save <セーブ.json>  # 作らずに、手で遊んだセーブ (ホーム画面の「ファイルに書き出し」) を読んで撮る
```

- **セーブ (回 SO3 から)**: 銀河の番号 20261020・6 か国で始め、観戦で 80 年 (2380 年まで) 進めたあと、**人の操作 (画面の指令と同じ `issue`) で遊んで**作る (`desktop/shots/play.mjs`)。観戦のまま進めるだけでは、地球の国が勝つ講和会議が起きない (観戦の AI は守り寄りで、60 個の銀河を 200 年回しても 0 回だった)。遊び方は台本に決めてある:
  1. 遠い星系 (光の遅れ 10 年以上) から「決めること」が届いたら、いちばん安い選択肢で返事を送る
  2. 首都で戦艦を毎年 2 隻ずつ造り、50 隻 (か相手の 3 倍) になったら、艦隊の少ない一番近い国に宣戦し、相手の首都でない一番近い星系に集める。戦争のあいだも造り続け、8 年ごとに前線へ集める (前線が落ちたと届いたら、次の星系へ。首都は最後)
  3. 地球に届いている戦勝点が 20 以上になったら、6 年ごとに講和を申し入れる (相手の首都に届いて、相手が応じたら講和会議)
  4. 講和会議の知らせが地球に届いたら止める
- 2026-10-23 の main での筋: 2404 年にギコン共和国に宣戦 → 2457 年の申し入れが 34 光年先のリオルタンエに 2492 年に届いて講和会議 → 講和を知らないギコン共和国の艦隊が 2496 年にトゥタンアを攻める (地球に届くのは 2517 年) → 講和会議の知らせが地球に届くのは 2527 年 (持ち点 54)。
- 書くセーブ (`desktop/shots/out/save-<銀河>-<名前>.json`。各 3 MB 前後): `decision` (決めることが届いた所。場面 3)・`reply` (返事を送った直後)・`offer` (講和会議になった申し入れを送った直後。予告編の光の球)・`front` (講和のあとの艦隊戦の知らせが届く 3 年前。予告編)・`conference` (講和会議の知らせが届いた所。場面 6 とほかの場面・カプセル)。筋の年と場所は `play-<銀河>.json`。ゲームの式と乱数だけで進むので、同じ版のゲームなら何度作っても同じ (`tools/tests/headless.js`)。ゲームが変わると筋も変わるので、リポジトリには入れず、撮るたびに作る (`.gitignore` 済み)。
- 場面 3・6 は、`--save` で読んだセーブに「決めること」や講和会議がなければ、前の撮り方 (地図の左上の知らせ・帝国 → 軍事) になる。
- 撮る画面に「遊び方の記録」の同意の欄が出ないよう、ページを開く前に「記録しない」にしておく (記録もしない)。
- 台本は、ゲームのページの関数 (`loadSave`・`issue`・`app.setView`・`galaxyView`・`openTreaty`) を呼ぶだけで、ゲームの中身は変えない。

## 3. トレーラー (回 SO3・B-080。`desktop/trailer/trailer.mjs`)

```sh
node tools/build.mjs
node desktop/trailer/trailer.mjs                              # 遊んでセーブを作り、desktop/trailer/out/trailer-<銀河>.mp4 を書く (15 分ほど)
node desktop/trailer/trailer.mjs --saves desktop/shots/out    # shoot.mjs が作ったセーブを使い、遊び直さない
```

43 秒。上の 2 の遊んだ筋 (セーブ `offer`・`front`・`conference`) を、場面ごとにゲームを 1 コマずつ進めて撮る。

| # | 秒 | 場面 | 字幕 |
|---|---|---|---|
| 1 | 9 | **光の球**: 講和の申し入れの指令が、地球から 34 光年先の相手の首都へ光の速さで広がる (「届くまで あと n 年」) | 命令は、光の速さでしか届かない。/ 2457年、地球はギコン共和国に講和を申し入れた。34 光年先の リオルタンエ に届くのは 2491年 |
| 2 | 9 | **講和のあとも戦う艦隊**: 前線のトゥタンアに寄せ、講和のあとに起きた艦隊戦の知らせが地球に届く | 講和は 2492年に、もう結ばれていた。/ 2496年、講和を知らない艦隊が トゥタンア を攻めた。地球がその戦いを知ったのは 2517年 |
| 3 | 8 | **35 年遅れで届く講和会議**: 知らせが届き、条件を押した順に選んでいく (送らない) | 2527年、講和会議の知らせが地球に届いた。35 年遅れで、ギコン共和国から何を取るかを選ぶ |
| 4 | 12 | **答え合わせ** (B-054): 2400〜2500 年の、地球が見ていた歴史と本当の歴史を早回し (トゥタンアの艦隊戦は「まだ届いていない」) | 時代の終わりに、答え合わせ。 |
| 5 | 5 | 題字 | NoLongerUbiquitous / 命令は、光の速さでしか届かない。 |

- 大きさと形式: CSS 1280×720 を 1.5 倍 (= 1920×1080。スクリーンショットと同じ)・30 コマ/秒・H.264 (High・yuv420p・12 Mbps を目安に。止まった画面が多いので、2026-10-23 の 43 秒では平均 6.5 Mbps・35 MB)・音は AAC の無音 (48 kHz)。上の 1 の Steam の決まり (1920×1080 まで・16:9・30 か 60 コマ・5000 kbps 以上・H.264 + AAC) に合う。
- 字幕は日本語だけ (いまはゲームが日本語だけ)。書体はゲームの本文と同じ Zen Old Mincho、題字は見出しと同じ Special Elite。字幕と暗転はページの上に重ねるだけで、ゲームの画面は変えない。字幕の年と名前は遊んだ筋から入れるので、ゲームが変わって筋が変わっても字幕は合う。
- **音楽はまだない** (音の素材は「あとで」。QD-53・QD-54)。音が入ったら ffmpeg の無音の所を差し替える。
- 前の案にあった「植民地が離れていく」「64 年/秒の早送りで国境が塗り変わる」は入れていない (B-080 の筋: 光の球 → 届く → 講和のあとも戦う艦隊 → 答え合わせ を優先し、43 秒に収めた)。
- 答え合わせの早回しは、ゲームでは実時間 (9 秒) で動くが、撮るのは 1 コマ 0.7 秒ほどかかるので、台本が 1 コマずつ同じ動き (年の針・灯る行) を付ける。
- 書き出した mp4 はリポジトリに入れない (`desktop/trailer/out/` は `.gitignore` 済み)。Steamworks に上げるのは、アカウントができてから (B-081)。

## 5. カプセルの案 (回 SO1。`desktop/shots/shoot.mjs` が作る)

撮るためのセーブを読み、星図だけを残して (右の欄・ボタン・知らせを消す)、入植した星系の塊に寄せて斜めから見下ろし、ゲームの名前を載せる。

| カプセル | 大きさ | 置き方 |
|---|---|---|
| ヘッダー | 920×430 | 名前を上寄りの真ん中、星図の塊を下に |
| 小 | 462×174 | 名前でほぼ埋める。星図は消して、天の川を暗く (小さくても読めるように) |
| メイン | 1232×706 | 名前を左下、塊を右上に |
| 縦長 | 748×896 | 名前を 2 行 (NoLonger / Ubiquitous) で上に、塊を下に |
| ライブラリのカプセル | 600×900 | 縦長と同じ |
| ライブラリのヒーロー | 3840×1240 | 文字なし。塊を真ん中 (大事な所は真ん中の 860×380 に入る) |
| ライブラリのロゴ | 1280×360 (透過 PNG) | 名前だけ |
| ページの背景 | 1438×810 | 天の川だけを暗く |

- **カプセルの決まりを守るため、星図の上の文字 (星の名前・光年・「攻囲 72%」など) は描かない** (ページの中で文字を描く関数を止める。ゲームは変えない)。載る文字はゲームの名前だけ。副題は、英語の副題が決まってから (QD-14)。
- 名前の書体は、ゲームの見出しと同じ Special Elite (Apache License 2.0。商用で使える。Google Fonts と、包装で同梱したもの)。古い報告書風の掠れ (`#worn`) もゲームと同じ。
- 天の川の背景は NASA/Goddard の SVS と Gaia (ESA/Gaia/DPAC) の画像 (`README.md` の「画像の出典」)。ストアの画像に使うときも出典を守り、ロゴは使わない (上の 1)。
- これは案。国境の色の塊が星図の真ん中にあるので、どの銀河・何年のセーブで撮るかで絵が変わる。気に入った場面のセーブ (`--save`) で撮り直せる。
