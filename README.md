### 遊びかた

- **人口・産業**: 入植地の人口を「方針」で農業・鉱業・工業に振り分ける。施設(農場・鉱山・工場・居住区・造船所)をクレジットと金属で拡張できる
- **資源**: 食料・水・金属・燃料・希少元素・工業品。天体ごとに埋蔵量が違う。食料や水が足りないと人口が減る
- **経済**: 税収・交易・余剰資源の売却でクレジットを稼ぎ、入植船や施設、軍艦に使う
- **採掘基地**: 入植していない天体にも無人の採掘基地を置ける (同じ星系に入植地が必要)。ガス惑星からは水と燃料、岩石の天体からは金属と希少元素
- **自動開発**: 星系ごとにオンにすると、生産が需要に届かない資源を選んで惑星上の施設 (農場・鉱山・工場) や採掘基地を自動で建て、過密になれば居住区も拡張する
- **自動防衛配備**: オンにすると、各入植星系の駐留艦を海賊の最大戦力まで自動で増やす。余っている軍艦を回し、足りなければ造船所で建造する
- **恒星間移民**: 人口が上限の90%を超えた入植地から、空きのある近くの入植地へ移民船が自動で出る。同時に居住区も自動で拡張する
- **航路**: 交易路上は光速。入植船と移民船は交易路をたどり、交易路網の外の目的地へは最も近い星系から最後だけ直行する (入植船は交易路の外では 0.9c)。軍艦は直行し、交易路が直接結ぶ区間以外は 0.9c。資材輸送船と交易用の貨物船は交易路しか通れない
- **資材の搬入**: 施設・軍艦・入植船を発注すると、地元に足りない資源は近くの入植星系から自動で取り寄せる。資材が光速で届いた時点で完成する
- **惑星間交易**: 入植星系どうしを交易路で結ぶと、余っている資源が足りない星系へ光速の貨物船で自動的に運ばれる。交易路がつながっていれば複数の交易路を乗り継いで届く
- **先住民**: 大気のある岩石惑星に先住民がいることがある。贈り物で友好度を上げて入植・交易・市民への統合を目指すか、軍艦と歩兵で制圧するか。制圧した先住民は奴隷化でき、市場奴隷 (労働力)・軍事奴隷 (安価な歩兵)・家畜 (食料) を切り替えられる。悪名が増えると他の先住民との関係が悪化する。解放もできる
- **軍隊**: 造船所で軍艦を建造し、星系間を移動させる。2320年以降に現れる宇宙海賊から入植地を守る
- **歩兵**: 軍事教練所 (惑星・ステーションの施設) で訓練するか軍事奴隷から徴集し、入植地ごとに駐留させる。交易路を通って移動し、先住民の制圧・反乱の抑止・海賊からの地上防衛に使う
- **種族**: 入植地の住民は種族の構成を持ち、先住民の統合や移民で混ざる。帝国タブで惑星ごとの種族数と内訳を見られる

### タブ

- **帝国**: 全星系の人口・資源・収支・軍事を一覧で管理。「交易路」「移民」「軍事」の切り替えで全交易路・移民・軍艦と歩兵の状況も見られる
- **イベント**: 飢餓・水不足・資源不足・海賊・先住民・入植などの重要な出来事と、いま起きている問題
- **候補地**: ハビタブルゾーン内にある未入植の天体を一覧し、そのまま入植船を送れる
