### 遊びかた

プレイヤーは地球政府。情報は光速でしか伝わらないので、遠い星系の様子は光が地球に届いた時点のもの (昔の様子) しか分からない。

- **地球目線**: 地図・帝国タブ・イベントは、地球に届いている情報で表示する (星系ごとに「○年前の情報」)。資金は地球政府のもの。船は地球から見た見かけの位置で動く。到着した船や通信も、その到着の光が地球に届くまでは途中を進んで見える
- **星系政府**: 入植した星系はそれぞれ独立した政府 (封建領主) を持ち、自分の資金で施設を建て、近くの星系へ交易路を引き、入植も自分で判断する。星系内の空いている天体 (入植地も先住民もいない) には宇宙ステーションを建てて拡張していく (10年に1つまで。太陽系は自動開発がオンのとき)
- **入植**: プレイヤー (地球政府) の入植船はいつも太陽系から自分で送り出す (費用は地球の資金と太陽系の備蓄)。ほかの星系の政府は自分の判断で入植する
- **従属と朝貢**: 星系は入植船を送ってきた星系に従属し、年間収入の25%を主人の星系へ朝貢する。従属は連鎖する
- **輸出入の代金と支援**: 交易路で運ぶ物資や建設資材を取り寄せると、受け手が基準価格で代金を払い、送り手の輸出収入になる。代金を払えない星系は、主人の星系が資源を持っていれば支援として無償で受け取れるが、そのぶん従属が深まって忠誠度が跳ね上がる (入植したての星系など)
- **資金援助**: 地球から地球の国の星系へ資金を送れる (光速の送金、星系の詳細欄から)。届くと忠誠度が上がる。入植後50年は、主人の星系が毎年、資金の3% (最大300 cr) を自動で送る (地球からの自動送金は政治タブで止められる)
- **指令**: 太陽系以外への指示は光速の指令として送られ、届いた先の政府が自分の資金で実行する
- **忠誠度と独立**: 星系の政府は忠誠度を持つ。主人や首都から遠いほど、主人より大きいほど、指令が多いほど下がり、主人の星系の艦隊で上がる。50未満だと指令を拒むことがあり、20未満だと独立を宣言する (従属する星系も一緒に離れる)。帝国 → 政治タブで一覧できる
- **国家間の戦争**: 独立国には宣戦・講和ができる (講和の申し出は光速で届く)。敵の星系へ艦隊を送ると艦隊戦になる。艦隊戦は時間をかけて進み (ランチェスターの法則で両軍が少しずつ沈み、戦力が近いほど長引く)、途中で届いた艦隊はその場で加わる。勝てば攻囲が始まり、艦隊の数と地上の抵抗 (歩兵・人口) に応じてゆっくり進んで降伏させる (降伏した星系は攻めた国の首都に従属する)。独立国はしぶとく、開戦から5年以上・戦力5倍以上の大差がついて初めて国ごと降伏し、地球の国に従属する。独立国は平時から星系ごとに軍事基地を建てて守りの艦隊を置き、戦争になると艦隊を増やして地球の国の星系を攻めてくる。地図では国ごとに輪の色が変わり、攻囲の進み具合も表示される

- **人口・産業**: 入植地の人口を「方針」で農業・鉱業・工業に振り分ける。施設(農場・鉱山・工場・居住区・軍事基地)をクレジットと金属で拡張できる
- **資源**: 食料・水・金属・燃料・希少元素・工業品。天体ごとに埋蔵量が違う。食料や水が足りないと人口が減る
- **経済**: 税収・交易・余剰資源の売却でクレジットを稼ぎ、入植船や施設、艦隊に使う
- **採掘基地**: 入植していない天体にも無人の採掘基地を置ける (同じ星系に入植地が必要)。ガス惑星からは水と燃料、岩石の天体からは金属と希少元素
- **自動開発**: 星系ごとにオンにすると、生産が需要に届かない資源を選んで惑星上の施設 (農場・鉱山・工場) や採掘基地を自動で建て、過密になれば居住区も拡張する
- **海賊対策の建艦**: 海賊が現れる5年前から、各星系の政府が自分の資金で軍事基地を建て、海賊の最大戦力ぶんの艦隊を編成する
- **自動防衛配備**: オンにすると、各入植星系の駐留艦隊を海賊の最大戦力まで自動で増やす。余っている艦隊を回し、足りなければ軍事基地で編成する
- **恒星間移民**: 人口が上限の90%を超えた入植地から、空きのある近くの入植地へ移民船が自動で出る。同時に居住区も自動で拡張する
- **航路**: 通信は光速、船は交易路上で 0.95c (地球へ向かう船も瞬間移動には見えない)。入植船と移民船は交易路をたどり、交易路網の外の目的地へは最も近い星系から最後だけ直行する (入植船は交易路の外では 0.9c)。艦隊は直行し、交易路が直接結ぶ区間以外は 0.9c。資材輸送船と交易用の貨物船は交易路しか通れない
- **征服戦争**: 入植に同意が要るのは最も進んだ未恒星間文明 (情報時代、統一国家) だけ。それ以外の先住民の惑星には勝手に入植でき、入植船に歩兵が同行して、到着すると征服戦争が自動で進む。入植地 (歩兵・艦隊・入植者の民兵) と先住民は毎年戦力を削り合い、先住民は疲弊でも弱っていく。劣勢になると入植船を送った星系が歩兵を送り込む (交易路がなければ直行)。戦争するかは戦争方針 (友好度の基準) で自動で決まり、進捗は地図の赤い輪と ⚔ の数字で分かる
- **入植船の積み荷**: 入植船は食料と水を積んでいき (交易路で物資が届き始めるまでの見込み年数ぶん)、入植先の備蓄にする
- **光速の通信**: 情報は光速でしか伝わらない。資源が足りない星系や建設地は、交易路でつながった送り手へ物資移送要求を送り、要求が届いてから荷が出発する。要求の動きは帝国 → 交易路タブで見られる。地図での描き方はヘッダーの「通信」ボタンで切り替える (表示しない・光の点。既定は表示しない)
- **資材の搬入**: 施設・艦隊・入植船を発注すると、地元に足りない資源は近くの入植星系から自動で取り寄せる。資材が届いた時点で完成する
- **惑星間交易**: 入植星系どうしを交易路で結ぶと、余っている資源が足りない星系へ0.95c の貨物船で自動的に運ばれる。交易路がつながっていれば複数の交易路を乗り継いで届く
- **先住民**: 大気のある岩石惑星に先住民がいることがある (天体観測で入植前から分かる)。贈り物で友好度を上げて入植・交易・市民への統合を目指すか、艦隊と歩兵で制圧するか。制圧した先住民は奴隷化でき、市場奴隷 (労働力)・軍事奴隷 (安価な歩兵)・家畜 (食料) を切り替えられる。悪名が増えると他の先住民との関係が悪化する。解放もできる
- **軍隊**: 軍事基地で艦隊を編成し、星系間を移動させる。2320年以降に現れる宇宙海賊から入植地を守る
- **歩兵**: 軍事教練所 (惑星・ステーションの施設) で訓練するか軍事奴隷から徴集し、入植地ごとに駐留させる。交易路を通って移動し、先住民の制圧・反乱の抑止・海賊からの地上防衛に使う
- **種族**: 入植地の住民は種族の構成を持ち、先住民の統合や移民で混ざる。帝国タブで惑星ごとの種族数と内訳を見られる

### タブ

- **帝国**: 全星系の人口・資源・収支・軍事を一覧で管理。「交易路」「移民」「軍事」の切り替えで全交易路・移民・艦隊と歩兵の状況も見られる
- **イベント**: 飢餓・水不足・資源不足・海賊・先住民・入植などの重要な出来事と、いま起きている問題
- **候補地**: ハビタブルゾーン内にある未入植の天体を一覧し、そのまま入植船を送れる

- **観戦モード**: ヘッダーの「観戦」で切り替え (ホーム画面から観戦モードで始めることもできる)。光の遅れなしに実際の様子 (船の実際の位置・各星系のいまの状態) を見られ、地球政府も自動で入植・開発・防衛配備・資金援助・戦争をする

### ホーム画面とセーブ

- 起動するとホーム画面が開く (ヘッダーの「ホーム」でいつでも開ける。開いているあいだは時間が止まる)
- 「続きから / ゲームに戻る」、新しいゲーム (銀河の番号と観戦モードを選べる)、セーブスロット3つ (セーブ・ロード・削除)、ファイルへの書き出しと読み込み
- 進行状況はブラウザに自動セーブされます (5秒ごと、1つだけ)。新しいゲームを始めると自動セーブは上書きされるので、残したいゲームはスロットへ
- 書き出したファイル (JSON) で別の端末に引き継げます
