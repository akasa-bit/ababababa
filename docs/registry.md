# 番号の予約

番号の取り合いをなくすための決まりです (回 R3。`docs/restart.md` の 5)。これまで、同じ目標の番号 (R28) を 2 つのレーンが同時に使おうとし、目標のファイルの版 (7) を 3 つのレーンが同時に上げて、番号のずらしと取り込み直しが続いた (`docs/conflicts.md` の 3 の 4)。

**番号は、使う前にここで取る。** ただし、取るための PR を待たなくて済むように、**レーンごとに先に範囲を割り当てておく**。自分のレーンの範囲から、小さい順に使い、使ったら下の「使った番号」の自分のレーンの欄に 1 行足す (欄がレーンごとに分かれているので、ほかのレーンと同じ行に書くことはなく、git が混ぜられる)。範囲を使い切ったら、この文書の末尾の「次の範囲」を 1 本の小さな PR で取る。

## 1. 番号の種類

| 種類 | 形 | どこで使う | 決まり |
|---|---|---|---|
| 目標の ID (現実) | `R<数>` | `targets/targets.json` の `realism`・`docs/targets.md` | 下の 2 の範囲から |
| 目標の ID (楽しさ) | `F<数>` | `targets/targets.json` の `fun` | 下の 2 の範囲から |
| 目標のファイルの版 | `version` | `targets/targets.json` | **予約しない**。目標を変える PR は 1 本ずつ (`docs/parallel.md` の 3)。マージの直前に main の版に 1 を足す。ぶつかったら、main を取り込んで足し直す |
| 補正の台帳 | `C<数>` | `docs/game-plan.md` の 4 | 下の 2 の範囲から。表の末尾に 1 行ずつ足す (並べ替えない) |
| 返事待ち | `QD-<数>` | `docs/decisions.md` | 下の 2 の範囲から |
| 残りの作業 | `B-<数>` | `docs/backlog.md` | 下の 2 の範囲から |
| 依頼の番号 | `<レーン>-<数>` | `docs/requests/<日付>-<レーン>.md` | **予約しない**。そのファイル (日付 × レーン) の中だけで数える (今のまま) |
| セーブの項目 | `saveField` の名前 | `src/` の仕組みのファイル (`core/base.js` の `saveField`) | 使う前に下の 4 の自分のレーンの欄に書く。`core/save.js` の `SAVE_LEGACY` と同じ名前は使えない |
| `EDITIONS.game` の値 | 名前 | `src/core/base.js` の `EDITIONS` | 使う前に下の 4 の自分のレーンの欄に書く (補正なら台帳の C の番号も) |
| `src/` のファイル | `src/<フォルダ>/<名前>` | `src/index.html` の `//#include` | 予約しない。**自分のレーンのフォルダの中だけ**に作り、`//#include` の行は、そのフォルダの行のまとまりの中に足す (`docs/parallel.md` の地図。`node tools/src.js --check` が組み込み忘れを見つける) |
