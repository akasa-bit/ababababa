# 従属関係の書き出し・比べる実験・ゼミの問い (レーン H・セッション H4-2)

ゲームの従属国の仕組み (`docs/vassal-game.md`) を、歴史学の授業で考察に使うための道具です。ユーザーの決定 (`docs/vassal-decisions.md` の 4) に沿って、**結びつきごとの表**と**星系 × 年のパネル**の両方を書き出します。レーン C の書き出し (`tools/fiscal-panel.js`) と同じく、画面なしの版で銀河を回す道具で、ゲームの中身は変えません。

## 1. 使い方

```sh
cd tools && npm ci                     # 初めのときだけ
node tools/vassal-export.js out/base 30 300 6             # 30 の銀河 × 300 年 × 6 か国
node tools/vassal-export.js out/T03 30 300 6 --force T03  # AI の国の新しい家臣をすべて保護国にする (比べる実験)
node tools/vassal-export.js out/T04 30 300 6 --force T04  # 同じ銀河で、すべて藩王国にする
```

- `--force <型>`: AI の国の新しい家臣の型をすべてその型にする (T01〜T19・`encomienda`)。同じシードなので、銀河と国は同じで、型だけが違う。人間の国 (観戦中のプレイヤーの国) の家臣は変えない。
- `--every <年>`: パネルを何年ごとに書くか (既定 5)。`--from <シード>`: 最初のシード (既定 1)。
- 出力: `ties.csv`・`panel.csv`・`meta.json` (設定と要約)。要約は、存続の中央値 (Kaplan–Meier)・100 結びつき年あたりの独立・法と実態の差の平均・独立の戦争の確率の平均を、全体と型の家族ごとに出す。

歴史の事例と同じ統計で比べるときは、`data/build/analyze_vassal.py` の関数 (`km_curve`・`cox`) を使う (`python3 data/build/analyze_vassal.py --game <tools/secession.js の書き出し>` は目標 R30〜R32 と比べる)。

## 2. コードブック

### ties.csv (1 行 = 1 つの主従の結びつき)

ICOW Colonial History (`data/raw/history/icow_colhist.csv`) と、従属国の事例 (`data/raw/vassal/cases.csv`) に合わせた形。

| 列 | 中身 |
|---|---|
| `seed` | 銀河のシード |
| `tie` | 結びつきの通し番号 (ファイルの中だけ) |
| `vassal`・`vassal_name` | 家臣の星系の番号と名前 |
| `lord` | 主人の星系 (家臣を持つ星系。国の首都とは限らない) |
| `realm` | 国 (いちばん上の主人の星系の番号) |
| `human` | 1 = 人間の国 (観戦中のプレイヤーの国) |
| `start`・`end`・`duration` | 始まりと終わりの年 (ゲームの暦。続いているものは `end` が空)・続いた年数 |
| `how` | 終わり方: `independence` 独立・`transfer` 主人か国が替わった・`other` そのほか・`abandoned` 入植地がなくなった・`censored` 試合の終わりに続いている (打ち切り) |
| `war` | 独立が戦争になったか (1/0)。戦争の判定は人間の国からの独立だけで行うので、AI の国どうしでは 0 |
| `war_p` | 独立のときの型の戦争の確率 (AI の国どうしの独立の比べに使う) |
| `type0`・`family0` | 始まりの型 (T01〜T19・`direct` = 植民地 (直轄)・`encomienda` = 植民地 + 強制労働) と型の家族 (`ritual` 儀礼の宗主権・`treaty` 条約の保護・`legal` 法と交易だけ・`settler` 入植者の自治・`colony` 直轄・`client` 傀儡と衛星・`dynastic` 君主と封の網) |
| `law0`・`fact0`・`gap0` | 始まりの束 (8 文字。順は 外交・軍事・課税と朝貢・法と裁判・統治者の任免・交易・宗教と文化・継承。S = 宗主・M = 分け合う・V = 従属国) と、法と実態の差の項目の数 |
| `type_end`・`law_end`・`fact_end` | 終わりの (最後の年の) 型と束 |
| `gap_mean` | 続いたあいだの法と実態の差の平均 |
| `elite_end`・`loyalty_end` | 最後の年の現地のエリートの構え (`coop` 協力・`bargain` 取引・`resist` 抵抗) と忠誠度 (0〜100) |
| `dist_lord_ly`・`dist_cap_ly` | 主人の星系と国の首都までの距離 [光年] (光の片道の年数と同じ) |

### panel.csv (1 行 = 1 つの家臣の星系の 1 年。`--every` 年ごと)

| 列 | 中身 |
|---|---|
| `seed`・`year`・`vassal`・`lord`・`realm` | 上と同じ |
| `type`・`family` | その年の型と家族 |
| `law`・`fact`・`gap` | その年の束と、法と実態の差 |
| `elite`・`loyalty` | 現地のエリートの構えと忠誠度 |
| `hazard` | その年に自立を求める動き (不満) が起きる確率 (離反のハザード。`docs/governance.md` の式) |
| `tribute` | 朝貢の割合 (型ごと) |
| `lord2` | 共同統治の 2 国目の宗主 (国の首都の星系。いなければ空) |
| `arrears` | 関税受領官の滞納 [cr] (プラット型だけ) |

### 限界

- ゲームの値は、事例 131 件 (`docs/vassal-cases.md`) から推定したものと仮の値の混ぜもの (`docs/vassal-game.md` の 2 と 6)。仮の値を変えて比べるときは、`tools/headless.js` の値のファイルで表を書き換える。
- ゲームには時代の差がない。歴史の儀礼の型と封の型の長さ (目標 R30) は、ゲーム版では判定していない (`docs/vassal-decisions.md` の 1)。
- 光の遅れのあるゲームなので、「1 年」は歴史の 1 年と同じではない (1 世代 = 100 年。`docs/reality-check.md`)。年数より、型どうしの比を見る。

## 3. 比べる実験の例 (10 の銀河 × 300 年 × 6 か国)

(下の表は `node tools/vassal-export.js out/<型> 10 300 6 --force <型>` の要約。H4-2 で回した)

| AI の家臣の型 (`--force`) | 結びつき | 存続の中央値 | 100 結びつき年あたりの独立 | 法と実態の差の平均 | 独立の戦争の確率の平均 |
|---|---|---|---|---|---|
| 藩王国 (T04) | 534 | 109 年 | 0.431 | 0.18 | 8.9% |
| 保護国 (T03) | 524 | 104 年 | 0.508 | 1.56 | 61.6% |
| 封臣 (T13) | 514 | 113 年 | 0.451 | 1.18 | 40.1% |
| 自治領 (T05) | 527 | 111 年 | 0.432 | 0.86 | 1.6% |
| 傀儡国 (T10) | 512 | 108 年 | 0.495 | 2.72 | 1.5% |

- 型だけを替えた同じ銀河で、独立の起きやすさは藩王国と自治領がいちばん低く、保護国と傀儡国が 15〜18% 高い。法と実態の差が大きい型ほど独立が多い (目標 R31 の向き)。
- 存続の中央値の差は小さい (104〜113 年)。人間の国の家臣と、主人が替わる結びつき (`transfer`) が混ざるため。型ごとの差を見るときは、独立だけを出来事として数える (100 結びつき年あたりの独立) か、`family0` で絞って Cox を回す。
- 独立の戦争の確率は型でいちばん大きく違う (保護国 62%・自治領 2%)。歴史の ICOW の宗主ごとの差 (英 9%・仏 32%) より、型による差のほうが大きく出る。
- 傀儡国は法と実態の差が大きい (2.7) のに、存続は保護国と変わらない。ゲームには宗主の敗戦で消える道筋 (満洲国 1945) がないため。ゼミの問い 1 の材料になる。

## 4. ゼミで使える問いの例

1. **法と実態**: 同じ銀河で、AI の家臣をすべて保護国 (`T03`) にした場合と藩王国 (`T04`) にした場合で、存続の中央値はどれだけ違うか。差はどの項目の「法と実態のずれ」から来ているか (`panel.csv` の `law`・`fact` を項目ごとに比べる)。歴史の保護国 (チュニジア 1881〜1956、韓国 1905〜1910) と比べて、ゲームが省いたもの (統監府のような中間の機関) は結果をどう変えそうか。
2. **現地のエリート**: エリートが抵抗に回った家臣は、その後何年で独立したか (`panel.csv` で `elite` が `resist` になった年から、`ties.csv` の終わりまで)。Robinson (1972) の「協力者の理論」は、このゲームの結果で支持されるか。協力が崩れる前に、主人は何をすべきだったか。
3. **距離と型**: AI の国は、首都から遠い家臣ほど条約の保護や入植者の自治を選ぶ (`docs/vassal-game.md` の 4)。距離 (`dist_cap_ly`) と独立の起きやすさの関係は、型を固定した実験 (`--force`) と、型を自由にした試合で違うか。歴史の Cox モデル (距離は効かなかった) と比べて何が言えるか。
4. **暴力**: 独立の戦争の確率 (`war_p`) は型の家族でどう違うか。歴史の ICOW (英 9%・仏 32%・スペイン 89%) との差は、何で説明できるか (宗主の種類か、型か、時代か)。
5. **反実仮想**: 「冊封朝貢国が条約の保護国に変えられなかったら」(清と朝鮮・越南) を、ゲームでどう問えるか。Tetlock & Belkin (1996) の反実仮想の決まり (最小の書き換え・ほかの事実との整合) に照らして、`--force` の実験は良い反実仮想か。
6. **型という考え方そのもの**: 史料の欄 (統治の欄の「史料」) の論争 (封建制をめぐる Ganshof と Reynolds、朝貢体制をめぐる Fairbank と Perdue) を読み、このゲームの「型 = 束の雛形」というモデルは、どちらの立場に近いか。19 の型に分けたことで見えなくなったものは何か。
