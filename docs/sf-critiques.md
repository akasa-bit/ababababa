# 物理学者が SF の描写に付けた文句と、このゲーム (P-6)

ユーザーの依頼: `docs/requests/2026-10-20-P.md` の P-6。

一流の物理学者が SF の描写を物理で論じた事例を集めました。そこから、今の物理学の知見で正しいものだけを選び、NoLongerUbiquitous に当てはまるかを判定しました。そのうえでゲームを直しました。

- データ: `data/raw/sf_critiques/` (集めた事例と分類) → `data/build/build_sf_critiques.py` → `data/derived/sf_critiques.json`
- ゲームの物理の棚卸し: `docs/research/game-physics-audit.md` (英語。節の番号 1.2・4.7 などは、下の表の「棚卸し」の列の番号)

棚卸しで見つかった食い違いも、ついでに直した:

- **進路変更の指令**: 移動中の艦隊へ指令が追いつく時刻を、太陽系からでなく首都から計算する。地球以外の国のときに、光より速く届いていた。両方の版。
- **地図の凡例**: 「地球に届いている光で描く」→「首都 (地球の国なら地球) に届いている光で描く」。両方の版。
- **入植候補の表**: 見出しの「最寄りの入植地から」を、実際の計算どおり「首都から」に直した。両方の版。
- **短い航路の船の時間**: 加速を終える前に折り返す航路の船の時間を、中点で折り返す式 2 (c/a) acosh(1 + 道のり ÷ 2c²/a) にした。前は一定の速さの式で、宇宙線の線量を少なく見積もっていた。シミュレーション版。
