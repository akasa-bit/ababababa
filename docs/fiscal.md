# 財政 (段 4 の 2)

`docs/game-plan.md` の段 4 の 2 つめ (セッション 7) です。止めていた財政 (税の段階・利子率・予算。ユーザーの依頼は `docs/requests-log.md` の 121) を、セッション 6 のお金の帳簿 ([money.md](money.md)) の上で作り直しました。あわせて、現実の長い期間のデータ (Jordà–Schularick–Taylor R6) と同じ形でゲームの財政を測り、どこが現実と違うかを表にしました。進め方の頼みは `docs/requests/2026-10-20-C.md` の C-6。

## 1. 財政の中身

セッション 20 (2026-10-21) で、4 つの手段を飛び飛びの段階からスライダーに変えました。選べる幅は、作る前に生データの国・年の 1〜99% 点で固定したもの ([policy-ranges.md](policy-ranges.md)。BIS の政策金利・世界銀行 WDI)。

| 選ぶもの | 選べる値 (幅は固定。刻みは画面のため) | 効き目 (大きさは仮の値。5 の表) | お金の行き先 |
|---|---|---|---|
| 税率 | 所得への税 2〜34% (刻み 0.5%。標準 15.5% = `MARKET.tax`) | 税の重さ k = 税率 ÷ 15.5%。家臣の忠誠度の目標 −15 × (k − 1)、首都の議会の支持 年 −0.5 × (k − 1)。前の 4 段階 (+6・0・−6・−12、+0.2・0・−0.2・−0.5) を直線にしたもの (重税 ×1.8 の議会は −0.5 → −0.4 に変わった) | 星系の家計 → 星系の政府 (自給の所得には掛からない) |
| 利子率 | 年 −1〜50% (刻み 0.25%) | 交易の値段 (運ぶ年数ぶんの利子 e^(利子率 × 年数)) と、銀行の貸出と預金の利子。マイナスなら向きが逆になり、預金が利子を払って借り手が受け取る (スイス 2014〜2022 年の形) | 下の 2 |
| 予算 (福祉・治安・軍事・教育・研究) | **2026-11-08 から: 機能ごとに標準を 100% として 0〜300% (刻み 5%。合わせた上限なし。16 を見る)**。前は首都の税収の 0〜60% ずつ (刻み 1%。合わせて 100% まで) | 福祉: 忠誠度の目標 ±最大 12・人口の増え方 ×0.85〜1.15。治安: 離反の起きやすさ ×1.4〜0.6。軍事: 艦隊の戦力 ×0.75〜1.25 (効き目 = 最大 × 3 (水準 − 1) ÷ (3 + 水準)。前は 最大 × 割合 ÷ (割合 + 0.1)) | 標準から動かした分だけ、首都の政府 ⇄ 首都の家計 (上げれば給付・給料・買い付け、下げれば浮く) |
| 赤字の上限 | 1 年に出せる国債 ÷ GDP 0〜15% (刻み 0.5%。0 は国債を出さない) | 資金が足りない分を国債で借りる ([debt.md](debt.md) の 4) | 銀行 → 首都の政府 |
| 消費税 (セッション 20 の 2) | 家計の買い物の値段に掛ける 0〜27% (刻み 0.5%) | 家計が見る値段が (1 + 税率) 倍になり、値段の弾力性のぶん消費が減る。所得の低い星系に重い (逆進)。忠誠度と議会への効き目は、所得への税率と合わせた重さ k = (税率 + 消費税) ÷ 15.5% で | 星系の家計 → 星系の政府 (物とサービスの買い物の値段 × 税率) |
| 関税 (セッション 20 の 2) | ほかの国からの輸入の値段に掛ける 0〜29% (刻み 0.5%) | 買い手の会社には、ほかの国の売り手の値段が (1 + 関税率) 倍に見え、国の中の売り手から多く買う (Krugman の重みの σ)。政府の資材の買い付けと主人の支援には掛からない | 買い手の星系の会社 → 買い手の星系の政府 (送り出すときに代金 × 関税率) |

- どれも、変えた知らせが光速で届いた星系から効きます (国家方針と同じ)。税率・利子率・赤字の上限を変えるには政治力 5 が要り、予算の割り振りには要りません。
- 消費税と関税の既定は 0 (人間でない国も)。消費税の幅だけは生データでなく OECD の標準税率の表の最低・最高で決めた ([policy-ranges.md](policy-ranges.md))。予算の割合の土台 (首都の税収) は所得への税のまま。
- 画面は 帝国 → 経済・政策 の「財政」の欄 (依頼 KE-4 で目標のタブから移した)。スライダーを離すと命令になり、動かしているあいだは横の値だけ変わります (`onPanelInput`)。幅の外・刻みに乗らない値は命令が通りません (`setFiscal`)。
- 前の 4 段階の名前 (低い・標準・高い・重税) は、古いセーブと命令の別名として残しています (税率 = 15.5% × 0.6・1・1.4・1.8)。セーブの `fiscal.tax` は税率そのものになりました。
- **人間でない国**は、既定では標準のまま (税率 15.5%・消費税 0・関税 0。`AI_FISCAL.vary = 0`。C-22「おすすめと既定のままで」2026-10-21)。`vary = 1` にすると、国ごとに現実の国の分布から 3 つの値を引く (1.3 の結果): 税の合計 ÷ 所得 は WDI の税収 ÷ GDP の国ごとの中央値の 10・50・90% 点 (8.0・15.7・24.2%) を標準 15.5% に合わせた 0.51・1・1.54 倍、そのうち消費税の割合は 財・サービスへの税 ÷ 税収 (GC.TAX.GSRV.RV.ZS) の 9.6・31.3・44.2%、関税率は TM.TAX.MRCH.WM.AR.ZS の 2.0・5.3・13.7%。10・50・90% 点を折れ線でつなぎ、シードと首都から別々に引く (試合の乱数は使わないので、再現できる)。所得への税率 = 合計 × (1 − 消費税の割合)、消費税率 = 合計 × 割合 ÷ (1 − 所得への税率) (買い物 ≈ 所得 − 所得への税とみる)。独立した国は元の国の財政を引き継ぐ。利子率は年 1%・予算 0 のまま、国債は Bohn の式 ([debt.md](debt.md)) のまま。結果は 1.3 (R19 が幅の下に出て、独立 +83%・戦争 +39%)。

## 2. 利子 (前の差分からの変更)

前の差分では、政府の貯えに年 1% の利子が**どこからも払われずに湧いていました**。今回は次の形にしました。

1. 銀行から借りている民間と先住民が、その星系で効いている国の利子率で利子を払う (払えない分は、また銀行から借りる)。
2. 銀行は、受け取った利子をすべて、預金 (政府の資金・民間と先住民の手持ち) の額に比べて分ける。銀行の儲けは 0。運ぶ途中のお金には利子がつかない。

利子の種類 (`interest`) も、お金の保存の試験 (`tools/tests/money.js`) で毎年確かめています。

## 3. 現実と同じ形で測る

### 3.1 やり方

1. 生データ: Jordà–Schularick–Taylor Macrohistory Database R6 (18 か国 1870〜2020 年)、Schmelzing (2020) の 1311〜2018 年の世界の実質利子率 (`data/fetch/fetch_fiscal.py` → `data/raw/fiscal/`)。
2. 目標: 税収 ÷ GDP (R19)、政府が黒字だった年の割合 (R20)、政府債務 ÷ GDP (R21)、民間の信用 ÷ GDP (R22)。幅は、ゲームを測る前に、生データの国ごとの値の 10%〜90% 点だけで決めて固定した (#120。`docs/targets.md` の版 4)。
3. ゲームの書き出し: `tools/fiscal-panel.js` が、画面なしの版で銀河を回し、国 (首都と従属星系の政府をまとめた一般政府) ごと・年ごとに、JST と同じ列 (`year, country, gdp, revenue, expenditure, debtgdp, tloans`) のパネルを書き出す。ゲームの中身は変えず、出入りの関数を道具の側で包んで数える。
4. 同じ台本: `data/build/analyze_fiscal.py` を、JST とゲームのパネルの両方にかける。

### 3.2 ゲームの国民経済計算の定義

| 列 | ゲームでの定義 | 現実 (SNA 2008・JST) との違い |
|---|---|---|
| gdp | 資源の付加価値 (採掘・収穫と工業の産出 − 工業の投入。基準価格 `PRICE`) + 政府が民間から買った分 (建設・維持費・予算。費用で測る。市場で売らない政府の産出を費用で測る SNA と同じ) | ゲームには市場の値段がないので、基準価格で測る。捨てた物も産出に入る (市場があれば、売れない物の値段は下がる) |
| revenue | 税 + 先住民からの収入 + 預金の利子 | JST は中央政府の収入 |
| expenditure | revenue − 政府の純貸出 (国の政府の資金の増加)。国の中の朝貢・資金援助・交易は、差し引きで消える | 同じ恒等式 (収入 − 支出 = 純貸出) |
| debtgdp | 政府の総債務 (資金がマイナスの政府のマイナス分) ÷ gdp | ゲームの政府は借りられない |
| tloans | 国の星系の民間と先住民の、銀行からの借り | JST は銀行から民間の非金融部門への貸出 |

### 3.4 ずれの理由 (1 試合を分けて見た。6 か国・100〜110 年目)

| 目標 | 理由 |
|---|---|
| R19 | 生産の値打ちは年に約 55 万 cr、税は約 1 万 cr。**基準価格 (`PRICE`) と税の大きさ (`BASE_TAX`・人口 × 0.08) が、互いに合わせて決められたことがない。** さらに、ゲームでは生産物はすべて政府の備蓄に入り、人々は代金を払わずに消費する (再分配の経済。ウル第三王朝やインカに近い形。[research/surplus-history.md](research/surplus-history.md) の 1.1・9.3)。生産の 4 割 (年 22 万 cr) は捨てていて、市場があれば値打ちがない物も GDP に入っている (捨てた分を除くと税収 ÷ GDP は約 0.03) |
| R20 | 政府は借りられず、資金の範囲でしか使えない。AI の政府は、入植と建設に備えて資金を積む |
| R21 | 政府が借りる仕組み (国債) がない |
| R22 | 民間の借りは、税を多く取る首都に集まる (地球の首都だけで 13 万 cr)。独立した小さな国 (1 銀河に約 8 か国) は借りがほぼ 0 で、すべての国の中央値を下げている。始めの 6 か国では幅の中 |

預金 ÷ GDP は約 0.47 で、現実 (広い意味のお金 ÷ GDP が 0.5〜1) に近い。

## 4. 部門の貸借表と取引表

Godley & Lavoie (2007) の形で書くと、ゲームのお金は次のとおりです。どの行も合計 0 になります。

### 4.1 貸借表 (ある時点の残高)

| | 政府 | 民間 | 先住民 | 運ぶ途中 | 銀行 | 合計 |
|---|---|---|---|---|---|---|
| 預金 (手持ち) | +資金 | +手持ち | +手持ち | +運んでいる額 | −預金の合計 | 0 |
| 貸出 | | −借り | −借り | | +貸出の合計 | 0 |
| 純資産 | 資金 | 手持ち − 借り | 手持ち − 借り | 運んでいる額 | −M₀ | 0 |

M₀ は、試合の始めに政府が持っていた資金 (`START_CREDITS`) の合計。銀行 (始めのお金を出した通貨当局を含む) の純資産は −M₀ で、試合のあいだ変わりません。銀行は貸すと同時に預金を作るので、預金の合計 − 貸出の合計 = M₀ がいつも成り立ちます (`tools/tests/money.js` の「全体」)。

### 4.2 取引表 (1 年の出入り)

| | 政府 | 民間 | 先住民 | 運ぶ途中 | 銀行 | 合計 |
|---|---|---|---|---|---|---|
| 税 | +T | −T | | | | 0 |
| 先住民からの収入 | +N | | −N | | | 0 |
| 建設・維持費・予算 | −G | +G | | | | 0 |
| 交易・朝貢・資金援助・開拓資金・出来事の費用 | ±X | ±(差) | ±(歓待) | ±(途中) | | 0 |
| 利子 | +i·D_政府 | +i·D_民間 − r·L_民間 | +i·D_先住民 − r·L_先住民 | | (受け取り − 払い = 0) | 0 |
| 純貸出 (列の合計) | 資金の増加 | 手持ち − 借りの増加 | 同 | 運んでいる額の増加 | 0 | 0 |

- r は借りた側の星系で効いている国の利子率。i は預金につく率で、i = (受け取った利子の合計) ÷ (預金の合計)。銀行の儲けは 0 にしてある。
- 試験 `money.js` は、行 (種類ごとの合計 0) と列 (帳簿ごとの記帳と額の増加の一致) を毎年確かめます。

## 7. 帰着の表・損の大きさ・行政の遅れ (回 KE8・B-012)

政策を通す手間の 1 段目 (`docs/econ-policy-list.md` の 5・7 の 3 の a)。帰着の表は、回 SE7 (利益集団の支持で政策を通す。B-022) がそのまま使えるように、星系の中の集団 (民族 × 所得の 5 分位。`docs/groups.md`) ごとの損得も出す。コードは `src/economy/incidence.js`、値は `src/economy/fiscal-consts.js` の `INCIDENCE`・`LOSS`・`ADMIN_LAG`、数の出どころは `docs/research/incidence.md`。

### 7.1 帰着の表

`incidenceOf(国, f1, f0)` = 財政を f0 から f1 にしたときの、手段ごとの 1 年の損得 [cr/年]。いまの帳簿の大きさに率の差を掛けた 1 次の近い形で、買い物・輸入・研究の量の変化と、そのあとの景気と物価の動きは入れない。

| 手段 | 家計 | 会社 | 政府 | ほかの国 | 所得の分位への分け方 |
|---|---|---|---|---|---|
| 所得への税 | −(率の差) × 家計の市場の所得 | — | + | — | 所得税の帰着 (上に重い) |
| 消費税 | −(率 × 買い物 ÷ 所得 の差) × 所得 (買い物 ≈ 所得 − 所得への税) | — | + | — | 消費税の帰着 (下に重い) |
| 関税 | −(率の差) × 関税の掛かる輸入 (`gv.mx`。値段を通して家計が負う) | — | + | — | 関税の帰着 (下に重い) |
| 政策金利 | 預金に比べて受け取り − 借りに掛かる差 | 同じ | 政府の資金に比べて受け取り | ほかの国の預金に比べて受け取り | 家計の分は金利の差の持ち高 (上に厚い)、会社の分は持ち主 |
| 研究開発の税額控除 | — | +(率の差) × 会社の研究開発費 (星系に家計の所得に比べて分ける) | − | — | 持ち主 (ほとんどいちばん上) |
| 予算 (機能ごと) | +(割合の差) × 首都の税収 (首都の家計が受け取る) | — | − | — | 福祉・教育は帰着の表、治安・軍事・研究は所得の分け前のまま |

- 部門を足すと 0 (お金は湧かない)。政策金利は、国の中の借り手 (家計・会社) が利子の差を払い、銀行を通してすべての預金の持ち主が預金に比べて受け取る (`interestStep` と同じ分け方。国債の利札は 1 年目は変わらないとみる。先住民は入れない)。銀行は銀河に 1 つなので、国の金利を上げると、ほかの国の預金の持ち主も得をする。
- 会社の分は、星系の家計が持つ分 (1 − 遠くの持ち主の持ち分 `gv.own`) だけ分位に分ける。
- `groupIncidence(星系, f1, f0)` = 星系の集団ごとの損得 `{ k: 民族, q: 分位, v: cr/年, rel: v ÷ 集団の家計の所得, by: 手段ごと }`。民族の間の所得の差は入れていない。
- 画面: 財政の欄の終わりに「帰着 (標準の財政と比べた 1 年の損得)」の表 (決めた財政と標準の財政の差。分位は分位の所得に対する割合)。
- 手元の例 (銀河 3・80 年目の地球の国。税率 20%・消費税 10%・福祉 10%): 所得への税は分位の所得の −2.1% (下) 〜 −6.4% (上)、消費税は −12.1% (下) 〜 −5.5% (上)、福祉は +6.9% (下) 〜 +0.6% (上)。政策金利を 3 点上げると、国の家計 −389・会社 −522・ほかの国 +910 cr/年。関税の掛かる輸入は銀河の全部で年 5 cr ほどと小さく (国の間の交易が少ない)、関税の損は今はほとんど 0。

### 7.2 損の大きさと忠誠・議会

家計の損の割合 ℓ (`policyLoss`。標準の財政と比べた、家計の市場の所得に対する 1 年の損) = 所得への税 (率 − 標準) + 消費税 (率 × (1 − 所得への税率) ÷ (1 + 率)) + 関税 (率 × 関税の掛かる輸入 ÷ 家計の所得。輸入 ÷ 所得は 1 まで)。

- 家臣の忠誠度の目標の「税」の項 = `LOSS.loyalty` × ℓ (= −15 ÷ 15.5%。所得の 1% の損で −0.97 点)。首都の議会の支持 年 `LOSS.council` × ℓ (= −0.5 ÷ 15.5%)。所得への税だけを変えたときは、前の式 (`TAX_LOYALTY` × (k − 1)) と同じ。
- 前と変わったこと: 消費税は、前は所得への税と同じ重さ (率をそのまま足す) と見ていたが、買い物の割合だけ軽くなった ((1 − 所得への税率) ÷ (1 + 消費税率) 倍。所得への税 15.5%・消費税 10% で 0.77 倍)。関税は、前は忠誠と議会に効かなかったが、損として効く。議会は、前は決めた財政で数えていたが、首都で効いている財政で数える。
- 集団の分位の差 (`groupDev`): 前は税の項を所得の分け前に比例させ、福祉の項を下に厚くした。いまは、手段ごとに分位の項 = 星系の項 × φ (φ = 分位の帰着の分け前 ÷ 所得の分け前 を、人口で平均して 1 にしたもの。`incFactor`)。所得への税の φ は下から 0.58・0.64・0.86・1.11・1.80、消費税は 1.43・1.09・0.97・0.86・0.65、関税は 1.19・1.03・0.92・1.01・0.85、福祉は 2.38・1.17・0.74・0.50・0.21。人口で平均すると星系の項のまま (差の平均は 0)。
- 人間でない国は標準の財政 (`AI_FISCAL.vary = 0`) なので、どの項も 0 で、試合の筋は前と同じ。

### 7.3 行政の遅れ

決めてから首都で効くまでの年数を手段ごとに持つ (`ADMIN_LAG`)。遠い星系は、そのうえ知らせが光速で届いてから効く。

| 手段 | 遅れ |
|---|---|
| 所得への税・研究開発の税額控除 | 0.85 年 |
| 消費税の率 | 0.05 年 (新しく入れるときは 1.75 年) |
| 関税 | 0.05 年 |
| 予算 | 0.5 年 |
| 政策金利・中央銀行に任せるか・赤字の上限 | すぐ |

- 財政に、手段ごとの首都で効き始める年 `on` と、いちばん遅い年 `done` を持つ (`setFiscal`。`fiscalFor` は、まだの手段だけ前の値にする)。遅れの途中でほかの手段を変えても、前に変えた手段の効き始めは動かない。前の財政 `prev` は、首都でいま効いている値 (前は決めた値)。
- 前の版のセーブ (`on` がない) は、前と同じく光の遅れだけ。
- 試験: `tools/tests/incidence.js` (帰着の表の足し算・分位・集団・忠誠と議会の式・遅れ・保存と読み込み)。`tools/tests/fiscal.js` は、首都の所得への税が遅れのあいだ前のままであることを見るように直した。

### 7.4 残り

## 8. 価格統制・配給・輸出禁止・禁輸 (回 KE9・B-008)

`docs/econ-policy-list.md` の 3 の G と 4 (24-2)。財政の命令の 4 つの欄として持ち (`ceil`・`ration`・`ban`・`embargo`)、ほかの財政と同じく議会の審議を通り (回 SE7・`docs/support.md`)、行政の遅れのあと首都で効き、遠い星系には光速で届いてから効く。値と出どころは `src/economy/fiscal-consts.js` の `ADMIN_LAG`・`CTL_RES`・`RATION_RES`・`CEIL_RANGE`。人間でない国はどれも使わない (試合の筋は、人間の国の禁輸がほかの国の買い手を止める分しか変わらない)。

| 手段 | 形 | 行政の遅れ | 現実の例 |
|---|---|---|---|
| 値段の上限 (`ceil`) | 資源ごとに、もとの値段 (`basePrice`) の 0.5〜2 倍 (0.05 きざみ)。国の星系の市場の値段は、値段が動いたあとで上限に切られる。上限で足りない分は買えない (不足。需要には数えるので、作る合図にはなる)。闇市は入れない | すぐ | 米国 1971 年 8 月 15 日の 90 日の凍結 (Executive Order 11615。発表の日に効いた) |

## 9. 物価の目標・量的緩和・金融抑圧・債務の再編・物価の外れの政治の損 (回 KE9・B-009・QD-27 = b)

`docs/econ-policy-list.md` の 3 の J と 4 (24-3)。帳簿は実質のままなので (`docs/money.md` の 5.1)、物価が上がって債務が軽くなる道は「国債の利札が物価に遅れる分、国債の実質の利子 (利札 − 物価の上がり方) が下がる」だけ。値と出どころは `src/economy/fiscal-consts.js` の `TARGET_RANGE`・`QE_RANGE`・`REPRESS_RANGE`・`QE`・`RESTRUCTURE`・`INFL_LOSS`。どれも人間の国だけが使う (物価の外れの政治の損だけは、どの国の家臣にも効く)。

| 手段 | 形 | 通し方 | 出どころ |
|---|---|---|---|
| 物価の目標 (`pistar`) | 中央銀行の目標 (既定 2%・幅 0〜20%)。中央銀行の則は選んだ目標で決め、物価の上がり方の式と見込みの錨と長期の利回りの錨は、人々が見込む目標 `s.T` (選んだ目標へ年 `CB.theta` = 0.3 の速さで近づく) を使う。国債の利札は借り換え (`CB.roll` = 7 年) で遅れて上がるので、そのあいだ実質の利子が下がる (インフレ税) | 中央銀行の決定と同じくすぐ (議会にかけない。英国では物価の目標を財務大臣が決める) | インフレ税の形は `econ-policy-list.md` の J |
| 量的緩和 (`qe`) | 国の星系の政府の国債のうち、中央銀行が持つ割合 (幅 0〜60%)。中央銀行は `QE.speed` = 1 年かけて買い、持った分 (`gv.qb`) の利子は国に戻る (政府は銀行が持つ分だけ払う)。長期の利回りが `QE.tp` × 中央銀行の持つ国債 ÷ GDP だけ下がり、買い入れ ÷ GDP × `QE.pi` だけ物価の水準が上がる (年 1 で消える上がり方として足す)。政府が国債を返した分は、銀行と中央銀行の持つ分に比べて返したとみる | すぐ | tp 0.042 = 米国の 2008〜10 年の買い入れ (GDP の約 12%) で期間の上乗せが約 0.5 点 (Gagnon ほか 2011 をまとめたカンザスシティ連銀の見方)。pi 0.47 = Weale & Wieladek (2016) の GDP の 1% の買い入れで物価 +0.62% (米国)・+0.32% (英国) の平均 |
| 金融抑圧 (`repress`) | 国の政府の、銀行が持つ国債の利札を repress 点下げる (幅 0〜4 点)。下げた分は国の中の預金者 (星系の政府・家計・会社・先住民) が預金に比べて受け取らない (国の中の預金者がふつうに受け取る額まで)。ほかの国の預金者は変わらない | 法なので議会の審議 (行政の遅れ 0.5 年は仮の値) | Reinhart & Sbrancia (2015): 1945〜80 年の先進国は実質の金利が負の年が約半分、米英の債務は年に GDP の 3〜4% ずつ目減りした |
| 債務の再編 (命令 `restructure`) | 国のすべての星系の政府の、銀行が持つ国債の 25・37・50・75% を払わない (中央銀行の持つ分は減らさない)。不履行 (`sovDefault`) と同じく預金が額に比べて目減りする。利回りの上乗せは払わない割合に比べる (Cruces & Trebesch 2013 の削り 1 点あたりの値。前からの `CB.spread`)。借りられない年数は `CB.exclude` × 割合 ÷ 37% (大きな再編ほど長い、は同じ論文。比例は仮の形)。首都の政府に国債がなくても、国として借りられない間を持つ | 政治力 20 (国家方針と同じ。仮の値)。借りられない間は続けてできない | Cruces & Trebesch (2013) の 1970〜2010 年の 180 件: 半分は 23% 未満か 53% 超・ギリシャ 2012 年 53.5%・アルゼンチン 2005 年 76.8% |

### 9.1 物価の外れの政治の損 (QD-27 = b)

物価の上がり方と 2% の差 1 点を、家計の所得の `INFL_LOSS` = 1% の損と同じに数え、税の損と同じ重さ (`LOSS`。7.2) で家臣の忠誠度の目標 (項「物価の上がり方」) と首都の議会の支持 (年ごと) を下げる。

- 重さの出どころ: Fair の大統領選挙の式 (2012 年の版) で、物価の上がり方 1 点が与党の票 −0.684 点、1 人あたりの成長 1 点が +0.672 点。成長 1 点 ≒ 所得 1% とみると、物価 1 点 ≒ 所得 1% の損。1984 年の版 (物価 −0.34・成長 +1.02) なら 3 分の 1 になる。Fair は物価の上がり方の絶対値で数えるが、ここでは目標 2% からの差にした (QD-27 の b の「目標から離れるほど」)。
- 人間の国が物価の目標を上げても、損は 2% からの差で数える (選んだ目標からの差にすると、インフレ税がただになる)。
- どの国の家臣にも効く。いまの版の物価の上がり方はほとんど 0〜5% なので、AI の国の家臣の忠誠度は 1 点ほど下がるだけ。集団の分位には分けていない (`groupDev` は税の項だけ)。

### 9.2 帰着の表

金融抑圧と量的緩和の行 (`incidenceOf`): 政府が払わなくなる国債の利子 (銀行が持つ国債 × 下げた点数、中央銀行が持つ国債 × 国債の実質の利子) を、国の中の預金者が預金に比べて負う。分け前は政策金利と同じ `rate`。量的緩和の利回りと物価の動きと、物価の目標は入れていない (動きの中の効きなので、1 次の表に乗らない)。

## 12. 星系ごとの所得の分け方と土地改革 (回 KE11・B-127)

前は、どの星系も所得の 5 分位の分け前が同じ定数 (`GROUPS.quint` = 世界銀行の 2,434 国・年の中央値 7・12・16・22・42%) で、土地改革を形にできなかった (10.1)。値と出どころは `src/economy/fiscal-consts.js` の `INEQ`・`LAND_RANGE`・`ADMIN_LAG.land`、計算は `src/economy/incidence.js` の `ineqSigma`・`ineqBase`・`quintOf`。目標は R84 (目標の版 29)。

### 12.1 形

- **所得は対数正規 (ばらつき σ)** とみる。5 分位の分け前は σ だけで決まる (上位 20% = 1 − Φ(0.8416 − σ) など)。世界銀行の 2,434 国・年で、上位 20% から解いた σ でほかの分位も平均 0.2〜0.8 点の差で当たる (`data/build/build_ineq.py`・`data/derived/ineq.json`)。
- **星系の σ = 素の偏り + 0.2749 × (農業の就業の割合 × 地主の割合 − 0.2014)**。
  - 素の偏り (`gv.sgb`): 国の首都は、世界銀行の国ごとの σ の平均の分布 (10% 点 0.548・中央値 0.706・90% 点 0.960) から、銀河と星系の番号で決まるくじで引く。ほかの星系は、はじめて入植地になった年に、その国の首都の値に国の中のばらつき (標準偏差 0.069) を足す。どちらも試合の乱数は使わない。
  - 農業の項: σ を国・年の農業の就業の割合に当てた傾き 0.2749 (2,187 国・年)。素の偏りはその平均の割合 (20.1%) のときの値とみて、星系の農業 (と自給) の就業の割合との差だけ動かす。構造転換で農業が減ると、偏りも少し下がる。
  - 地主の割合 = 1 − 効いている土地改革 (法)。
- 使う所: 帰着の表 (所得に比べる手段の分位の分け方)・集団の分位の損得 (`groupIncidence`)・集団の忠誠度の分位の差 (`incFactor`)・法案の支持の声の重さと関税の支持 (`politics/support.js`)・財政と集団の画面。

### 12.2 土地改革 (法 `land`)

- 地主の農地のうち耕す人へ移す割合 (0・25・50・75・100%)。法なので議会の審議にかけ、行政の遅れ 1 年 (台湾の「耕者有其田」は 1953 年 1 月の法から年末までに移した・韓国の農地改革法は 1949 年 6 月から 1950 年の分配)。
- 効き: 星系の σ が 0.2749 × 農業の就業の割合 × 割合 だけ下がる。農業が 50% の星系で全部移すと σ −0.14、上位 20% の分け前が約 5 点下がる。戦後の日本・韓国・台湾は耕地の 3〜4 割を移し、自作の農家が 8〜9 割になった (台湾の所得のジニ係数は 1953 年 0.56 → 1964 年 0.32。この間の工業化の分も入っている) ので、国と国の比較の傾きから決めたこの効きは、それより小さめ。
- 帰着の表の行「土地改革」: 家計の所得の合計は変わらず、星系ごとに (新しい分け前 − 前の分け前) × 家計の所得が分位のあいだで移る。上の分位の集団は損をして法案に反対し、下の分位は支持する (回 SE7 の支持の式がそのまま使う)。
- 入れなかったもの: 生産への効き (Besley & Burgess 2000 のインドの州では貧困が減ったが産出は変わらず、Adamopoulos & Restuccia 2020 のフィリピンの土地の上限では農業の生産性が下がり、Banerjee, Gertler & Ghatak 2002 の西ベンガルの小作の改革では上がった。向きが研究で違うので 0)・地主への補償 (財産の分位ごとの持ち分がゲームにないので、所得の分け方だけを動かす)・改革を戻すこと (法を 0 に戻すと地主の割合も戻る。現実の改革はほとんど戻らない)。

### 12.3 測った結果

- **R84 合格** (30 銀河 × 150 年 × 6 か国、5 年ごと。`node tools/ineq-panel.js f.csv 30 150 6 && python3 data/build/build_ineq.py --game f.csv`): 星系 (人口 100 万人以上) 1,064 の上位 20% の分け前の中央値 44.3% (幅 38.44〜54.70%)、ばらつき (90% 点 − 10% 点) 18.3 点 (幅 8.13〜24.38 点)。main は全部の星系が 42.4% でばらつき 0 (不合格)。
- 土地改革の効き (試験 `tools/tests/ineq.js`。シード 3・40 年目の首都): 首都は農業の就業が 6.4% と少ないので、全部移しても σ 0.636 → 0.618・上位 20% の分け前 41.8 → 41.2%。農業の多い開拓星系ほど大きく効く。
- AI の国は土地改革をしない。星系ごとの分け前は帰着の表・集団の忠誠度の分位の差・法案の支持の重さに入るので、家臣の集団の忠誠度と人間の国の法案の通り方が少し変わる (CI の自動対戦の表)。

## 15. お金の山と挑戦の届かなさ (回 KE15・B-069)

### 15.1 何もしないとお金が山になる

**根**: 人間が動かす首都の政府 (観戦でない) は、税を集めるだけで、ふだんの行政サービスに使わなかった (`fiscal.js` の `debtStep` の人間の分岐は国債の出し入れだけ。`docs/debt.md` の 4.1 = b「プレイヤーの政府は資金を自動では使わない」)。AI の国の政府は、手元の資金が税収の `DEBT.cash` (0.161) 年分を超えたら行政サービスに使う。何もしないと首都の政府の資金が積もり、預金の利子 (`interestStep` は借り手が払った利子を預金の多さで配る) で雪だるまになる。銀河 101・地球だけで、100 年で 12.5 万 cr (GDP の 9.14 倍)、300 年で 247 万 cr (GDP の 52.97 倍)。4 か国の 100 年の版でも首都が政府の資金 (プラスの分) の 97〜99% を持った。

**直し** (QD-99 = 上限 1 年分・変えられる): 財政の法に「手元の資金の上限」(`cashcap`。税収の 0.5・1・2・5 年分・上限なし。既定 1 年分) を足した。人間が動かす首都の手元の資金がこれを超えたら、超えた分を行政サービスに使う (AI の国の政府と同じく 1 刻みで超えた分の 1 − e^(−0.25) = 22.1%)。税収は帳簿のならし (始めの数年は 0 から上がる) と、税率 × GDP の見込みの大きいほう (始めの資金を始めの年に使いきらないように)。上限なしは前と同じ。変えるのは赤字の上限と同じく財政の法案 (議会の審議・行政の遅れ 0)。現実の政府の手元の資金 (0.161 年分) より上限を大きくしたのは、プレイヤーが入植船 (500 cr。始めの税収は年 2,000 cr ほど) などの大きな買い物を国債なしで買えるように。

**測り**:

| 銀河 101・地球だけ・2400 年 (100 年) | 125.2k cr (GDP の 9.14 倍) | 3.1k cr (0.23 倍) | 2.0k cr (0.15 倍) | 5.2k cr (0.38 倍) |

| 30 銀河 × 500 年・地球だけ (fun-targets の「何もしない」) | 3,294 万 cr | 27,955 cr (1,179 分の 1) | — | — |

GDP は上限のあるなしで変わらない (銀河 101 の 2350〜2600 年の GDP が同じ)。山だけが消えた。試験 `tools/tests/debt.js` の cashCap・cashCapNone・cashCapSave。

### 15.2 挑戦の F18 が届かない元

**直し** (QD-100 = 首都が属領の入植を出す。`economy/development.js` の `askColonyFunds`・`colonyAskArrived`・`colonyFundPay`、`fiscal-consts.js` の `COLONY_FUND`): 入植できるのに資金の足りない家臣の星系の政府は、足りない額を国の首都へ光速で願い出る (要求 `colask`。往復の光の時間と取っておく年数のあいだに 1 度まで)。願いが届いた首都 (人間が動かしていない首都) は、手元の資金で払えれば資金援助で送り、払えなければ願いを取っておき (`gv.colFund`)、その額を行政サービスに使わずに取っておく (回 KE14 の資本の予算と同じ。取っておくのは `INVEST_PLAN.years` = 2 年)。取っておく願いの合計は首都の税収の `COLONY_FUND.share` = 0.25 年分まで。人間が動かす首都には願わない (プレイヤーの資金を勝手に使わない。資金援助は手で送れる。**15.3 で変えた**: 自動の資金援助を入れていれば、人間の首都も税収の半年分を超えた手元の資金から答える)。試験 `tools/tests/colfund.js`。

### 15.3 資金援助で属領が自分で入植する (QD-100 の見直し・QD-101・QD-102)

15.2 の「国の入植の予算」を入れたあと、ユーザーから「いや待って、属領は勝手に膨張してほしいな。どちらかというと、資金援助で入植がどうにかならないか調べてみて」。入植船を出すのは前から属領自身で、首都は足りない資金を送るだけだったが、人間の国は願いの外で、AI の国も首都に資金がなくてほとんど届いていなかった。資金援助で属領の入植が回るかを調べた。

**調べたこと** (`tools/` ではなく試しの台本。観戦で 150 年進めて家臣を作り、人間の操作に切り替えて 60 年。4 銀河。同じ状態から形を変えて比べた):

| 形 (直す前の版) | 属領の入植船 | 止めた理由 (入植できる属領の年 × 星系) |
|---|---|---|
| 資金援助なし | 0・0・0・0 隻 | 資金 (クレジット不足) |
| 入植できるのに足りない属領へ、足りない額 + 1 割を手で送る (60 年に 7〜25 回・3,000〜13,000 cr) | 0・0・0・0 隻 | — |
| 資金を完全に足す | 0・0・0・4 隻 | 低付加価値物品か食料が足りない |
| + 入植の人口の線 100 万人 | 0・0・0・8 隻 | 同じ (入植できる属領は 2.37 倍) |
| + 資材も足す | 21・25・19・19 隻 (星系 +8〜+18。そのままは +2〜+4) | なし |

- 止めていたのは 3 つ: **人口** (人間の国の属領は入植に 300 万人。ある銀河では属領 18 のうち 16 が届かない)・**資金** (属領の GDP は年 0〜56 cr)・**資材** (入植船 1 隻に低付加価値物品 100・食料など)。
- 資材が買えない訳: 属領はみな交易路で首都とつながっていたが、取り寄せられるのは売り手の「目標の在庫を超える余り」だけ。首都の在庫は自分の消費の目標を割っていて (銀河 1: 低付加価値物品 4,708 に目標 6,003・食料 810 に目標 3,176)、外へ出す余りがなかった。首都自身は自分の在庫をそのまま使えるので入植でき、属領だけが止まっていた。
- 資金援助の行き先: 資金援助は届くと属領の資金に入り、赤字 (資金のマイナス) の穴埋めや行政サービスに消えた (借りの重い政府への援助が貸し手や赤字に消える形)。

**直し** (ユーザーの選び: QD-101 = 市場で値段を上げて買える・QD-102 = 100 万人に下げる):

1. **品薄でも買える** (`economy/colonize.js` の `procureFrom`・`market-consts.js` の `SCARCE`): 資材の取り寄せで、目標を超える余りで足りなければ、交易路でつながった売り手 (光の遅れのぶん古い記録が届いている星系) から、目標を割る分も 1 回の注文で売り手のいまの在庫の 1 割まで、品薄の値段 (`bulkPrice`。買ったあとの在庫で決まる。在庫が目標の半分なら基準の 2 倍) で買える。主人の援助 (払えない属領に主人が資材を回す) は前のとおり余りからだけ (首都の在庫が援助で減りすぎないように)。資材の取り寄せはどの建設も同じ関数を通るので、経済全体の値段の決まり方が変わる (下の測り)。
2. **人間の国の属領の入植の人口の線を 100 万人に** (`economy/development.js` の `aiColonize`。台帳 C20 の人口の分だけ。入植船は 1 隻ずつ・ふだん 10 光年のまま。シミュレーション版は変えない)。
3. 属領は、入植船の代金と**資材の代金を合わせた額**を取り置き (資本の予算)、足りない分を首都に願い出る (前は船の代金だけで、資材の代金で「資金不足」になっていた)。
4. **入植船のための資金援助** (`col`): 首都が願いに答えて送る資金援助は、属領に届いても資金に入れず、要求の上に取っておく (`held`)。属領が入植船を買えるとき (資材がそろい、合わせて足りるとき) に資金に入れて、その刻みで使う (`releaseHeldColony`)。`COLONY_FUND.hold` = 5 年使われなければ、ふつうの資金援助として資金に入る。お金は要求の上にあるあいだも運ぶ途中のお金として数える (お金の試験はそのまま合格)。
5. **人間の首都も答える**: 「自動の資金援助」(帝国 → 政治。前からある設定で、既定は入) を入れていれば、人間の首都も属領の願いに答える。払うのは税収の半年分 (`COLONY_FUND.keep`) を超えた手元の資金からだけ (プレイヤーが自分で使う分を残す)。切れば願いも来ない。

**測り (直したあと。手元の 4 銀河 × 60 年)**: 資金を完全に足したときの属領の入植船は 12・13・22・13 隻 (直す前 0・0・0・4。資材の不足はなくなった)。自動の資金援助だけ (プレイヤーは何もしない) で 3・3・0・3 隻、入植できるのに足りない属領へ手で送ると 8・2・0・6 隻。属領が自分で入植するようになったが、首都の手元の資金 (税収の半年分を超えた分)・属領の入植先の範囲 (10 光年)・入植の間隔 (10 年) で、資金を完全に足したときよりは少ない。30 銀河の測りは下。

## 16. 予算を「標準の何 %」で選ぶ (ユーザーの依頼 2026-11-08 の common-3)

**依頼** (`docs/requests/2026-11-08-common.md` の common-3): 「今だと標準に予算を足すことしかできない。減らせるようにしよう」「複数種の予算が足されて 100% が上限になるシステム、いる?」「通算の上限をなくして、すべての予算を 100% 基準にした上で、0% から 300% まで動かせるようにしよう」。

**前の形**: 予算の 5 つ (福祉・治安・軍事・教育・研究) は、首都の税収のうち標準に**足す**割合で、機能ごとに 0〜60%・合わせて 100% まで。0 が既定で、減らす向きはなかった。

**いまの形** (`economy/fiscal-consts.js` の `BUDGET`・`budgetLv`・`budgetExtra`・`budgetEffect`、`fiscal.js` の `budgetStep`・`budgetAt`):

- 機能ごとに**標準を 100%** として、0〜300% を 5% 刻みで選ぶ。合わせた上限はない。既定は 5 つとも 100%。人間でない国はいつも 100%。
- **標準の分は、政府のふだんの支出に入っている**とみて、お金の流れは足さない (研究者の曲線の政府の分と同じ考え。`docs/innovation.md` の 3.2)。標準から動かした分だけ、1 年に (水準 − 1) × 標準の額 を、首都の政府と首都の家計のあいだで動かす。上げれば政府が払い (給付・給料・買い付け)、下げれば浮く (家計への給付が減る = 家計から政府へ)。浮いた分を先に受け取り、上げた分は手元の資金の分だけ払う (払えた割合 `bpaid` だけ、上げた分が効く)。
- **効き目** = 最大 × 3 (水準 − 1) ÷ (3 + 水準): 100% で 0、300% で表の「最大」、0% で同じ大きさの逆向き。200% で最大の 0.6 倍、50% で −0.43 倍。上げるほど伸びが鈍り、下げた痛みは同じ幅の上げの得より大きい。
- 教育と研究は効き目の式でなく、動かした額で効く (前と同じ道): 教育は動かした支出 ÷ GDP が学校を出る世代の就学年数と学力に入る (負なら縮む)。研究は動かした額 ÷ 研究者 1 人の費用だけ公の研究者を足す・減らす (減らすのは研究者の曲線の政府の分まで)。会社の研究への呼び水 (弾力性 0.5) は、増やしたときだけ効かせた (測られたのは増やした側で、0 まで減らすと会社の研究まで 0 になる式のため)。
- 支持 (議会の審議) と帰着の表は、水準でなく動かした額 ÷ 税収で数える (前の割合と同じ物差し)。

**標準の額** (税収に対する割合。年金と医療の `govScale` と同じく、税収に対する割合を OECD に合わせる。QD-30):

| 機能 | 標準 ÷ 税収 | 出どころ |
|---|---|---|
| 福祉 | 25.5% | COFOG の社会保護 40% × 一般政府の支出 ÷ GDP 40.8% から公的年金 7.7% (年金はゲームで別に払う) を引き、税収 ÷ GDP 33.8% で割る |
| 治安 | 4.8% | 公共の秩序と安全 4% × 40.8% ÷ 33.8% |
| 軍事 | 3.6% | 防衛 3% × 40.8% ÷ 33.8% |
| 教育 | 14.5% | 教育 12% × 40.8% ÷ 33.8% |
| 研究 | 1.5% | 政府が出す研究開発費 ÷ GDP の国・年の中央値 0.522% (OECD MSTI。`data/derived/innovation.json` の `rnd.caps.public_median`) ÷ 33.8% |

支出 ÷ GDP 40.8% は OECD *Government at a Glance 2021* の 2019 年の OECD 平均。COFOG の割合は `COFOG` の表の値 (`docs/econ-policy-list.md` の 3 の B)。5 つとも 0% なら税収の約 50% が浮き、5 つとも 300% なら税収の約 100% を多く使う。

**同じもの**: 既定 (5 つとも 100%) のままなら、試合の中身は前の版と同じ (シード 3・6 か国・120 年と、シード 5・地球だけ・200 年で、セーブの中身が予算の欄とセーブした時刻のほかは同じ)。CI の自動対戦は人間の財政を動かさないので、数は変わらない。

**前の版のセーブ**: セーブに予算の形の版 `bv` (= 2) を足した。ないセーブは、読み込みで前の割合を水準 1 + 割合 ÷ 標準 に直す (刻みに丸め、300% で止める。`budgetFromShares`)。直すのは席の財政・その前の財政・審議中の法案の値。

**試し** (地球だけ・銀河 101 と 102・150 年。人間の国は観戦の AI が動かし、予算だけを始めに決めて置いたまま。`budgetStep` は観戦でも動く):

| 予算 | 首都の資金 (cr) | 国の星系 | 家臣の忠誠度の平均 | 上げた分を払えた割合 |
|---|---|---|---|---|
| 5 つとも 100% (既定) | −161・114 | 21・16 | 77.0・71.3 | — |
| 5 つとも 0% | −294・237 (福祉だけで年 754・800 cr 浮く) | 21・18 | 65.6・61.0 | — |
| 福祉だけ 0% | 353・425 | 20・19 | 63.4・64.1 | — |
| 軍事だけ 300% | 584・168 | 21・19 | 82.6・78.2 | 100% |
| 5 つとも 300% | −5・−768 | **3・2** | 100・76.4 | 90%・37% |

5 つとも 300% (税収の約 100% を多く使う) は、予算が資金を先に使い切って入植が止まる (前の版の「合わせて 100%」と同じ端)。福祉を 0% にすると忠誠度が 10〜14 点下がり、そのぶん資金が残る。

**目につく違い**: 標準の額は機能ごとに大きく違うので、同じ「+100%」でも払う額が違う (軍事は税収の 3.6%、福祉は 25.5%)。軍事は安く上げられる。現実の政府の支出の割合のままにした。

### 16.2 年金と医療の水準 (QD-119 = a。依頼 common-4)

予算と同じく、**年金と医療も標準を 100% として 0〜300%** (5% 刻み) で選べるようにした (`AGE_BUDGET`。値は財政の `budget.pension`・`budget.health`。既定 100%。人間でない国はいつも 100%)。

- **払う額**: 国のどの星系の政府も、いままでの式 (`ageSpendStd`。年金 = 0.445 × 65 歳以上の割合 × 所得、医療 = 0.049 × (1 + 2 × 65 歳以上の割合) × 所得。どちらも × 15.5% ÷ 33.8%) に水準を掛けて払う。所得への税と同じく、変えた知らせが光速で届いた星系から効く (行政の遅れは予算と同じ 0.5 年)。人間が動かす首都が手元の資金の分だけ払う (`apaid`) のは前と同じ。
- **損得**: 標準から下げた分 ÷ その星系の家計の所得 を、家計の損 `policyLoss` の `age` とする。所得への税・消費税・関税の損と同じ道で、家臣の忠誠度の目標 (所得の 1% の損で −0.97 点。忠誠度の内訳の「年金と医療の水準」) と首都の議会の支持を下げる。上げれば得として上がる。帰着の表 (`incidenceOf`) と法案の支持にも、星系の家計の損得として入る (分位には所得の割合で分ける)。
- **大きさの目安**: 65 歳以上が 28% の星系では、標準の年金は家計の所得の約 5.7%、医療は約 3.5%。両方 0% にすると、税収 (所得の 15.5%) の約 6 割が浮き、忠誠度の目標は約 −9 点。所得への税をその分上げたときと同じ重さ。
- **入れていないもの**: 年金を下げても、高齢の人の数や出生は変えない (家計の所得の損としてだけ数える)。医療の水準の死亡率への効き目は、現実のデータから 16.3 で入れた (依頼 common-5)。

**試し** (地球だけ・銀河 101 と 102・300 年。人間の国は観戦の AI が動かし、水準だけを始めに決めて置いたまま。300 年たつと試合の筋が大きく分かれるので、2 つの銀河の値は目安):

| 水準 | 首都の 1 年の収支 (cr) | 首都の資金 (cr) | 国の星系 | 家臣の忠誠度の平均 |
|---|---|---|---|---|
| 年金・医療とも 100% (既定) | −2,872・−1,236 | 259・329 | 25・28 | 80.4・82.2 |
| 年金 50% | −2,617・−805 | 70・−91 | 35・28 | 58.3・50.2 |
| 年金・医療とも 0% | **+2,342・+5,118** | 474・−117 | 28・33 | 55.1・82.0 |
| 年金 200% | −6,994・−4,479 | **−19,870・−15,573** | **11・8** | 56.7・62.2 |

両方 0% にすると、終盤の首都の収支が赤字から黒字に変わる。年金を 200% にすると、首都の資金が大きくマイナスになり、国が 8〜11 星系まで縮んだ。忠誠度は筋の分かれ方で大きく揺れる (下げた分の損の項は −2.5〜−9 点ほど)。


### 16.3 医療の水準と 65 歳以上の死亡率 (ユーザーの依頼 2026-11-08 の common-5)

医療を下げると、家計の損 (16.2) に加えて、**65 歳以上の死亡率が少し上がる**ようにした。大きさは現実のデータから決めた (`docs/research/health-mortality.md`)。

- **データ**: WDI と WHO GHED の国 × 5 年の区間 868 の候補から、データがそろわない・人口 100 万人未満・武力紛争・ありえない跳び・外れ値を除いた 403 を使い、5 年の変化を国と年の固定効果で推定した。死亡の登録が 90% 以上の国で、合計の医療の支出が 1% 増えると 65 歳以上の死亡のハザードが 0.044% 下がる (95% 区間 −0.111〜+0.011%。**0 にかかる**)。15〜64 歳には効き目がない。全部の国をまとめるとほぼ 0。
- **式**: L = 医療の水準 × 払えた割合 `apaid` (人間の首都が資金不足で払いきれないときも下がる)。65 歳以上のきざみの死亡のハザード × (1 + 0.7227 (L − 1))^−0.0436 (`DEMO.healthMort`・`healthMortK`。`docs/demography.md` の 3.3)。0.7227 は医療の支出のうち政府の割合 (高所得国の中央値) で、政府が払うのをやめても家計の払う分は残るとみなす。
- **大きさ**: L = 0 で ×1.058 (65 歳の平均余命 20 年なら約 −0.46 年)、0.5 で ×1.020、2 で ×0.977、3 で ×0.962。0 と 3 は観測の幅の外へのばした値。財政の画面の医療の行に、水準ごとの倍率を出す。
- **試合での大きさ**: 地球の本星の年齢の表だけを、所得と出生を止めて 150 年回すと、65 歳以上の割合は 0% で 20.07%・50% で 20.33%・100% で 20.47%・200% で 20.65%・300% で 20.76%。人口は 0% で −0.5%。ゲーム版は人口の合計が前の増え方のまま (`docs/demography.md` の 2) なので、変わるのは年齢の中身だけ。地球だけの試合 (銀河 101・102、150 年) では、試合の筋の分かれ方 (高齢の割合 0.229〜0.241) の方が大きく、医療の水準の差は見分けられない。
- 小さく、統計的にはっきりしない効き目を、ユーザーの依頼 (「統計学的に整合性が取れるもの」から作る) に沿って、推定の点の値のまま入れた。死亡率の面では、医療を削ることはほとんど得にも損にもならず、損は主に家計の損 (忠誠度と議会の支持) で出る。
