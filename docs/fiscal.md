# 財政 (段 4 の 2)

`docs/game-plan.md` の段 4 の 2 つめ (セッション 7) です。止めていた財政 (税の段階・利子率・予算。ユーザーの依頼は `docs/requests-log.md` の 121) を、セッション 6 のお金の帳簿 ([money.md](money.md)) の上で作り直しました。あわせて、現実の長い期間のデータ (Jordà–Schularick–Taylor R6) と同じ形でゲームの財政を測り、どこが現実と違うかを表にしました。進め方の頼みは `docs/requests/2026-10-20-C.md` の C-6。

## 1. 財政の中身

セッション 20 (2026-10-21) で、4 つの手段を飛び飛びの段階からスライダーに変えました。選べる幅は、作る前に生データの国・年の 1〜99% 点で固定したもの ([policy-ranges.md](policy-ranges.md)。BIS の政策金利・世界銀行 WDI)。

| 選ぶもの | 選べる値 (幅は固定。刻みは画面のため) | 効き目 (大きさは仮の値。5 の表) | お金の行き先 |
|---|---|---|---|
| 税率 | 所得への税 2〜34% (刻み 0.5%。標準 15.5% = `MARKET.tax`) | 税の重さ k = 税率 ÷ 15.5%。家臣の忠誠度の目標 −15 × (k − 1)、首都の議会の支持 年 −0.5 × (k − 1)。前の 4 段階 (+6・0・−6・−12、+0.2・0・−0.2・−0.5) を直線にしたもの (重税 ×1.8 の議会は −0.5 → −0.4 に変わった) | 星系の家計 → 星系の政府 (自給の所得には掛からない) |
| 利子率 | 年 −1〜50% (刻み 0.25%) | 交易の値段 (運ぶ年数ぶんの利子 e^(利子率 × 年数)) と、銀行の貸出と預金の利子。マイナスなら向きが逆になり、預金が利子を払って借り手が受け取る (スイス 2014〜2022 年の形) | 下の 2 |
| 予算 (福祉・治安・軍事) | 首都の税収の 0〜60% ずつ (刻み 1%。合わせて 100% まで) | 福祉: 忠誠度の目標 +最大 12・人口の増え方 ×最大 1.15。治安: 離反の起きやすさ ×最大 0.6。軍事: 艦隊の戦力 ×最大 1.25 (効き目 = 最大 × 割合 ÷ (割合 + 0.1)) | 首都の政府 → 首都の家計 (給付・給料・買い付け) |
| 赤字の上限 | 1 年に出せる国債 ÷ GDP 0〜15% (刻み 0.5%。0 は国債を出さない) | 資金が足りない分を国債で借りる ([debt.md](debt.md) の 4) | 銀行 → 首都の政府 |
| 消費税 (セッション 20 の 2) | 家計の買い物の値段に掛ける 0〜27% (刻み 0.5%) | 家計が見る値段が (1 + 税率) 倍になり、値段の弾力性のぶん消費が減る。所得の低い星系に重い (逆進)。忠誠度と議会への効き目は、所得への税率と合わせた重さ k = (税率 + 消費税) ÷ 15.5% で | 星系の家計 → 星系の政府 (物とサービスの買い物の値段 × 税率) |
| 関税 (セッション 20 の 2) | ほかの国からの輸入の値段に掛ける 0〜29% (刻み 0.5%) | 買い手の会社には、ほかの国の売り手の値段が (1 + 関税率) 倍に見え、国の中の売り手から多く買う (Krugman の重みの σ)。政府の資材の買い付けと主人の支援には掛からない | 買い手の星系の会社 → 買い手の星系の政府 (送り出すときに代金 × 関税率) |

- どれも、変えた知らせが光速で届いた星系から効きます (国家方針と同じ)。税率・利子率・赤字の上限を変えるには政治力 5 が要り、予算の割り振りには要りません。
- 消費税と関税の既定は 0 (人間でない国も)。消費税の幅だけは生データでなく OECD の標準税率の表の最低・最高で決めた ([policy-ranges.md](policy-ranges.md))。予算の割合の土台 (首都の税収) は所得への税のまま。
- 画面は 帝国 → 目標 の「財政」の欄。スライダーを離すと命令になり、動かしているあいだは横の値だけ変わります (`onPanelInput`)。幅の外・刻みに乗らない値は命令が通りません (`setFiscal`)。
- 前の 4 段階の名前 (低い・標準・高い・重税) は、古いセーブと命令の別名として残しています (税率 = 15.5% × 0.6・1・1.4・1.8)。セーブの `fiscal.tax` は税率そのものになりました。
- **人間でない国**は、既定では標準のまま (税率 15.5%・消費税 0・関税 0。`AI_FISCAL.vary = 0`。C-22「おすすめと既定のままで」2026-10-21)。`vary = 1` にすると、国ごとに現実の国の分布から 3 つの値を引く (1.3 の結果): 税の合計 ÷ 所得 は WDI の税収 ÷ GDP の国ごとの中央値の 10・50・90% 点 (8.0・15.7・24.2%) を標準 15.5% に合わせた 0.51・1・1.54 倍、そのうち消費税の割合は 財・サービスへの税 ÷ 税収 (GC.TAX.GSRV.RV.ZS) の 9.6・31.3・44.2%、関税率は TM.TAX.MRCH.WM.AR.ZS の 2.0・5.3・13.7%。10・50・90% 点を折れ線でつなぎ、シードと首都から別々に引く (試合の乱数は使わないので、再現できる)。所得への税率 = 合計 × (1 − 消費税の割合)、消費税率 = 合計 × 割合 ÷ (1 − 所得への税率) (買い物 ≈ 所得 − 所得への税とみる)。独立した国は元の国の財政を引き継ぐ。利子率は年 1%・予算 0 のまま、国債は Bohn の式 ([debt.md](debt.md)) のまま。結果は 1.3 (R19 が幅の下に出て、独立 +83%・戦争 +39%)。

## 2. 利子 (前の差分からの変更)

前の差分では、政府の貯えに年 1% の利子が**どこからも払われずに湧いていました**。今回は次の形にしました。

1. 銀行から借りている民間と先住民が、その星系で効いている国の利子率で利子を払う (払えない分は、また銀行から借りる)。
2. 銀行は、受け取った利子をすべて、預金 (政府の資金・民間と先住民の手持ち) の額に比べて分ける。銀行の儲けは 0。運ぶ途中のお金には利子がつかない。

利子の種類 (`interest`) も、お金の保存の試験 (`tools/tests/money.js`) で毎年確かめています。

## 3. 現実と同じ形で測る

### 3.1 やり方

1. 生データ: Jordà–Schularick–Taylor Macrohistory Database R6 (18 か国 1870〜2020 年)、Schmelzing (2020) の 1311〜2018 年の世界の実質利子率 (`data/fetch/fetch_fiscal.py` → `data/raw/fiscal/`)。
2. 目標: 税収 ÷ GDP (R19)、政府が黒字だった年の割合 (R20)、政府債務 ÷ GDP (R21)、民間の信用 ÷ GDP (R22)。幅は、ゲームを測る前に、生データの国ごとの値の 10%〜90% 点だけで決めて固定した (#120。`docs/targets.md` の版 4)。
3. ゲームの書き出し: `tools/fiscal-panel.js` が、画面なしの版で銀河を回し、国 (首都と従属星系の政府をまとめた一般政府) ごと・年ごとに、JST と同じ列 (`year, country, gdp, revenue, expenditure, debtgdp, tloans`) のパネルを書き出す。ゲームの中身は変えず、出入りの関数を道具の側で包んで数える。
4. 同じ台本: `data/build/analyze_fiscal.py` を、JST とゲームのパネルの両方にかける。

### 3.2 ゲームの国民経済計算の定義

| 列 | ゲームでの定義 | 現実 (SNA 2008・JST) との違い |
|---|---|---|
| gdp | 資源の付加価値 (採掘・収穫と工業の産出 − 工業の投入。基準価格 `PRICE`) + 政府が民間から買った分 (建設・維持費・予算。費用で測る。市場で売らない政府の産出を費用で測る SNA と同じ) | ゲームには市場の値段がないので、基準価格で測る。捨てた物も産出に入る (市場があれば、売れない物の値段は下がる) |
| revenue | 税 + 先住民からの収入 + 預金の利子 | JST は中央政府の収入 |
| expenditure | revenue − 政府の純貸出 (国の政府の資金の増加)。国の中の朝貢・資金援助・交易は、差し引きで消える | 同じ恒等式 (収入 − 支出 = 純貸出) |
| debtgdp | 政府の総債務 (資金がマイナスの政府のマイナス分) ÷ gdp | ゲームの政府は借りられない |
| tloans | 国の星系の民間と先住民の、銀行からの借り | JST は銀行から民間の非金融部門への貸出 |

### 3.4 ずれの理由 (1 試合を分けて見た。6 か国・100〜110 年目)

| 目標 | 理由 |
|---|---|
| R19 | 生産の値打ちは年に約 55 万 cr、税は約 1 万 cr。**基準価格 (`PRICE`) と税の大きさ (`BASE_TAX`・人口 × 0.08) が、互いに合わせて決められたことがない。** さらに、ゲームでは生産物はすべて政府の備蓄に入り、人々は代金を払わずに消費する (再分配の経済。ウル第三王朝やインカに近い形。[research/surplus-history.md](research/surplus-history.md) の 1.1・9.3)。生産の 4 割 (年 22 万 cr) は捨てていて、市場があれば値打ちがない物も GDP に入っている (捨てた分を除くと税収 ÷ GDP は約 0.03) |
| R20 | 政府は借りられず、資金の範囲でしか使えない。AI の政府は、入植と建設に備えて資金を積む |
| R21 | 政府が借りる仕組み (国債) がない |

## 4. 部門の貸借表と取引表

Godley & Lavoie (2007) の形で書くと、ゲームのお金は次のとおりです。どの行も合計 0 になります。

### 4.1 貸借表 (ある時点の残高)

| | 政府 | 民間 | 先住民 | 運ぶ途中 | 銀行 | 合計 |
|---|---|---|---|---|---|---|
| 預金 (手持ち) | +資金 | +手持ち | +手持ち | +運んでいる額 | −預金の合計 | 0 |
| 貸出 | | −借り | −借り | | +貸出の合計 | 0 |
| 純資産 | 資金 | 手持ち − 借り | 手持ち − 借り | 運んでいる額 | −M₀ | 0 |

M₀ は、試合の始めに政府が持っていた資金 (`START_CREDITS`) の合計。銀行 (始めのお金を出した通貨当局を含む) の純資産は −M₀ で、試合のあいだ変わりません。銀行は貸すと同時に預金を作るので、預金の合計 − 貸出の合計 = M₀ がいつも成り立ちます (`tools/tests/money.js` の「全体」)。

### 4.2 取引表 (1 年の出入り)

| | 政府 | 民間 | 先住民 | 運ぶ途中 | 銀行 | 合計 |
|---|---|---|---|---|---|---|
| 税 | +T | −T | | | | 0 |
| 先住民からの収入 | +N | | −N | | | 0 |
| 建設・維持費・予算 | −G | +G | | | | 0 |
| 交易・朝貢・資金援助・開拓資金・出来事の費用 | ±X | ±(差) | ±(歓待) | ±(途中) | | 0 |
| 利子 | +i·D_政府 | +i·D_民間 − r·L_民間 | +i·D_先住民 − r·L_先住民 | | (受け取り − 払い = 0) | 0 |
| 純貸出 (列の合計) | 資金の増加 | 手持ち − 借りの増加 | 同 | 運んでいる額の増加 | 0 | 0 |

- r は借りた側の星系で効いている国の利子率。i は預金につく率で、i = (受け取った利子の合計) ÷ (預金の合計)。銀行の儲けは 0 にしてある。
- 試験 `money.js` は、行 (種類ごとの合計 0) と列 (帳簿ごとの記帳と額の増加の一致) を毎年確かめます。

## 7. 帰着の表・損の大きさ・行政の遅れ (回 KE8・B-012)

政策を通す手間の 1 段目 (`docs/econ-policy-list.md` の 5・7 の 3 の a)。帰着の表は、回 SE7 (利益集団の支持で政策を通す。B-022) がそのまま使えるように、星系の中の集団 (民族 × 所得の 5 分位。`docs/groups.md`) ごとの損得も出す。コードは `src/economy/incidence.js`、値は `src/economy/fiscal-consts.js` の `INCIDENCE`・`LOSS`・`ADMIN_LAG`、数の出どころは `docs/research/incidence.md`。

### 7.1 帰着の表

`incidenceOf(国, f1, f0)` = 財政を f0 から f1 にしたときの、手段ごとの 1 年の損得 [cr/年]。いまの帳簿の大きさに率の差を掛けた 1 次の近い形で、買い物・輸入・研究の量の変化と、そのあとの景気と物価の動きは入れない。

| 手段 | 家計 | 会社 | 政府 | ほかの国 | 所得の分位への分け方 |
|---|---|---|---|---|---|
| 所得への税 | −(率の差) × 家計の市場の所得 | — | + | — | 所得税の帰着 (上に重い) |
| 消費税 | −(率 × 買い物 ÷ 所得 の差) × 所得 (買い物 ≈ 所得 − 所得への税) | — | + | — | 消費税の帰着 (下に重い) |
| 関税 | −(率の差) × 関税の掛かる輸入 (`gv.mx`。値段を通して家計が負う) | — | + | — | 関税の帰着 (下に重い) |
| 政策金利 | 預金に比べて受け取り − 借りに掛かる差 | 同じ | 政府の資金に比べて受け取り | ほかの国の預金に比べて受け取り | 家計の分は金利の差の持ち高 (上に厚い)、会社の分は持ち主 |
| 研究開発の税額控除 | — | +(率の差) × 会社の研究開発費 (星系に家計の所得に比べて分ける) | − | — | 持ち主 (ほとんどいちばん上) |
| 予算 (機能ごと) | +(割合の差) × 首都の税収 (首都の家計が受け取る) | — | − | — | 福祉・教育は帰着の表、治安・軍事・研究は所得の分け前のまま |

- 部門を足すと 0 (お金は湧かない)。政策金利は、国の中の借り手 (家計・会社) が利子の差を払い、銀行を通してすべての預金の持ち主が預金に比べて受け取る (`interestStep` と同じ分け方。国債の利札は 1 年目は変わらないとみる。先住民は入れない)。銀行は銀河に 1 つなので、国の金利を上げると、ほかの国の預金の持ち主も得をする。
- 会社の分は、星系の家計が持つ分 (1 − 遠くの持ち主の持ち分 `gv.own`) だけ分位に分ける。
- `groupIncidence(星系, f1, f0)` = 星系の集団ごとの損得 `{ k: 民族, q: 分位, v: cr/年, rel: v ÷ 集団の家計の所得, by: 手段ごと }`。民族の間の所得の差は入れていない。
- 画面: 財政の欄の終わりに「帰着 (標準の財政と比べた 1 年の損得)」の表 (決めた財政と標準の財政の差。分位は分位の所得に対する割合)。
- 手元の例 (銀河 3・80 年目の地球の国。税率 20%・消費税 10%・福祉 10%): 所得への税は分位の所得の −2.1% (下) 〜 −6.4% (上)、消費税は −12.1% (下) 〜 −5.5% (上)、福祉は +6.9% (下) 〜 +0.6% (上)。政策金利を 3 点上げると、国の家計 −389・会社 −522・ほかの国 +910 cr/年。関税の掛かる輸入は銀河の全部で年 5 cr ほどと小さく (国の間の交易が少ない)、関税の損は今はほとんど 0。

### 7.2 損の大きさと忠誠・議会

家計の損の割合 ℓ (`policyLoss`。標準の財政と比べた、家計の市場の所得に対する 1 年の損) = 所得への税 (率 − 標準) + 消費税 (率 × (1 − 所得への税率) ÷ (1 + 率)) + 関税 (率 × 関税の掛かる輸入 ÷ 家計の所得。輸入 ÷ 所得は 1 まで)。

- 家臣の忠誠度の目標の「税」の項 = `LOSS.loyalty` × ℓ (= −15 ÷ 15.5%。所得の 1% の損で −0.97 点)。首都の議会の支持 年 `LOSS.council` × ℓ (= −0.5 ÷ 15.5%)。所得への税だけを変えたときは、前の式 (`TAX_LOYALTY` × (k − 1)) と同じ。
- 前と変わったこと: 消費税は、前は所得への税と同じ重さ (率をそのまま足す) と見ていたが、買い物の割合だけ軽くなった ((1 − 所得への税率) ÷ (1 + 消費税率) 倍。所得への税 15.5%・消費税 10% で 0.77 倍)。関税は、前は忠誠と議会に効かなかったが、損として効く。議会は、前は決めた財政で数えていたが、首都で効いている財政で数える。
- 集団の分位の差 (`groupDev`): 前は税の項を所得の分け前に比例させ、福祉の項を下に厚くした。いまは、手段ごとに分位の項 = 星系の項 × φ (φ = 分位の帰着の分け前 ÷ 所得の分け前 を、人口で平均して 1 にしたもの。`incFactor`)。所得への税の φ は下から 0.58・0.64・0.86・1.11・1.80、消費税は 1.43・1.09・0.97・0.86・0.65、関税は 1.19・1.03・0.92・1.01・0.85、福祉は 2.38・1.17・0.74・0.50・0.21。人口で平均すると星系の項のまま (差の平均は 0)。
- 人間でない国は標準の財政 (`AI_FISCAL.vary = 0`) なので、どの項も 0 で、試合の筋は前と同じ。

### 7.3 行政の遅れ

決めてから首都で効くまでの年数を手段ごとに持つ (`ADMIN_LAG`)。遠い星系は、そのうえ知らせが光速で届いてから効く。

| 手段 | 遅れ |
|---|---|
| 所得への税・研究開発の税額控除 | 0.85 年 |
| 消費税の率 | 0.05 年 (新しく入れるときは 1.75 年) |
| 関税 | 0.05 年 |
| 予算 | 0.5 年 |
| 政策金利・中央銀行に任せるか・赤字の上限 | すぐ |

- 財政に、手段ごとの首都で効き始める年 `on` と、いちばん遅い年 `done` を持つ (`setFiscal`。`fiscalFor` は、まだの手段だけ前の値にする)。遅れの途中でほかの手段を変えても、前に変えた手段の効き始めは動かない。前の財政 `prev` は、首都でいま効いている値 (前は決めた値)。
- 前の版のセーブ (`on` がない) は、前と同じく光の遅れだけ。
- 試験: `tools/tests/incidence.js` (帰着の表の足し算・分位・集団・忠誠と議会の式・遅れ・保存と読み込み)。`tools/tests/fiscal.js` は、首都の所得への税が遅れのあいだ前のままであることを見るように直した。

### 7.4 残り

- 政治力の費用を政策の大きさと反対する集団の数で決める (拒否権。`docs/econ-policy-list.md` の 5) は、回 SE7 (B-022) で集団の支持と一緒に。
- 帰着の表を書き出し (`tools/export.js`) に出す。

## 8. 価格統制・配給・輸出禁止・禁輸 (回 KE9・B-008)

| 手段 | 形 | 行政の遅れ | 現実の例 |
|---|---|---|---|
| 値段の上限 (`ceil`) | 資源ごとに、もとの値段 (`basePrice`) の 0.5〜2 倍 (0.05 きざみ)。国の星系の市場の値段は、値段が動いたあとで上限に切られる。上限で足りない分は買えない (不足。需要には数えるので、作る合図にはなる)。闇市は入れない | すぐ | 米国 1971 年 8 月 15 日の 90 日の凍結 (Executive Order 11615。発表の日に効いた) |
| 配給 (`ration`) | 食料・水・工業品だけ。刻みの始めの星系の在庫を入植地の人口に比べて分け、1 つの入植地がそれより多く買わない (配給がないと、先に買う入植地が取り、あとの入植地が飢える) | 0.15 年 | 英国の食料の配給 (1939 年 11 月に発表、1940 年 1 月 8 日に始まる。約 2 か月) |
| 輸出禁止 (`ban`) | 資源ごとに、ほかの国の買い手に売らない (交易の注文を受けない・売り手の候補から外す・入植の資材と高付加価値物品の取り寄せも)。国の中は止めない | すぐ | |
| 禁輸 (`embargo`) | 国ごとに、その国と売り買いしない (両向き) | すぐ | 米国のキューバの禁輸 (1962 年 2 月 3 日に布告、2 月 7 日に効いた。4 日) |

- 選べる資源は 7 つ (`CTL_RES`。食料・水・燃料・金属・希少元素・工業品・高付加価値物品)。自分の国への禁輸と、配給できない資源は断る (`fiscalCtl`)。
- 政治力: 4 つのどれかを変えると、ほかの財政と同じく 5 (`pcCost` の `fiscal`)。
- 議会: 法案の文に「値段の上限 食料 ×0.5・輸出禁止 金属・禁輸 …」と出る (`ctlText`)。輸出禁止と禁輸は、関税と同じく保護を好む集団の値の項で支持が動く (`supportLogit` の `values.tariff`)。値段の上限は帰着の表から集団の損得に入る (下)。
- 帰着の表 (`incidenceOf`。7.1): 値段の上限は、家計が買う物 (食料・水・工業品・高付加価値物品) で、(いまの値段 − 上限) × ふだんの消費 を会社 (売り手) から家計へ移す 1 次の近い形 (分け前は消費税と同じ `ctax`)。原料 (金属・燃料・希少元素) は買い手も会社なので、部門では差し引き 0。不足で買えなかった人の損は入れない。
- 画面: 財政の画面の「価格統制と交易の規制」の表 (`ctlHtml`。資源ごとにいまの値段の倍率・上限・配給・輸出禁止、国ごとに禁輸)。
- 試験: `tools/tests/controls.js` (上限で値段が止まる・配給で入植地が同じ割合だけ買える・輸出禁止はその資源だけ・禁輸は両向き・国の中は止めない・帰着の表の足し算・選べない値・法案・保存と読み込み・人間でない国)。

### 8.1 入れなかったもの

- 公的備蓄 (常平倉・戦略石油備蓄): 政府が物を持つ倉がいまはない (`docs/money.md` の 4.1 の C で選ばなかった)。倉を足すと、物の出入りの試験 (`tools/tests/conserve.js` の種類ごとの出入り) と、星系の在庫を前提にした市場の作りを両方変えることになるので、回 KE9 では入れなかった。価格の下限 (政府が下限で買い取る) も同じ倉が要るので入れていない。
- 闇市: 上限で買えなかった分が、上限より高い値段で売られる道。入れると上限が効かない度合い (現実の価格統制の大きな問題) を数で持てるが、売り手の選び方が二重になるので入れていない。

## 9. 物価の目標・量的緩和・金融抑圧・債務の再編・物価の外れの政治の損 (回 KE9・B-009・QD-27 = b)

`docs/econ-policy-list.md` の 3 の J と 4 (24-3)。帳簿は実質のままなので (`docs/money.md` の 5.1)、物価が上がって債務が軽くなる道は「国債の利札が物価に遅れる分、国債の実質の利子 (利札 − 物価の上がり方) が下がる」だけ。値と出どころは `src/economy/fiscal-consts.js` の `TARGET_RANGE`・`QE_RANGE`・`REPRESS_RANGE`・`QE`・`RESTRUCTURE`・`INFL_LOSS`。どれも人間の国だけが使う (物価の外れの政治の損だけは、どの国の家臣にも効く)。

| 手段 | 形 | 通し方 | 出どころ |
|---|---|---|---|
| 物価の目標 (`pistar`) | 中央銀行の目標 (既定 2%・幅 0〜20%)。中央銀行の則は選んだ目標で決め、物価の上がり方の式と見込みの錨と長期の利回りの錨は、人々が見込む目標 `s.T` (選んだ目標へ年 `CB.theta` = 0.3 の速さで近づく) を使う。国債の利札は借り換え (`CB.roll` = 7 年) で遅れて上がるので、そのあいだ実質の利子が下がる (インフレ税) | 中央銀行の決定と同じくすぐ (議会にかけない。英国では物価の目標を財務大臣が決める) | インフレ税の形は `econ-policy-list.md` の J |
| 量的緩和 (`qe`) | 国の星系の政府の国債のうち、中央銀行が持つ割合 (幅 0〜60%)。中央銀行は `QE.speed` = 1 年かけて買い、持った分 (`gv.qb`) の利子は国に戻る (政府は銀行が持つ分だけ払う)。長期の利回りが `QE.tp` × 中央銀行の持つ国債 ÷ GDP だけ下がり、買い入れ ÷ GDP × `QE.pi` だけ物価の水準が上がる (年 1 で消える上がり方として足す)。政府が国債を返した分は、銀行と中央銀行の持つ分に比べて返したとみる | すぐ | tp 0.042 = 米国の 2008〜10 年の買い入れ (GDP の約 12%) で期間の上乗せが約 0.5 点 (Gagnon ほか 2011 をまとめたカンザスシティ連銀の見方)。pi 0.47 = Weale & Wieladek (2016) の GDP の 1% の買い入れで物価 +0.62% (米国)・+0.32% (英国) の平均 |
| 金融抑圧 (`repress`) | 国の政府の、銀行が持つ国債の利札を repress 点下げる (幅 0〜4 点)。下げた分は国の中の預金者 (星系の政府・家計・会社・先住民) が預金に比べて受け取らない (国の中の預金者がふつうに受け取る額まで)。ほかの国の預金者は変わらない | 法なので議会の審議 (行政の遅れ 0.5 年は仮の値) | Reinhart & Sbrancia (2015): 1945〜80 年の先進国は実質の金利が負の年が約半分、米英の債務は年に GDP の 3〜4% ずつ目減りした |
| 債務の再編 (命令 `restructure`) | 国のすべての星系の政府の、銀行が持つ国債の 25・37・50・75% を払わない (中央銀行の持つ分は減らさない)。不履行 (`sovDefault`) と同じく預金が額に比べて目減りする。利回りの上乗せは払わない割合に比べる (Cruces & Trebesch 2013 の削り 1 点あたりの値。前からの `CB.spread`)。借りられない年数は `CB.exclude` × 割合 ÷ 37% (大きな再編ほど長い、は同じ論文。比例は仮の形)。首都の政府に国債がなくても、国として借りられない間を持つ | 政治力 20 (国家方針と同じ。仮の値)。借りられない間は続けてできない | Cruces & Trebesch (2013) の 1970〜2010 年の 180 件: 半分は 23% 未満か 53% 超・ギリシャ 2012 年 53.5%・アルゼンチン 2005 年 76.8% |

### 9.1 物価の外れの政治の損 (QD-27 = b)

物価の上がり方と 2% の差 1 点を、家計の所得の `INFL_LOSS` = 1% の損と同じに数え、税の損と同じ重さ (`LOSS`。7.2) で家臣の忠誠度の目標 (項「物価の上がり方」) と首都の議会の支持 (年ごと) を下げる。

- 重さの出どころ: Fair の大統領選挙の式 (2012 年の版) で、物価の上がり方 1 点が与党の票 −0.684 点、1 人あたりの成長 1 点が +0.672 点。成長 1 点 ≒ 所得 1% とみると、物価 1 点 ≒ 所得 1% の損。1984 年の版 (物価 −0.34・成長 +1.02) なら 3 分の 1 になる。Fair は物価の上がり方の絶対値で数えるが、ここでは目標 2% からの差にした (QD-27 の b の「目標から離れるほど」)。
- 人間の国が物価の目標を上げても、損は 2% からの差で数える (選んだ目標からの差にすると、インフレ税がただになる)。
- どの国の家臣にも効く。いまの版の物価の上がり方はほとんど 0〜5% なので、AI の国の家臣の忠誠度は 1 点ほど下がるだけ。集団の分位には分けていない (`groupDev` は税の項だけ)。

### 9.2 帰着の表

金融抑圧と量的緩和の行 (`incidenceOf`): 政府が払わなくなる国債の利子 (銀行が持つ国債 × 下げた点数、中央銀行が持つ国債 × 国債の実質の利子) を、国の中の預金者が預金に比べて負う。分け前は政策金利と同じ `rate`。量的緩和の利回りと物価の動きと、物価の目標は入れていない (動きの中の効きなので、1 次の表に乗らない)。

### 9.3 試し (同じ試合の双子。シード 3・40 年目から人間の国が動かす・赤字の上限 5%)

|---|---|
| 何もしない | 国債 ÷ GDP 0.41 → 0 (余った資金で返す)。物価 年 3% ほど |
| 物価の目標 10% | 物価 5.7% (1 年目) → 8% (3 年目) → 10% (10 年目)。長期の利回り 5.3% → 13%。首都の政府は利子を受け取る側になる (利札が物価に遅れる) |

### 9.4 残り

- 量的緩和の物価の押し上げは、小さな買い入れの推定 (GDP の 1%) をそのまま大きな買い入れに伸ばしている。日本銀行のように国債の半分を持っても物価が上がらなかった例もある。
- 中央銀行の儲けと損 (持った国債の値下がり) は入れていない。利子はそのまま国に戻る。
- 再編の政治の損 (政権が倒れやすくなる) は入れていない。政治力と借りられない間だけ。
