# 財政 (段 4 の 2)

`docs/game-plan.md` の段 4 の 2 つめ (セッション 7) です。止めていた財政 (税の段階・利子率・予算。ユーザーの依頼は `docs/requests-log.md` の 121) を、セッション 6 のお金の帳簿 ([money.md](money.md)) の上で作り直しました。あわせて、現実の長い期間のデータ (Jordà–Schularick–Taylor R6) と同じ形でゲームの財政を測り、どこが現実と違うかを表にしました。進め方の頼みは `docs/requests/2026-10-20-C.md` の C-6。

## 1. 財政の中身

| 選ぶもの | 選べる値 | 効き目 (大きさは仮の値。5 の表) | お金の行き先 |
|---|---|---|---|
| 税 | 低い・標準・高い・重税 | 人口あたりの税 ×0.6・×1・×1.4・×1.8。家臣の忠誠度の目標 +6・0・−6・−12。議会の支持 年 +0.2・0・−0.2・−0.5 | 星系の民間 → 星系の政府 (前と同じ) |
| 利子率 | 年 0・1・3・5・8% | 交易の値段 (運ぶ年数ぶんの利子 e^(利子率 × 年数)) と、銀行の貸出の利子 | 下の 2 |
| 予算 (福祉・治安・軍事) | 首都の税収の 0・5・10・20・30% ずつ (合わせて 6 割まで) | 福祉: 忠誠度の目標 +最大 12・人口の増え方 ×最大 1.15。治安: 離反の起きやすさ ×最大 0.6。軍事: 艦隊の戦力 ×最大 1.25 (効き目 = 最大 × 割合 ÷ (割合 + 0.1)) | 首都の政府 → 首都の民間 (給付・給料・買い付け) |

- どれも、変えた知らせが光速で届いた星系から効きます (国家方針と同じ)。税と利子率を変えるには政治力 5 が要り、予算の割り振りには要りません。
- 画面は 帝国 → 目標 の「財政」の欄です。
- 人間でない国は、標準 (税は標準・年 1%・予算 0) のままです。

## 2. 利子 (前の差分からの変更)

前の差分では、政府の貯えに年 1% の利子が**どこからも払われずに湧いていました**。今回は次の形にしました。

1. 銀行から借りている民間と先住民が、その星系で効いている国の利子率で利子を払う (払えない分は、また銀行から借りる)。
2. 銀行は、受け取った利子をすべて、預金 (政府の資金・民間と先住民の手持ち) の額に比べて分ける。銀行の儲けは 0。運ぶ途中のお金には利子がつかない。

利子の種類 (`interest`) も、お金の保存の試験 (`tools/tests/money.js`) で毎年確かめています。

## 3. 現実と同じ形で測る

### 3.1 やり方

1. 生データ: Jordà–Schularick–Taylor Macrohistory Database R6 (18 か国 1870〜2020 年)、Schmelzing (2020) の 1311〜2018 年の世界の実質利子率 (`data/fetch/fetch_fiscal.py` → `data/raw/fiscal/`)。
2. 目標: 税収 ÷ GDP (R19)、政府が黒字だった年の割合 (R20)、政府債務 ÷ GDP (R21)、民間の信用 ÷ GDP (R22)。幅は、ゲームを測る前に、生データの国ごとの値の 10%〜90% 点だけで決めて固定した (#120。`docs/targets.md` の版 4)。
3. ゲームの書き出し: `tools/fiscal-panel.js` が、画面なしの版で銀河を回し、国 (首都と従属星系の政府をまとめた一般政府) ごと・年ごとに、JST と同じ列 (`year, country, gdp, revenue, expenditure, debtgdp, tloans`) のパネルを書き出す。ゲームの中身は変えず、出入りの関数を道具の側で包んで数える。
4. 同じ台本: `data/build/analyze_fiscal.py` を、JST とゲームのパネルの両方にかける。

### 3.2 ゲームの国民経済計算の定義

| 列 | ゲームでの定義 | 現実 (SNA 2008・JST) との違い |
|---|---|---|
| gdp | 資源の付加価値 (採掘・収穫と工業の産出 − 工業の投入。基準価格 `PRICE`) + 政府が民間から買った分 (建設・維持費・予算。費用で測る。市場で売らない政府の産出を費用で測る SNA と同じ) | ゲームには市場の値段がないので、基準価格で測る。捨てた物も産出に入る (市場があれば、売れない物の値段は下がる) |
| revenue | 税 + 先住民からの収入 + 預金の利子 | JST は中央政府の収入 |
| expenditure | revenue − 政府の純貸出 (国の政府の資金の増加)。国の中の朝貢・資金援助・交易は、差し引きで消える | 同じ恒等式 (収入 − 支出 = 純貸出) |
| debtgdp | 政府の総債務 (資金がマイナスの政府のマイナス分) ÷ gdp | ゲームの政府は借りられない |
| tloans | 国の星系の民間と先住民の、銀行からの借り | JST は銀行から民間の非金融部門への貸出 |

### 3.3 結果 (30 銀河 × 150 年 × 6 か国、観戦。財政は標準)

`node tools/fiscal-panel.js panel.csv 30 150 6` → `python3 data/build/analyze_fiscal.py panel.csv`。ゲームの値は、銀河ごとの国のあいだの中央値の、30 銀河の中央値 (かっこは銀河の 10%〜90%)。

| 目標 | 現実の幅 (JST 18 か国) | ゲーム (すべての国) | 判定 | 参考: 始めの 6 か国だけ |
|---|---|---|---|---|
| R19 税収 ÷ GDP | 0.105〜0.263 | 0.021 (0.020〜0.023) | **不合格** (5〜12 分の 1) | 0.019 |
| R20 政府が黒字だった年の割合 | 0.125〜0.561 | 0.651 (0.578〜0.690) | **不合格** (多すぎる) | 0.708 |
| R21 政府債務 ÷ GDP | 0.202〜0.730 | 0 | **不合格** (政府は借りられない) | 0 |
| R22 民間の信用 ÷ GDP | 0.294〜0.785 | 0.0003 (0〜0.17) | **不合格** | 0.363 (幅の中) |

### 3.4 ずれの理由 (1 試合を分けて見た。6 か国・100〜110 年目)

| 目標 | 理由 |
|---|---|
| R19 | 生産の値打ちは年に約 55 万 cr、税は約 1 万 cr。**基準価格 (`PRICE`) と税の大きさ (`BASE_TAX`・人口 × 0.08) が、互いに合わせて決められたことがない。** さらに、ゲームでは生産物はすべて政府の備蓄に入り、人々は代金を払わずに消費する (再分配の経済。ウル第三王朝やインカに近い形。[research/surplus-history.md](research/surplus-history.md) の 1.1・9.3)。生産の 4 割 (年 22 万 cr) は捨てていて、市場があれば値打ちがない物も GDP に入っている (捨てた分を除くと税収 ÷ GDP は約 0.03) |
| R20 | 政府は借りられず、資金の範囲でしか使えない。AI の政府は、入植と建設に備えて資金を積む |
| R21 | 政府が借りる仕組み (国債) がない |
| R22 | 民間の借りは、税を多く取る首都に集まる (地球の首都だけで 13 万 cr)。独立した小さな国 (1 銀河に約 8 か国) は借りがほぼ 0 で、すべての国の中央値を下げている。始めの 6 か国では幅の中 |

預金 ÷ GDP は約 0.47 で、現実 (広い意味のお金 ÷ GDP が 0.5〜1) に近い。

### 3.5 直し方の案 (勝手には直していない。選んでもらう)

| 目標 | 案 | 中身 | 現実との差 | 遊びへの影響 | いつ |
|---|---|---|---|---|---|
| R19 | **a. 市場を入れて、生産物を民間のものにする (おすすめ)** | 生産物は民間が持ち、売り買いする。政府は税で取る。捨てる物は値下がりで値打ちが下がる | 現代の市場経済と同じ形。税収 ÷ GDP は税率から決まる | 大きい (経済の作り直し) | セッション 8 (物価・需要で決まる生産と同じ回) |
| R19 | b. 税を 5〜10 倍にする補正 | `EDITIONS.game` の値。補正の台帳に 1 行 | 比は合うが、理由がない | 政府の資金が 5〜10 倍になる | すぐ |
| R19 | c. 基準価格を下げる | `PRICE` を 1/5 ほどに | 交易の値段も下がる (R01 の較正に響く) | 交易の収支が変わる | すぐ |
| R20・R21 | **d. 政府も銀行から借りられるようにする (国債。おすすめ)** | 資金が足りない政府は、利子を払って借りる。借りの上限は税収の何年分か | 現実の政府と同じ | AI の政府が借りて使うように、支出の決め方も変える | セッション 7 の続き (次の PR) |
| R20・R21 | e. いまのまま | 政府は借りない (近世より前の国家の財宝に近い) | 1870 年以後の国家とは違う | 変わらない | — |
| R22 | **f. いまのまま (おすすめ)** | 大きな国では幅の中。独立した小さな国の扱いは、R19 を直すときに見直す | — | — | — |

### 3.6 利子率の既定値

既定の年 1% は、Schmelzing (2020) の世界の実質利子率 (7 年の平均) の 1950〜2018 年の平均 2.2%・1990〜2018 年の中央値 1.85% より低い。1850〜1913 年は 3.3%、1500〜1699 年は 7.0%。交易と距離 (R01) の較正 ([trade.md](trade.md)) が年 1% を使っているので、いまは変えていない。

## 4. 部門の貸借表と取引表

Godley & Lavoie (2007) の形で書くと、ゲームのお金は次のとおりです。どの行も合計 0 になります。

### 4.1 貸借表 (ある時点の残高)

| | 政府 | 民間 | 先住民 | 運ぶ途中 | 銀行 | 合計 |
|---|---|---|---|---|---|---|
| 預金 (手持ち) | +資金 | +手持ち | +手持ち | +運んでいる額 | −預金の合計 | 0 |
| 貸出 | | −借り | −借り | | +貸出の合計 | 0 |
| 純資産 | 資金 | 手持ち − 借り | 手持ち − 借り | 運んでいる額 | −M₀ | 0 |

M₀ は、試合の始めに政府が持っていた資金 (`START_CREDITS`) の合計。銀行 (始めのお金を出した通貨当局を含む) の純資産は −M₀ で、試合のあいだ変わりません。銀行は貸すと同時に預金を作るので、預金の合計 − 貸出の合計 = M₀ がいつも成り立ちます (`tools/tests/money.js` の「全体」)。

### 4.2 取引表 (1 年の出入り)

| | 政府 | 民間 | 先住民 | 運ぶ途中 | 銀行 | 合計 |
|---|---|---|---|---|---|---|
| 税 | +T | −T | | | | 0 |
| 先住民からの収入 | +N | | −N | | | 0 |
| 建設・維持費・予算 | −G | +G | | | | 0 |
| 交易・朝貢・資金援助・開拓資金・出来事の費用 | ±X | ±(差) | ±(歓待) | ±(途中) | | 0 |
| 利子 | +i·D_政府 | +i·D_民間 − r·L_民間 | +i·D_先住民 − r·L_先住民 | | (受け取り − 払い = 0) | 0 |
| 純貸出 (列の合計) | 資金の増加 | 手持ち − 借りの増加 | 同 | 運んでいる額の増加 | 0 | 0 |

- r は借りた側の星系で効いている国の利子率。i は預金につく率で、i = (受け取った利子の合計) ÷ (預金の合計)。銀行の儲けは 0 にしてある。
- 試験 `money.js` は、行 (種類ごとの合計 0) と列 (帳簿ごとの記帳と額の増加の一致) を毎年確かめます。

## 5. 仮の値 (現実のデータで決めていない値)

前の差分のまま、文献で決めていない値です。補正 (現実からわざとずらした値) ではないので、補正の台帳には載せず、ここに並べます。R19〜R22 を直すときに、一緒に決め直します。

| 値 | いま | 決め方の候補 |
|---|---|---|
| 税の段階の倍率 (`TAX_LEVELS.k`) | 0.6・1・1.4・1.8 | 税率の段階として、現実の税収 ÷ GDP の幅 (R19) から決める |
| 税の段階の忠誠度・議会の支持 | 忠誠度 +6・0・−6・−12、支持 年 +0.2・0・−0.2・−0.5 | 税と反乱・支持の研究 (例: 近世の税の反乱) から |
| 予算の効き目の最大と、鈍り方 (`BUDGET`・`BUDGET_HALF` 0.1) | 福祉 +12・×1.15、治安 ×0.6、軍事 ×1.25 | 政府支出の効き目の研究 (財政乗数・治安と離反) から |
| 利子率の選べる値 (`RATES`) | 0・1・3・5・8% | Schmelzing の時代ごとの幅 (3.6) から |
| 予算の上限 | 税収の 6 割 | 現実の政府支出の構成から |
