## 2. いまの形 (2026-10-20 の main で確かめたこと)

セッション 20 (2026-10-21) で、税・利子率・予算・赤字の上限は現実の幅の中で細かく選べるようになり、AI の国の税率は現実の分布から引くようになりました (`docs/fiscal.md` の 1・`docs/policy-ranges.md`)。下の表の上の 4 行は、その前の形です。

| 手段 | いま (`src/index.html`) | 困ること |
|---|---|---|
| 税 | `TAX_LEVELS` の 4 段階 (低い ×0.6・標準・高い ×1.4・重税 ×1.8)。税の種類は、民間の所得への税 (15.5%。`docs/market.md` の 5) の 1 つだけ | 税率を細かく選べない。消費税・法人税・関税・資産への税などの区別がない |
| 利子率 | `RATES` = 0・1・3・5・8% の 5 つから政府が選ぶ。交易の値段 (運ぶ年数ぶんの利子) と、政府の貯えの利子に使う | マイナス金利も、8% より高い金利も選べない。中央銀行がなく、金利が貸し借り・物価・景気に効く道がない |
| 予算 | `BUDGET_SHARES` = 税収の 0・5・10・20・30% を、福祉・治安・軍事の 3 つに割り振る | 飛び飛び。支出の分け方が 3 つだけ (現実の COFOG は 10 の機能) |
| 赤字の上限 | `DEFICITS` = 0・1・3・5・10% | 飛び飛び |
| 物価 | 星系の市場の値段は、在庫と需要で動く (`docs/market.md`)。国全体の物価指数とインフレ率はない | 金融政策とインフレを扱えない |
| 国債 | 政府は銀行から借りられる。AI の政府は Bohn (1998) の形の式で借りて返す (`docs/debt.md`)。利回りと債務不履行はない | 国債の利回り・信用の危機・債務の再編を扱えない |
| 画面 | 数字の表だけ。経済のグラフはない | 推移や関係が見えない |

## 3. 一流のプロなら、私たちがまだしていないことで何をするか

| 専門 | すること |
|---|---|
| 経済学者 | **政策を変えたときの「反応」を、現実と比べる。** いまは税収 ÷ GDP のような「水準」しか合わせていない。プロは「金利を 1 ポイント上げたら、生産と物価が何年かけてどう動くか」(インパルス応答) を、現実の推定と比べる。政策を遊ぶゲームで大事なのはこちら |
| 金融の専門家 | **中央銀行・物価・利子の期間構造を入れる。** マイナス金利・ゼロ金利の壁・インフレ・国債の利回り・取り付け騒ぎ・国の債務不履行が起きるようにする |
| ゲーム制作者 | **政策の「場」を設計してから作る。** 有名な政策ゲーム (Victoria 3・Democracy 4・Capitalism Lab など) の、政策の選び方と画面を分解して比べる。経済の輪 (何が何を増やし、何が何を減らすか) を図にして、必勝法の輪を先に見つける。値を細かく動かせても、選ぶ意味が残る形にする |
| データアナリスト | **データの設計図 (コードブック) を作る。** 何を、どの単位で、どの粒度 (国・星系・年) で記録するかを決め、ゲームの出力を現実のデータと同じ形の表にして、同じ分析の台本で比べる。グラフは「その画面で何を判断するか」から逆算して選ぶ |
| 政治家 | **政策の勝ち組と負け組と、通す手間を入れる。** どの政策も、だれかが得をして、だれかが損をする。いまは政策を変えるのに政治力を少し払うだけで、利益団体の反発・実施までの遅れ・選挙や正統性への響きがない |
| コンサルタント | **「現実の経済政策のすべて」を、漏れなく重なりなく一覧にする。** 財政・金融・為替・貿易・金融規制・価格統制・国有化・配給・通貨改革・債務不履行などを分類し、効き目と手間の表で、どれをどの順で入れるかを決めてから着手する |

## 4. 出発点にする生の材料

このリポジトリの文書 (`docs/fiscal.md`・`docs/debt.md`・`docs/market.md` など) は、もうかみ砕いたものなので、出発点にしない。値と幅は、次の一次の資料と生データから計算し直す (取得は `data/fetch/` → `data/raw/<名前>/` (MANIFEST.json と README.md つき) → `data/build/` の形)。

- **数え方の決まり (国際基準の手引き)**: 国連の SNA 2008 (国民経済計算)、IMF の GFSM 2014 (政府の財政統計) と COFOG (支出の機能の分け方)、MFSM (金融統計)、BPM6 (国際収支)
- **政策そのものの記録**
  - BIS の中央銀行の政策金利 (国によっては 1946 年から)。実際にあった金利の幅 (マイナス金利から、何十 % の高い金利まで) が分かる。正しい最低と最高は生データで確かめる
  - IMF の iMaPP (金融規制の手段)・AREAER (為替と資本規制)・IFS (国際金融統計)・GFS (政府の財政)
  - OECD の Revenue Statistics (税の種類ごとの税収) と Tax Database (税率)
  - Global Trade Alert (貿易政策の一件ごとの記録)
  - 各国の予算書・法律の条文・中央銀行の議事録 (FOMC の議事録など)
- **政策を変えたときに何が起きたかの記録 (政策のショック)**
  - Romer & Romer (2010): 税の変更を一件ずつ読んで作った記録
  - Ramey (2011): 軍事支出のニュースの記録
  - 金融政策のショック: Romer & Romer (2004)、Jarociński & Karadi (2020)
  - IMF の財政再建の記録 (Devries ほか 2011)
- **危機と長い期間のデータ**: Reinhart & Rogoff (債務不履行・インフレ・銀行危機)、Laeven & Valencia (銀行危機)、Global Macro Database (Müller ほか 2025)、JST Macrohistory (もう `data/raw/fiscal/` にある)
- **分配のデータ**: WID (所得と富の分配)、LIS (家計の調査の個票)
- **ゲーム側の材料**: ほかの政策ゲームの Steam のレビュー (プレイヤーの生の声)、このゲームのプレイ記録 (レーン B のセッション 5 の同意の仕組みのあと)

## 5. 手法と道具

| 用途 | 手法 | 道具 |
|---|---|---|
| 帳簿の整合 | ストックフロー一貫モデル (SFC): 全部門の取引の表と貸借の表を作り、すべての行と列が 0 になることを毎年確かめる | Godley & Lavoie (2007) の型。`tools/tests/money.js` を広げる |
| 政策の反応を測る | 局所射影法 (Jordà 2005)、構造 VAR。同じ台本で、現実のデータとゲームの書き出しの両方を測る。ゲームの側は、画面なしの版で政策を無作為に変える実験で測る (偶然で選ぶので、原因と結果がはっきりする) | Python (statsmodels・linearmodels)、R (lpirfs・fixest) |
| 比べる相手 | 中央銀行の使うモデルのインパルス応答 (Christiano, Eichenbaum & Evans 2005 など) | Dynare |
| 政策の決まり方 | テイラー則 (Taylor 1993) を、現実の金利・インフレ・景気から推定する | 上と同じ |
| 較正 | シミュレーションの積率法、ABC、感度分析 (Sobol)。結果は幅で出す | SALib、`tools/headless.js` の一括実行 |
| 経済の輪の設計 | 資源の流れの図と、輪の点検 | Machinations |
| グラフ | 小さなグラフを並べる (Tufte)。画面ごとに「何を判断するか」から決める (Few) | 自前の Canvas か、組み立てで同梱できる小さな描画のライブラリ (外から読み込まない) |
| 政策の一覧と順番 | 漏れのない分類 (MECE)、効き目と手間の 2 軸の表、KPI の木 | 表計算 |
| 政治 | 利害関係者の地図、だれが払うかの表 (帰着)、拒否権を持つ者の分析 | 文書と表 |

## 6. ほかの専門家がデータを取り出せるようにする

- **現実と同じ形で書き出す**: 国民経済計算 (SNA の形)、政府の財政 (GFS・COFOG の形)、部門ごとの貸借表、値段、交易 (CEPII の BACI の形)、戦争 (COW の形) を、国・星系・年の表 (パネル) で書き出す。経済学者が現実のデータに使っている台本を、そのまま当てられるようにする。列の名前と符号は、できるだけ SNA・GFS・SDMX の符号に合わせる
- **政策の出来事の記録**: 「何年に、どの国が、どの政策を、いくつからいくつに変えたか」を一件ずつ残す (Romer & Romer の記録と同じ形)。政策の効き目を、外の人が自分で推定できる
- **コードブック**: すべての列の意味・単位・出典を書いた説明書
- **再現できる一括実行**: 「この設定・このシード・この政策で、N 個の銀河を回して書き出す」を、画面なしの版で、設定のファイル 1 つで動かせるようにする。分析の例 (ノートブック) も付ける
- **ゲームの中の「データを書き出す」ボタン**: CSV で書き出し、ゲームの版・シード・設定も一緒に入れる。プレイヤーの記録を外に出すときは、同意の仕組み (レーン B のセッション 5) を通す

## 7. 頼み (そのまま)

```text
レーン C の最後 (セッション 9 のあと) に続ける。docs/econ-policy.md の 2〜6 を材料にする。

■ ねらい
このゲームの経済を、「現実の経済政策で実際に行われたことを、すべて行える」ものにする。数字の表だけでなく、グラフで状況が分かるようにする。経済学者・金融の専門家・データアナリスト・政治家・コンサルタント・ゲーム制作者の一流のプロが見ても、手を抜いていないと言える水準にする。

■ いまの不満 (直すこと)
- 税・利子率・予算・赤字の上限が飛び飛び (利子率は 0・1・3・5・8% だけ、予算は 0・5・10・20・30%)。マイナス金利も、30% のような高い金利も選べない。
- 中央銀行・国全体の物価とインフレ・国債の利回りがない。
- 数字の表ばかりで、グラフがない。

■ 進め方 (この順。各段は小さな PR にし、試験と CI を通してからマージ)
1. 一覧を先に作る (コードはまだ変えない)
   - 現実に行われた経済政策を、漏れなく重なりなく分類した一覧を作る。財政 (税の種類・支出の機能 COFOG)・金融政策 (政策金利・準備率・量的緩和・マイナス金利・為替介入)・為替と資本規制・貿易 (関税・数量制限・補助金)・金融規制 (自己資本・LTV など)・価格統制・配給・国有化と民営化・通貨改革・債務の再編と不履行・金融抑圧。
   - 材料は、かみ砕いた解説ではなく一次の資料にする (docs/econ-policy.md の 4)。
   - 政策ごとに「現実に使われた値の幅 (いちばん低い・高い例と出典)」「ゲームで入れる形」「入れる手間」「遊びへの効き目」を書き、効き目と手間の表で順番の案を作る。
   - 政策の勝ち組と負け組 (だれが得をし、だれが払うか) と、通す手間 (反発・実施の遅れ・正統性への響き) をどう入れるかの案も書く。
   - 有名な政策ゲーム (Victoria 3・Democracy 4・Capitalism Lab など) の、政策の選び方と画面を比べた表を付ける。
   - この一覧を Artifact で見せて、どれを入れるか・どの順にするかを私に選ばせる。
2. 値の幅を現実に合わせる
   - 選べる値は飛び飛びにせず、現実に使われた幅の中で細かく選べるようにする (例: 政策金利は BIS の記録の最低から最高まで)。幅は生データから計算し、目標の PR と同じく先に固定する。
3. 帳簿を全部門にする (ストックフロー一貫)
   - 家計・会社・銀行・中央銀行・政府・ほかの国の部門を持ち、全取引の表と貸借の表のすべての行と列が毎年 0 になることを試験で確かめる。
   - 物価の水準とインフレ、政策金利から利回りまでの期間構造、国債の利回りと債務不履行の危険を入れる。
4. 政策の「反応」を現実と比べる
   - 金利・税・支出・関税を変えたときに、生産・物価・雇用・債務が何年かけてどう動くかを、局所射影法で、現実のデータ (Romer & Romer、Ramey、金融政策のショックの記録) とゲームの書き出しに、同じ台本で当てて比べる。合わせる目標として先に登録する。ゲームの側は、画面なしの版で政策を無作為に変える実験で測る。
   - 中央銀行の決まり方は、テイラー則を現実から推定して、AI の国の中央銀行に使う。
   - 値の決め方は、積率法か ABC と感度分析 (Sobol) で行い、結果を幅で出す。
5. グラフ
   - 画面ごとに「プレイヤーがそこで何を判断するか」を先に決め、そのためのグラフだけを作る (小さなグラフを並べる形を基本にする)。
   - 少なくとも: 生産と物価と失業の推移・金利と利回りの曲線・政府の収支と債務・部門ごとの貸借・交易の流れ・政策を変えた時点の印。光の遅れのぶん古い情報は、古さが分かるように描く。
   - 描画は外から読み込まずに入れる。配色はスキン 6、画面は Xiaomi Pad 8 Pro の横と縦で確かめる。
6. 1 で選んだ政策を入れる
   - 1 の表の順に、まとまり (金融政策・税の種類・支出の機能・貿易と為替・金融規制・価格統制と配給・国有化・通貨改革と債務の再編 など) ごとに入れる。
   - 入れるたびに、4 のやり方で反応を確かめ、5 のグラフに足す。
7. 外の専門家がデータを取り出せるようにする
   - 国民経済計算 (SNA の形)・政府の財政 (GFS・COFOG の形)・部門ごとの貸借表・値段・交易 (BACI の形) を、国・星系・年の表で書き出す。
   - 政策の出来事の記録 (何年に、どの国が、どの政策を、いくつからいくつに) を一件ずつ残す。
   - すべての列の意味・単位・出典を書いたコードブックを付ける。
   - 設定のファイル 1 つで「この設定・シード・政策で N 個の銀河を回して書き出す」を画面なしの版で動かせるようにし、分析の例を付ける。
   - ゲームの中に「データを書き出す」ボタンを付ける (版・シード・設定も入れる)。プレイヤーの記録を出すときは、レーン B の同意の仕組みを通す。

■ 決まり
- 「現実的」と「面白い」がぶつかる所は勝手に決めず、ずらす量と理由の表にして私に選ばせる。私が選んだものは補正の台帳に載せる。
- セッションの分け方は docs/econ-policy.md の 8。1 の一覧を見せたところで、私の選んだ政策と順番に合わせて、分け方を選び直してよい。
```

## 9. 決まりと、ほかのレーンとの突き合わせ

- **進め方は、ほかの段と同じ** (`docs/sessions.md` の 2): 生データ → 目標の固定 → 補正なしで作る → 測る → 困ったら補正を台帳に。目標を変える PR は 1 本ずつ (`docs/parallel.md` の 3)。
