# 合わせる目標 (事前登録)

調整を始める前に、「どの実データのどのパターンに、どの範囲で合えば合格か」を決めて固定したものです。
正本は [`targets/targets.json`](../targets/targets.json) で、このページはその説明です。
固定したときのハッシュは [`targets/targets.lock`](../targets/targets.lock) にあります。`node tools/check-targets.js` で、固定したときから書き換わっていないかを確かめられます。

## 決まり

1. **書き換えは専用の PR で行う。** 目標を変えるのは「目標の変更」だけの PR にし、理由を書きます。関係する調整の結果を見る前に行い、`node tools/check-targets.js --lock` で固定し直します。
2. **幅は生データだけから決める。** 合格の幅がまだ決まっていない目標 (表の「幅」が「生データから」のもの) は、取得スクリプトで生データの統計量を計算した時点で、その結果だけから幅を書き込んで固定します。シミュレーションの結果を見てから幅を決めてはいけません。
3. **確認用のデータは較正に使わない。** 「確認用」(holdout) の目標は、パラメータの推定や調整に使わず、合否の確認だけに使います (標本外検証)。
4. **同じ形式・同じコードで比べる。** 自動対戦の結果を実データと同じ形式で書き出し、実データと同じ統計コードで合否を計算します。
5. **1 試合では判定しない。** シミュレーションの統計量は、別々の銀河 (シード) を 30 以上回した分布で評価します。
6. **楽しさは見知らぬ人で測る。** 楽しさの目標は、作者とこの会話の参加者以外の試遊者のデータでだけ判定します。ただし、データが自動対戦の目標 (F06・F16〜F19) は、そこに書いたボットと銀河の数で判定します (版 12)。
