## 2. いまの形 (2026-10-20 の main で確かめたこと。`docs/governance.md`・`src/index.html` の `REGIMES`)

- 統治体制は 6 種類: 直接統治・間接統治・封建制・連邦制・自治領・エンコミエンダ制。違いは、離反の倍率・遅れへの敏感さ・朝貢・忠誠度の目標・**自治の度合い (0〜4 の 1 本の物差し `rank`)**・独立が戦争になる確率と、指令への従い方。
- 一部の係数は歴史の生データから推定した (COLDAT の英仏の植民地・ICOW。`docs/reality-check.md`)。封建制・連邦制・自治領の倍率は仮の値。
- AI の国の統治体制は、国号から決めている (帝国 → エンコミエンダ制など)。現実の根拠はない。
- 従属国は忠誠度などの数字で動き、現地のエリートは交渉の相手として出てこない。

## 3. 歴史学のプロなら、私たちがまだしていないことで何をするか

- **「従属」を 1 本の物差しにしない。** 主権を束に分ける: 外交・軍事・課税と朝貢・法と裁判・統治者の任免・交易・宗教と文化・継承。それぞれをだれが握っているかで見る (Lake 2009 の上下関係、Burbank & Cooper 2010 の「帝国の手札」、Doyle 1986)。
- **当時の言葉と、法と実態の差を分ける。** 冊封・宗主権・保護・委任統治・藩王国の「至上権 (paramountcy)」などは、その時代と地域の言葉。条約の文 (法) と実際の力関係 (実態) はよくずれる。条約のない「非公式の帝国」(Gallagher & Robinson 1953) もある。
- **言葉そのものが論争中だと示す。** 「封建制」は Ganshof の古典的な定義に対し、Reynolds (1994) が「封と家臣の一般像は史料に合わない」と批判した。Fairbank の「中華世界秩序 (朝貢体制)」の型も強く見直されている。型を確定したものとして出さず、論争ごと示す。
- **従属させられた側の主体性を入れる。** 現地のエリートは、協力・取引・裏切りで従属の形そのものを決めていた (Robinson 1972 の「協力者」の理論)。
- **移り変わりを見る。** 保護国 → 併合 (韓国 1905 → 1910)、自治領 → 独立 (ウェストミンスター憲章 1931)、委任統治領 → 独立 (イラク 1932)。型は止まったものではなく道筋。「最後は独立する」という目的論を避ける。
- **ゲームが何を単純にしたかを書く。** 型ごとに「現実はこうで、ゲームはここを省いた」という注をつける。

## 4. 出発点にする生の材料

このリポジトリの文書 (`docs/governance.md` など) は、もうかみ砕いたものなので、出発点にしない。

- **条約と法の本文 (一次史料)**
  - Aitchison『インドの条約・約定・サナド集』(藩王国との従属同盟の条約の原文集)
  - バルドー条約 (1881)・マルサ条約 (1883、チュニジア)、フェズ条約 (1912、モロッコ)、英埃共同統治協定 (1899、スーダン)
  - 国際連盟規約 第 22 条と各委任統治の文書、常設委任統治委員会の議事録 (国際連盟の文書庫。デジタル化されている)
  - 1926 年の帝国会議の報告 (バルフォア報告書)、ウェストミンスター憲章 (1931)
  - 日韓の諸条約 (1905・1910)、自由連合盟約 (米国とミクロネシア連邦など)
  - オスマン帝国の ahdname (恩恵の約定)
  - 明・清の実録、『大清会典』と理藩院の則例、『朝鮮王朝実録』の冊封と朝貢の記事
- **文書館**: 英国国立公文書館 (植民地省 CO・外務省 FO)、仏の海外公文書館 (ANOM)、オスマン文書館、中国第一歴史档案館、国際連盟の文書庫 (ジュネーヴ)
- **データセット (生の符号化データ)**
  - International System(s) Dataset (Griffiths & Butcher 2013): ヨーロッパ型でない国家や従属的な政体も入った、1816 年からの国家の一覧
  - COLDAT・ICOW の植民地の歴史 (もう `data/raw/history/` にある)、COW の植民地と従属の隣接データ
  - Seshat の符号化された変数 (コードブックごと)
  - Lake の上下関係の指標 (軍事基地・為替の制度・交易の依存)
- 取得は `data/fetch/` → `data/raw/<名前>/` (MANIFEST.json と README.md つき) → `data/build/` の形。史料の本文は、出典 (版・頁・文書番号) を必ず残す。

## 5. 手法と道具

| 手法 | 中身 |
|---|---|
| 史料批判 | だれが、何のために書いたか (外的・内的批判)。条約の文と実際を突き合わせる |
| 理念型による類型づくり | Weber の理念型。現実の事例は型の混ざりものとして置く |
| 概念史 | 「宗主権」「保護」などの言葉が、いつ、だれに、どう使われたか (Koselleck) |
| 比較史 | 地域と時代をまたいで、同じ問いで比べる (Bloch) |
| 事例の符号化 | 事例を主権の束の項目ごとに符号にする。2 回別々に符号化し、一致の度合い (Krippendorff の α) を測る |
| 生存分析 | 型ごとに、何年続いたか・どの型へ移ったかを測る (いまの Cox モデルを広げる) |
| 質的比較分析 (QCA) | どの条件の組み合わせが、独立・併合・存続につながったか (Ragin) |
| 過程追跡 | 1 つの事例の中で、原因から結果への道筋を史料で確かめる |
| ネットワーク分析 | 朝貢・冊封の結びつきを網の目として見る |
| 反実仮想の決まり | 「もし〜なら」を考えるときの決まり (Tetlock & Belkin 1996) |
| 道具 | Zotero (文献)・Tropy (文書館の写真)・Nodegoat と Palladio (網の目と年表)・QGIS (地図)・R (survival・QCA) |

## 6. 頼み (そのまま)

```text
レーン H として進める。docs/vassal-history.md の 2〜5 を材料にする。統治体制 REGIMES・離反・朝貢・独立の戦争に触るので、持ち分けは docs/vassal-history.md の 8 に従う。画面はレーン U の決まりに合わせる。

■ 進め方 (この順。各段は小さな PR にし、試験と CI を通してからマージ)
1. 類型の案を作る (コードはまだ変えない)
   - 「自治の度合い」の 1 本の物差しをやめ、主権の束 (外交・軍事・課税と朝貢・法と裁判・統治者の任免・交易・宗教と文化・継承) を、項目ごとに「宗主が握る・分け合う・従属国が握る」で持つ形にする案を作る。
   - 歴史の型 (冊封朝貢国・保護国・藩王国・自治領・委任統治領 A/B/C・共同統治・特許会社領・傀儡国・衛星国・自由連合・封臣・同君連合・緩衝国・いまの 6 種類 など) を、その組み合わせとして書く。型ごとに、当時の言葉、法と実態の差、代表の事例、一次史料の出典、研究者の論争 (例: 封建制をめぐる Ganshof と Reynolds、Fairbank の朝貢体制とその批判)、ゲームで省くことを書く。
   - 材料は、かみ砕いた解説ではなく一次史料と生のデータにする (docs/vassal-history.md の 4)。
   - この案を Artifact で見せて、どの型を入れるかを私に選ばせる。
2. 事例のデータを作る
   - 型ごとに事例を集め、主権の束の項目で符号化する (史料の出典つき。2 回別々に符号化して、一致の度合いを測る)。続いた年数・移った先の型・独立が戦争を伴ったかも入れる。
   - 型ごとの存続と移り変わりの速さを生存分析で推定し、合わせる目標として先に登録する。
3. ゲームに入れる
   - 主権の束を持つ従属国にし、項目ごとに交渉で変えられるようにする。現地のエリートが受け入れたり抵抗したりする (レーン D の集団と合わせる)。
   - AI の国の型は、国の名前ではなく、歴史の研究で効くと分かっている条件 (地理・力の差・文化の近さなど) から決める。
   - 2 の目標で測り、合わないところは理由を書く。
4. 考察の道具
   - ゲームの中に、型ごとの「史料」の欄 (事例・出典・論争・省いたこと) を作る。
   - 同じ銀河で型だけを変えて比べる実験と、従属関係の記録の書き出し (レーン C のセッション 25 と同じ形) を用意し、コードブックと、ゼミで使える問いの例を付ける。

■ 決まり
- 「現実的」と「面白い」がぶつかる所は勝手に決めず、ずらす量と理由の表にして私に選ばせる。選んだものは補正の台帳に載せる。
- セッションの分け方は docs/vassal-history.md の 7。1 の案を見せたところで、私の選んだ型に合わせて、分け方を選び直してよい。
```

## 8. 決まりと、ほかのレーンとの持ち分け

- **進め方は、ほかの段と同じ** (`docs/sessions.md` の 2): 生データ → 目標の固定 → 補正なしで作る → 測る → 困ったら補正を台帳に。目標を変える PR は 1 本ずつ (`docs/parallel.md` の 3)。
- **シミュレーション版は一旦無視する** (`docs/parallel.md` の 6)。
- **光の遅れ**: 交渉と型の変更は光速の指令のまま (届くまで遅れる)。史料の欄と画面の値は、首都に届いている記録 (`known`) から作る。
- **持ち分け**:
  - **H が持つ**: `REGIMES` と統治体制の画面、離反のハザードの式 (`docs/governance.md`)、AI の国の統治体制の決め方。
  - **D (セッション 11) と分ける**: D の 11 は集団を入れ、R08 を較正し直す (`docs/status/Q.md`・`docs/proposals/`)。離反の式は H と D の両方が触るので、**H3 と D の 11 は同時に動かさない**。後から来たほうが、先の形に合わせる。現地のエリートは D の集団を使う。D の 11 がまだなら、H3 では現地のエリートを 1 つの行為者として入れ、D の 11 で集団に合わせる。
