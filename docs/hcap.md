# 学歴と生産性 (人的資本。回 KE5・B-117)

ユーザーの依頼 (2026-10-24、`docs/requests/2026-10-24-KE.md` の KE-6・KE-7):「学歴とか生産性とか」。政治の回 SE6 (星系の中の集団) とは別に、経済で、輸送船の次に入れる。

## 1. 現実の目標 (目標の版 18)

作る前に固定した (`docs/targets.md` の 決まり 1・2)。生データは世界銀行 EdStats の Barro–Lee の推計 (`data/README.md` の「学歴 (就学年数) のデータ」)。

| 目標 | 統計量 | 中央値 (低い方から) |
|---|---|---|
| R62 就学年数と所得 | 所得 (2021 年の国際ドル) の 5 分位ごとの、25 歳以上の平均の就学年数の 25%〜75% 点 (141 か国・702 国・年。1990〜2010 年) | 3.06・5.49・7.23・9.30・9.91 年 |
| R63 就学年数の伸び | 10 年の伸び (年あたり) を、初めの就学年数 (0〜2・2〜4・4〜6・6〜8・8〜10・10 年〜) で分けた区分ごとの 25%〜75% 点 (144 か国・720 組。1960〜2010 年) | 0.053・0.098・0.118・0.114・0.110・0.066 年/年 |

- R62 は「豊かな国ほど長く学校に通う」こと、R63 は「就学年数は世代が入れ替わる速さでしか変わらず、中ほどの国でいちばん速く伸び、下がることはまれ」なことを見る。
- ゲームの年齢は 1 世代の比 (100 ÷ 28 = 3.57 倍) で延ばしてある (R36 と同じ。台帳の C01) ので、世代の入れ替わりで決まる就学年数の伸びも 3.57 倍ゆっくりになる。R63 はゲームの年を現実の年に直して比べる (パネルの列 t = ゲームの年数 × 28 ÷ 100。t の 0・10・20… の値は補間する)。
- ゲームの曲線の材料として、学校を出たばかりの世代 (25〜29 歳) の就学年数と所得の当てはめも出した: 就学年数 = 14 ÷ (1 + exp(−(−5.883 + 0.711 ln y)))、y は 2011 年の国際ドル (R² 0.59。200 ドルで 1.5 年、5,000 ドルで 7.6 年、60,000 ドルで 12.2 年)。`data/derived/hcap.json` の game。

## 2. 作り (`SCHOOL`。`economy/demography-consts.js`・`economy/demography.js`)

| | 中身 | 値の出どころ |
|---|---|---|
| 持ち方 | 入植地ごとに **集団ごと × 5 歳の区分ごと** の人数と平均の就学年数と学力 (`c.edu = { 鍵: { p: [21], s: [21], q: [21] } }`。学力は 4)。区分は年齢の表 `c.age` と同じで、人数の合計を `c.age` に合わせる。就学年数を持つのは 25 歳の区分から上 | 年齢の表 (回 KE2) |
| 学校を出る世代 | 25〜29 歳の区分に入る人の就学年数 = 14 ÷ (1 + exp(−(−5.883 + 0.711 ln y + 0.0594 × 予算の教育の支出 ÷ GDP [%])))。y は市場で測った 1 人あたりの実質の所得を 5 年でならしたもの (`c.incU`。4 の PR で直した。前は生産力 `c.inc`) | EdStats の 25〜29 歳 (1.)・教育の支出の当てはめ (下) |
| 年をとる | 年齢の表と同じ割合で次の区分へ移る。お年寄りの区分ほど就学年数が短いので、世代の入れ替わりで大人の平均が伸びる | |
| 始めからある入植地 | 年上の区分ほど、学校を出たころの所得が年 4.5% ずつ低かったとみて、上の曲線で区分ごとに決める | EdStats の 5 歳ごとの区分 (7,722 組) に当てた値。所得の 4 つの区分で、区分ごとの就学年数をほぼ再現する |
| 入植者・移民 | 出た星系 (入植者は送り出した星系のいちばん大きい入植地) の区分ごとの就学年数を持って来て、「よそ生まれ」に入る (移民の年齢の形で) | |
| 生産性 | 働く人 (25〜64 歳) の exp(φ(s)) の平均 ÷ exp(φ(8.49)) (4 の PR で、s を学力で直した就学年数にした)。φ は就学 1 年あたりの収益の折れ線 (4 年まで 0.134、8 年まで 0.101、その先 0.068)。どの部門の 1 人あたりの産出 (`yieldOf`) にも掛ける。8.49 年は地球の始めの値 (地球の生産性は始めのまま) | Psacharopoulos 1994 (Penn World Table の人的資本の指数と同じ形) |
| 予算の「教育」(新しい予算の項目) | 人間の国の首都が、税収 × 割合を払う (家計へ。お金の種類 `education`)。国の中の入植地の若い世代の曲線を、教育の支出 ÷ GDP [%] × 0.0594 だけ logit でずらす (光の遅れのある財政の値で)。曲線そのものが現実のふつうの国 (支出の中央値 GDP の 4.2%) のものなので、予算はその上に足す分 | EdStats の教育の支出 (SE.XPD.TOTL.GD.ZS) の 5〜20 年前の平均と、ln y を一緒に当てた傾き (131 か国・488 組。国を引き直す 5%〜95% 点 0.027〜0.126) |
| 親の世代の効き (rho) | 0 (若い世代の就学年数は、所得と教育の支出だけで決まる) | R63 の伸びの速さに合わせた (8 銀河で、0 なら 8〜10 年の区分の伸び 0.090、0.3 で 0.072、0.6 で 0.047。幅は 0.078〜0.154) |

- 予算の教育の効き方は、データのとおり小さめ: 首都で税収の 60% (GDP の 13%) を使うと、若い世代の就学年数が 11.4 → 12.0 年、100 年で大人の平均が +0.2 年・生産性が +2%。豊かな首都は上限 (14 年) に近いので伸びる余地が少なく、貧しい入植地ほど効く。就学年数は学校に通った長さだけで、学んだ中身 (学力。Hanushek & Woessmann) は数えない (4 で学力を足した)
- 試してやめたこと: 大人の就学年数を年齢によらず 1 つで持つ形 (8 銀河で、伸びが ρ = 0 でも 0.047 と遅すぎた。お年寄りが亡くなって入れ替わる分が出ない)

### 2.1 あとで SE6 (星系の中の集団) と混ぜられるように (ユーザーの依頼 2026-10-24)

SE6 の決まった案は「階層 5 (所得の 5 分位) × 民族 (種族と、本国生まれ / 入植地生まれ) × 価値観 2 軸」(`docs/proposals/11-groups.md`)。学歴はこれに合わせられる形で持つ:

- 表の鍵はいまは**生まれ** (`away` = よそ生まれ (入植者と移民) / `here` = ここ生まれ)。南北アメリカの本国生まれと入植地生まれ (クリオーリョ) の差と同じ区分。SE6 は鍵に階層と価値観を足して表を細かくできる (それぞれの集団が `{ p, s, q }` を持つ。人数の合計は `c.age` に合わせる)
- 生産性と平均は、表を人数で重みづけて出す (`schoolK`・`schoolMean`)。表を細かくしても、決め方は変わらない
- 読む関数: `schoolBy(c)` (集団ごとの表)・`schoolOf(c)` (大人の平均)・`schoolAges(c)` (区分ごとの平均)・`schoolMean(c, f, 区分の始め, 区分の終わり)` (f は就学年数と学力を受け取る)・`learnOf(c)`・`learnAges(c)`・`eduAges(c)` (学力。4)。表の読み方と鍵の決め方は `docs/notices/SE/2026-10-24-KE-school.md`
- 階層 (所得の 5 分位) ごとの就学年数の差は、この回では作らない (国の中の学歴の不平等のデータ (Thomas, Wang & Fan 2001 の学歴のジニ係数など) を、SE6 で集団を作るときに使う)

- **R62・R63 が合格しない理由**: どの入植地も、地球と同じ学校に通った入植者から始まる。貧しい入植地 (所得 5,000 ドル未満) の就学年数は 9〜10 年のままで、現実のこの所得の国 (2〜8 年) より長い。開拓の星系が貧しいのは学歴ではなく、資本・工業・原料・交易が足りないから (`docs/regions.md`。次の「投資の行き先と原料の手配」で見る)。R63 は、就学年数の短い入植地がないので、比べられる区分が 2 つしかない (比べられた 2 つは幅の中)
- **R34 が外れた理由**: 就学年数の収益を 0 にした版 (生産性が変わらない) では 0.0121 で main と同じなので、学歴による生産性の伸びのせい。中央銀行の景気のずれ (`speedGap` = 1 年の伸び − 5 年の伸び) は、伸びがだんだん遅くなると負になる。学歴の伸びは就学年数が上限に近づくにつれて遅くなるので、ずれがいつも少し負になり、政策金利が低め (中立の金利より約 1.35 点下。main は約 0.87 点) に出て、長期と短期の差が開いた。中立の金利 (`CB.rstar`) を伸びに合わせて動かす (Laubach & Williams 2003 の形) と直る見込み。中央銀行の作りの変更なので、この回では直さず残りにした (`docs/status/KE.md`)
- 所得の差 (`tools/region-gap.js`、8 銀河): 総人口 94,802 → 103,786 百万人、首都の所得 (人口の重みの平均) 91,244 → 130,276 ドル、首都でない入植地の所得の中央値 169 → 225 ドル、国の中の β 収束 年 1.89% → 1.97%。首都の大人の就学年数は 150 年で 7.7 → 約 10.5 年、働く人の生産性は約 1.2 倍

## 4. 学力 (目標の版 19。ユーザーの決定 2026-10-24「学力も効く形を足す」。`docs/requests/2026-10-24-KE.md` の KE-10)

就学年数 (学校に通った年数) だけでは、同じ年数で学んだ中身の差が入らない。現実では、国際的な学力の試験の点数は国の所得と強く結びつき、点数の差は就学年数より所得の差をよく説明する (Hanushek & Woessmann 2012・Angrist ほか 2021)。

### 4.1 現実の目標 (作る前に固定した)

生データは世界銀行 Human Capital Index の調和された試験の点数 (HD.HCI.HLOS。PISA・TIMSS・PIRLS と地域の試験を同じ物差し (300〜625 点) にそろえたもの。Patrinos & Angrist 2018。`data/README.md` の「学歴 (就学年数) と学力のデータ」)。

| 目標 | 統計量 | 中央値 (低い方から) |
|---|---|---|
| R64 学力と所得 | 所得 (2021 年の国際ドル) の 5 分位ごとの、試験の点数の 25%〜75% 点 (170 か国・595 国・年。2010・2017・2018・2020 年) | 368.2・388.1・419.0・485.4・517.2 点 |

- 試験の点数は学校に通う子どもの学力なので、ゲームでは学校を出る世代 (年齢の区分の 25〜29 歳に入った人) の学力と比べる。
- ゲームの曲線の材料として、点数と所得の当てはめも出した: 点数 = 300 + 325 ÷ (1 + exp(−(−6.834 + 0.675 ln y)))、y は 2011 年の国際ドル (R² 0.61。200 ドルで 312 点、5,000 ドルで 382 点、60,000 ドルで 509 点)。前の 10 年の教育の支出 (GDP 比) を足すと、支出 1% あたり logit +0.056 (国を引き直すブートストラップの 5〜95% 点 0.005〜0.109)。教育の支出を GDP の 1% 増やすと、5,000 ドルの国で約 +3 点 (所得 2 倍で約 +32 点。就学年数への効き (2) と同じく小さい)。`data/derived/hcap.json` の game の learn。

### 4.2 作り (`LEARN`。`economy/demography-consts.js`・`economy/demography.js`)

| | 中身 | 値の出どころ |
|---|---|---|
| 持ち方 | `c.edu` の集団ごとに、区分ごとの平均の学力 `q` を就学年数 `s` と並べて持つ (`{ p, s, q }`)。人数で混ぜる決め方は就学年数と同じ (`eduAdd`)。前の版のセーブの集団には、所得の形の学力を足す | |
| 学校を出る世代 | 学力 = 300 + 325 ÷ (1 + exp(−(−6.834 + 0.675 ln y + 0.0561 × 予算の教育の支出 ÷ GDP [%]))) | HCI の試験の点数の当てはめ (4.1) |
| 学歴と学力を決める所得 y | 市場で測った 1 人あたりの実質の所得 (`incomeUSD`。R10・R62 と同じ) を、刻みの終わりの値で 5 年ならしたもの (`c.incU`)。2 の就学年数もこの所得にした | |
| 始めからある入植地 | 就学年数と同じく、年上の区分ほど学校を出たころの所得が年 4.5% ずつ低かったとみる | 2 の cohort |
| 入植者・移民 | 区分ごとの就学年数と学力を運ぶ (`eduAges`) | |
| 生産性 | 働く人 (25〜64 歳) の exp(φ(s × q ÷ 625)) の平均 ÷ exp(φ(5.6))。s × q ÷ 625 は世界銀行の Human Capital Index の「学力で直した就学年数」(LAYS)。5.6 は地球の始め (最初の刻みのあと) の値 (前の 8.49 と同じ決め方。地球の生産性は始めのまま) | Kraay (2019)・Filmer ほか (2020) |

- **学歴を決める所得を直した理由**: 前は生産力 (`c.inc`。設備を全部動かしたときの付加価値を基準の値段で測ったもの。売れ残りを数えない) で決めていた。需要が足りず貧しい開拓星系 (測った所得 200 ドル) でも、生産力は数万ドルあるので、豊かな国の学歴と学力になっていた (R62 の貧しい分位が 10 年、試験の点数が 530 点)。現実の学歴と学力は、測った所得 (GDP) と結びついている (4.1 と 1 の当てはめも、測った所得で当てた)。
- 刻みの途中の所得でならすと、刻みの終わりの値の約 2 倍に出た (値段と量の 2 刻みの振れがそろう)。ならすのは刻みの終わりの値にした (パネルの所得と同じ測り方)。
- **測り方の直し** (`tools/hcap-panel.js`): 1 人あたりの所得を、年の終わりの 1 刻みでなく、その年の 4 つの刻みの平均にした (R38 の地域のパネルと同じ。`docs/regions.md` の 5.1)。1 刻みだけ所得が大きく下がる年があり、5 年でならした所得で決まる学歴・学力と比べると、貧しい分位に豊かな入植地が入っていた。
