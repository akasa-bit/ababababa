# 目標の幅の案 (レーン Q のセッション Q2)

後の回で固定する目標の幅の**案**です。`targets/targets.json` は変えていない。固定は、その段のセッションが「目標の変更」の PR で行う (`docs/parallel.md` の「レーン Q の決まり」)。番号 (R28〜) も、固定するときに、ほかのレーンの開いている目標の PR (例: #126 の R27) と重ならないように決める。

### 案 B. 人口転換 (出生率の所得弾力性)

ln (合計特殊出生率) を ln (1 人あたり所得) に当てはめた傾き (年の固定効果つき): **-0.327** (国のブートストラップの 5%〜95%: -0.355〜-0.301)。
ブートストラップの幅は観測が多いので狭い。ゲームは国 (星系) が少ないので、合格の幅は「推定値 ±50% (-0.49〜-0.16)」をおすすめにする (R11 と同じ形)。

### 案 C. 1 世代の長さ (台帳の C01 の確かめ)

出産の平均年齢 (WPP、2023 年) の所得の分位ごとの中央値:
1,033 ドル〜 29.1 歳 / 5,325 ドル〜 28.6 歳 / 13,117 ドル〜 28.4 歳 / 23,564 ドル〜 29.2 歳 / 47,649 ドル〜 31.4 歳。
台帳の C01 の「現実の値 26.9〜30 年」と合う。ゲームは 100 ÷ 28 倍に延ばすので、ゲームの出産の平均年齢が 100 年 ± (この幅 × 3.6) に入ることを確かめの目標にする案。

### 5 歳きざみの率の元

所得の分位ごとに、出生率が分位の中央値に近い国の 2023 年の 5 歳きざみの死亡率 (男女) と年齢別出生率を `rates_2023_median_country` に置いた (Ethiopia, Djibouti, Georgia, Turks and Caicos Islands, Germany)。セッション 10 は、所得で率を動かす元にする。

## セッション 12: R17 入植集団の大きさと存続

R17 は固定ずみ (幅のない目標)。材料は `data/raw/colony/literature.json`。再現の試験の案:

1. Smith 2014 の前提 (150 年・5 世代・遺伝の多様性を保つ・災害も考える。前提の細かい数は本文と未照合) をゲームの計算に入れ、14,000〜44,000 人の幅で「続く」になり、その下で「続かない」になる。

3. 画面には、続く確率を幅で出す (どちらの前提かを書く)。

まだのもの: Smith・Traill・Frankham の数を論文の本文と照らすこと (`data/raw/colony/README.md`)。1 人あたりの住む場所の質量の文献の幅 (`docs/proposals/12-ship.md` の 12-4) は Q2 では集めていない。
