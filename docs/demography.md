# 年齢つきの人口 (回 KE2・B-010)

`docs/proposals/10-age.md` の決まった案 (2026-10-20、ユーザーが「現実に寄せる」を選んだもの) を作った回です。式と値は `src/economy/demography-consts.js` の `DEMO`、仕組みは `src/economy/demography.js`。作る途中で、決まった案のままでは遊びが成り立たないことが分かり、ユーザーに 2 つ選んでもらいました (QD-29・QD-30。下の 3)。

## 2. 補正 (台帳の C13): 人口の合計は前の増え方のまま

`EDITIONS.game.demoTotal = true`。人口の合計は前のロジスティック (年 4%) の増え方のまま決め、年齢の中身 (死亡・年をとる・出生率) だけを現実の率で動かします。合計との差は次のように埋めます。

- 足りない分: 合計特殊出生率が高い入植地 (いちばん貧しい分位の国の 4.0 以上) ほど生まれた子として、低い入植地 (いちばん豊かな分位の国の 1.45 以下) ほど移民の年齢で足す (`DEMO.fill`)。豊かな国が人口を移民で保つ形。
- 多すぎる分: 年齢の割合のまま減らす。
- 出生のしやすさ (福祉・混み具合・食べ物の充足など) と飢えの死亡は合計の側に入れ、年齢の中身には掛けない。

`demoTotal` を外すと (シミュレーション版は値がないので外れたまま)、決まった案のとおり現実の率だけで人口が動きます。

## 3. 選んでもらったこと (2026-10-23)

### 3.1 人口の増え方 (QD-29 → d)

年数を延ばすと、現実でいちばん多産な国 (合計特殊出生率 8) でも人口の増え方は年 1.3% が上限です (前のゲームは年 4%)。しかもゲームの国はみな豊かで、出生率はドイツ並み (1.45) になります。

4 銀河 × 150 年 × 6 か国 (main: 入植地 63.5・総人口 8.2 万 [百万人]):

| 案 | 入植地 | 総人口 |
|---|---|---|
| a. 決まった案のまま (補正なし) | 21.3 | 1.8 万 |
| b. 年数を延ばさない (10-1 の c) | 19.0 | 0.3 万 |
| c. a + 開拓地の出生を最大 4.8 倍 | 22.0 | 2.1 万 |
| **d. 合計は前の増え方、年齢は中身だけ (選ばれた)** | 59.5 (下の 3.2 のあと) | 8.0 万 |

### 3.2 年金と医療の大きさ (QD-30 → 政府の大きさに合わせる)

はじめに伝えた d の数 (全部効かせて 44.5) は、足りない人口を全部子どもで足していた版のもので、豊かな本星で 0〜14 歳が 34% になっていました。移民で足すと年齢の形は現実に近くなる一方、年金と医療が GDP の約 18% (ドイツの実際と同じくらい) になり、税収 (GDP の 11%。JST の 1870〜2020 年の中央値) で払いきれず、入植が止まりました (25.8)。

| 案 | 入植地 |
|---|---|
| **税収に対する割合が OECD と同じになるように縮める (× 0.46。選ばれた)** | 60.3 |
| 現実の GDP 比のまま | 25.8 |
| 年金と医療は後で (B-007 と一緒に) | 53.0 |

0〜14 歳は 2〜4 番目の分位で幅の中ですが、65 歳以上が中・高所得でいつも多すぎます。現実の国 (1990〜2023 年) は人口転換の途中で、昔の高い出生率のぶん、いまの率の行き着く先より若いからです (ドイツの 2023 年の率をそのまま続けると、65 歳以上は 30% 近くになる)。ゲームの入植地は、いまの率の行き着く形に寄ります。いちばん下の分位は、合計を年 4% で増やす補正のぶん子どもが多すぎます。率を時代で動かす (所得が上がる途中の国は、出生率が所得より遅れて下がる) か、目標を「いまの率の行き着く形」と比べるかは、B-102 で生データ (HMD・HFD) と一緒に決めます。

試してやめたもの (どれも R36 が 5 分位すべてで外れた): 足りない分を全部子どもにする (豊かな本星で 0〜14 歳 34%)・全部移民にする (どの入植地も移民の形に寄り、低所得でも 65 歳以上 16%)・全部を年齢の割合のまま増やす (高齢も増えるので高齢の死亡率を下げたのと同じになり、低所得でも 65 歳以上 15%)・出生のしやすさ (混み具合・工業品の不足) を年齢の中身にも掛ける (低所得でも 0〜14 歳 17%)。
