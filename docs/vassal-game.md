## 2. 値の決め方

| 値 | 決め方 | 区分 |
|---|---|---|
| 離反の倍率 | 事例 131 件の Cox モデル (終わりまでの時間 ~ 法と実態の差 + 始まりの世紀) の差の係数で、exp(b × (差 − 藩王国の差))。b のハザード比 1.37 (95% 区間 1.22〜1.54)。植民地 (直轄) は前に COLDAT で推定した 1.39 (目標 R08) をそのまま使う | 社会 |
| 独立が戦争になる確率 | 型の事例の暴力の割合を、家族の割合へ 4 件分寄せた値。藩王国 (= 間接統治) と植民地 (= 直接統治) は ICOW の 128 件の英 9%・仏 32% (標本が大きいので) | 社会 |
| 朝貢 | 実態の課税と朝貢が 宗 50%・分 25%・従 5% (前の直接統治・間接統治・自治領の値) | 社会 (割合は前のまま) |
| 自治の度合い | 法の束の点 (宗 0・分 0.5・従 1) の合計 ÷ 2 (0〜4)。下げると、下げた分 × 8 だけ忠誠度が下がる (前と同じ 1 段 −8) | 社会 (反発の大きさは仮) |
| 指令を受けない | 実態で外交と任免を従属国が握る型 (冊封朝貢国・封臣・不平等条約の半主権国) | 社会 |
| 指令を拒むことがある忠誠度 | 50 + 5 × (実態の点 − 藩王国の実態の点)、30〜80 | 仮 |
| 遠さへの敏感さ (ゲーム版だけ) | 1.6 × 0.88^(実態の点)。現地が握るほど遠さが効きにくい | **補正** (C03・C12) |
| 忠誠度の目標 | 0 (法と実態の差の効きは離反の倍率に入っているので二重に数えない)。直轄 +10・強制労働 −10 は前のまま | — |

## 3. 前の 6 種類の読み替え (古いセーブと指令)

| 前の名前 | いま |
|---|---|
| 直接統治 | 植民地 (直轄、T20)。直轄の仕組み (指令にかならず従う・上限) は前のまま |
| 間接統治 | 藩王国・土侯国 (T04)。基準 (離反 ×1) |
| 封建制 | 封臣 (T13) |
| 連邦制 | 幕藩制の藩 (T14。国の中の自治の束で、いちばん近い) |
| 自治領 | 自治領 (T05)。事例では実態で外交と任免を分け合うので、指令は受ける |
| エンコミエンダ制 | 植民地 + 強制労働 |

AI の国の型は、まだ国号から決める (連邦 → T14、自治領 → T05、帝国 → 強制労働、王国など → T13、ほか → T04)。条件から決めるのは H3-2。

## 4. 法と実態を星系ごとに持つ・現地のエリート・約定の交渉・AI の型 (H3-2)

| 仕組み | 中身 | 区分 |
|---|---|---|
| 星系ごとの束 | 家臣の星系ごとに法 (`gv.law`) と実態 (`gv.fact`) を持つ (持っていなければ型の雛形)。離反の倍率に「法と実態の差」の項 = 1.37^(この星系の差 − 型の平均の差) を掛ける | 社会 (事例の Cox) |
| 型を変えるとき | 法は新しい型の雛形になり、実態はそのまま (力関係はすぐには変わらない)。直轄にすると実態も宗主が握る | 社会 |
| 現地のエリート | 1 つの行為者 (レーン D の集団が入るまで)。忠誠度 60 以上で協力 (実態が法へ寄る)、35 未満で抵抗 (実態が「従」へ寄る)、そのあいだは取引 (動かない)。寄る速さは 1 項目・1 年あたり 2% で半段ずつ。抵抗に回ると知らせが出る | 社会 (向きは Robinson 1972。速さと線は仮の値) |
| 約定の交渉 | 束の 1 項目の法を変える光速の指令 (政治力は統治体制の変更と同じ)。宗主の側へ寄せると、狭めた分 (法の点 1 点で −4) だけ忠誠度が下がる。指令を受けない型も、統治体制の変更と約定の交渉は受ける | 社会 |
| AI の国の型 | 国号ではなく、首都からの距離で決める。歴史の事例を宗主との位置で 3 つ (陸続き・近い海・遠い海) に分け、区分ごとの型の数に比べた確率で選ぶ。ゲームの距離は、歴史の 3 区分と同じ割合になる所 (11 光年・14.5 光年。ゲームの主従の距離の 38% 点と 60% 点) で分ける。入植で生まれる従属国には、既にある国家を従えた型 (傀儡国・衛星国・不平等条約) と直轄は使わない | 社会 |
| 独立の記録 | 独立のとき、戦争になったかと型の戦争の確率を `lastIndependence` に残す (測る道具のため) | 土台 |

全体の存続の中央値は 148 年 (H3-1 は 127 年、その前の main は 138 年)。R32 は、AI の国どうしの独立では戦争の判定をしないので、独立のときの型の戦争の確率の平均で測った。

### R30 が合わない理由 (選んでもらう)

歴史の事例では、儀礼の宗主権 (冊封朝貢・藩部・貢納公国) と君主と封の網 (封臣・藩・同君連合) が平均の 3〜4 倍長く続いた。けれども事例の Cox では、その長さの多くは**始まりの時代** (100 年遅いと終わりが 2.3 倍起きやすい) で説明され、型そのものの効きは法と実態の差 (R31) だけだった。近代以前は何でもゆっくり動いていた、ということ。ゲームには時代の差がないので、R31 に合わせて差の大きい儀礼の型の離反を高くすると、R30 の順が逆になる。現実の値どうし (R30 と R31) がぶつかるので、どちらに寄せるかを選んでもらう (`docs/status/H.md`)。

## 6. 新しい仕組みの要る型 (H3-3)

宗主が 2 国のときは「主な宗主 1 国 + 2 国目は朝貢と称号だけ」(ユーザーの決定。`docs/vassal-decisions.md` の 2)。ほかは型の束から出る仕組みを 1 つずつ入れた。値はどれも仮の値で、向きは事例から (`H33`)。

| 型 | 仕組み | 事例 |
|---|---|---|
| 共同統治 (T08) | 2 国目の宗主 (主な宗主の国のほかで首都がいちばん近い独立した国) へ朝貢の 3 分の 1 を送る。主な宗主は分け前を断てるが、断つと家臣の忠誠度 −6 (2 国目とのつながりは家臣の正統性でもあった) | 英埃スーダン (実態は英)、琉球の両属 (実態は薩摩) |
| 特許会社領 (T09) | 朝貢の 30% は会社が取り、宗主に届かない (家臣の政府に残る)。直接統治にすれば特許を取り上げられる | 東インド会社 (1858 年に国王の直轄へ) |
| 統治者の任免 (どの型でも) | 実態で任免を宗主が握るか分け合う家臣なら、現地の統治者を替えられる (光速の指令)。実態は約定どおりに戻り、エリートは協力から始まるが、忠誠度 −15 | 幕藩の改易・転封、バローダの廃位 (1875)、韓国の高宗の退位 (1907) |
| 同君連合 (T15) | 1 世代に 1 度ほど継承の危機が起きる。継承を実態で従属国が握っていれば、連合は戦争なしに解ける | ハノーファー (1837)、スウェーデン=ノルウェー (1905) |
| プラット型 (T19) | 関税受領官: 払えなかった朝貢を滞納として持ち越し、次の年に先に取る。滞納のあいだは忠誠度の目標 −6 | ドミニカ (1907〜41)、ハイチ (1915〜47) |
| 幕藩制の藩 (T14) | 新しい仕組みは足さない。任免の仕組み (改易) と束 (課税と朝貢は「分」) で表す | — |

30 の銀河 × 300 年 (H3-3 のあと): 存続の中央値 136 年・独立 683。R31 1.48 (合格)・R32 4/5 (合格)。

## 7. 史料の欄 (H4-1)

統治の欄の中に「史料」を畳んで置いた (ユーザーの決定。`docs/vassal-decisions.md` の 3)。開くと、型を選ぶ欄と、その型の家族・事例の最頻の束・存続の中央値、**当時の言葉・法と実態の差・事例 (事例のデータの全件と、期間・終わり方・暴力)・一次史料の出典・研究者の論争・ゲームで省いたこと**が出る。見るだけで、指令ではない。

- 中身は `data/build/build_vassal_game.py` が `docs/vassal-typology.md` の 3 (H1 の記述。H2-1 で条文の番号を直したもの) と事例 131 件から `VASSAL_DATA` に書く。植民地 (直轄) の記述は台本の中に書いた。
