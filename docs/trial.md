# 体験版 (回 SO4・B-082)

評論家の 4-2 (`docs/critique/04-plan.md`): 体験版 = 最初の時代 (2300〜2400 年)。終わりに答え合わせ (1-3) を見せて、続きを遊びたくさせる。Steam Next Fest (`store/steamworks.md` の 3) には、ストアのページと体験版が要る。

## 1. 作り方

- `node tools/build.mjs --trial` で、リポジトリの根に `demo.html` を作る (ゲーム版の `index.html` も一緒に作る)。`--trial-to <ファイル>` は体験版だけをそのファイルに作る (試験用)。
- 中身はゲーム版と同じ src。`src/core/base.js` の `TRIAL` だけを `true` にする (`EDITION` は `game` のまま。セーブの形も同じ)。体験版だけの仕組みは `src/outward/trial.js`。
- 公開のページ (`.github/workflows/pages.yml`) には、ゲーム版・シミュレーション版と一緒に `demo.html` を置く。
- 包装: `node desktop/prepare.mjs --trial` で、`demo.html` を包装のゲームとして写す。Steam の体験版は別のアプリの番号になるので、出すのは Steamworks のアカウント (QD-21) のあと。

## 2. 体験版で違うところ

| 所 | 体験版 | ゲーム版 |
|---|---|---|
| 終わりの年 | 2400 年 (100 年) だけ。終わったら先へ進めない (速さを上げても止まったまま) | 100・300・500 年・終わりなしから選ぶ。終わったあとも続けて遊べる |
| ホームの頁 | シングルプレイ・ロード・国家制作・著作権関連 (マルチプレイと友達と遊ぶは出さない) | すべて |
| 終わりの画面 | 答え合わせ (「結果へ」) → 結末と点数 → 「この時代の答え合わせ」「セーブを書き出す」「ホームへ」と、製品版への案内の文 | 答え合わせ → 結末と点数 → 「続けて遊ぶ」「ホームへ」 |
| 保存の名前 | `nlu-trial` (製品版の自動セーブやスロットと混ざらない) | `moribin` |
| 読めるセーブ | 終わりの年が 2400 年で、2401 年を越えていないものだけ | すべて (体験版のセーブも。2400 年から続けられる) |
| 題と札 | 「NoLongerUbiquitous 体験版」(英語は Demo) | 「NoLongerUbiquitous」 |

- ストアのページの番地 (`TRIAL_STORE_URL`) は、Steam のアプリの番号が決まったら入れる。空のあいだは、終わりの画面に案内の文だけを出す。
- 終わりの年の答え合わせは、ゲーム版の 100 年の試合でも、答え合わせを閉じてから終わりの画面が出るように直した (前は同じ時に開き、答え合わせが終わりの画面で上書きされていた)。

## 3. 試験

`tools/tests/trial.js` (CI の試験の一式に入る): 体験版をその場で組み立て、ブラウザで開いて、題・ホームの頁・終わりの年・2400 年での答え合わせと終わりの画面・先へ進めないこと・セーブの読み書き・英語の題を見る。ゲーム版の 100 年の試合も、答え合わせのあとに終わりの画面が出て続けて遊べるかを見る。

## 4. まだのもの

- Steam の体験版のアプリ・Next Fest への申し込み・配信者への鍵 (評論家の 4-5・4-6): ストアのページの公開と Steamworks のアカウント (QD-21) のあと。
- 体験版の遊び方の記録 (体験版から製品版のウィッシュリストへ移る割合。評論家の 4-2 の物差し) は、Steam の数で見る。
