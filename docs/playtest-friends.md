# 友達と遊ぶ (回 GA12・B-063)

5 波目の「友達と一度遊ぶ」(回 W4 の W4-Q1 = b・W4-Q2 = a。`docs/requests/2026-11-01-common.md`) の手順と、遊んだあとの記録の集め方。ゲームの中の説明は、ホームの「友達と遊ぶ」(`src/screen/home.js` の `friendsHtml`)。この文書は、誘う人 (ユーザー) のためのもの。

## 1. 友達に送る文 (そのままコピーしてよい)

```text
NoLongerUbiquitous という宇宙の植民のゲームを、ネット対戦で一緒に遊んでほしい。30 分〜1 時間くらい。
1. https://akasa-bit.github.io/ababababa/ を開く (タブレットかパソコンの Chrome・Edge・Safari。できれば家の Wi-Fi)
2. ホームの「友達と遊ぶ」を読んでおく
3. 当日、こちらから招待コードを送るので、ホーム → マルチプレイ →「参加する」に貼って、できた返事コードを送り返してほしい
終わったら、「友達と遊ぶ」のいちばん下で感想を書いて、「記録を書き出す」のファイルを送ってほしい (名前や場所は入っていない)
```

## 2. 当日の流れ (ホスト)

1. ホーム →「友達と遊ぶ」→「100 年の版の設定へ」(終わりの年 100 年・4 か国になる)。人数が多ければ国の数を増やす。
2. 「次へ (国家選択)」→ 友達の国を「＋人間」→「ネット対戦」。
3. 友達ごとに「招待コードを作る」→「コピー」→ メッセージアプリで送る → 返ってきた返事コードを貼って「つなぐ」→ 全員つながったら「はじめる」。ログインしていれば「部屋を作る」の 6 文字のコードだけでもよい (本物の Firebase で部屋のコードを試すのは、これが初めて。だめなら招待コードの道で)。
4. 速さはホストが決める。はじめは「1 年」。だれかが考えたいときは止める。
5. 遅れて来た人・途中で切れた人は、メニューの「ホーム」で開くネット対戦の画面の「入っていない国」から招待を作り直す (回 SO5)。
6. 2400 年で終わりの画面が出たら、みんなに「友達と遊ぶ」の 6 (感想と記録の書き出し) を頼む。ホストも書く。

つながらないとき: ネット対戦の画面の「つながらないとき」。中継のサーバーを置いていないので、スマートフォンの回線や会社・学校のネットではつながらないことがある (`docs/status/SO.md` の回 SO5)。

## 3. 記録の集め方

- 友達から届いたファイル (`nolongerubiquitous-playlog-日付.json`) を、リポジトリの `playtest/<遊んだ日>/` に置く。`playtest/` は `.gitignore` に入れてあり、公開のリポジトリには入らない。
- 1 つのファイルに、その端末のプレイ記録 (同意したときだけ) と感想 (書いて「感想を残す」を押したものだけ) が入る。記録を止めていた人のファイルでも、感想は読める。
- 数える: `node tools/playlog-report.js playtest/<遊んだ日> --players`。楽しさの目標 (F01〜F05・F20・F21)・判断の数・待つだけの時間の表と、感想の表 (また遊びたいか・100 年の長さ・つながり・書いたこと) が出る。
- 出た表 (と、言いたいこと) をセッションに貼るか、ファイルをセッションに渡す。W5 (5 波目の見直し) でまとめて見る。

## 4. 記録の扱い

- 友達は「見知らぬ試遊者」ではないので、楽しさの目標の合否には使わない (`targets/targets.json` の rules。道具も 30 人より少なければ「参考」と出す)。どこで迷ったか・どの判断が多かったか・感想を、6 波目の組み方の材料にする。
- 記録に名前・メール・場所は入っていない (`src/screen/playlog.js` の同意の文)。それでもファイルそのものは公開のリポジトリに入れない。文書に残すのは、まとめた数と、感想の文 (だれのものか分からない形) だけ。
- 遊んでいて見つかった不具合は、そのとき進んでいる回を止めずに直す (別の PR。`docs/sessions.md` の 3 の「5 波目」)。
