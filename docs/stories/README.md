# 語り手の出来事を書くフォーマット

ゲームの「出来事」(語り手の出来事。`src/politics/story.js` の `STORY`) の中身を、ユーザーが考えて書くための場所です (2026-10-23 のユーザーの依頼)。1 つの出来事 (連作) を 1 つのファイルに書き、Claude がそれをゲームに入れます。

## 1. 書き方

1. [`_template.md`](_template.md) をコピーして、`docs/stories/<短い英字の名前>.md` を作る (例: `refugees.md`)。
2. 分かる所だけ埋める。**数は空でよい** (Claude が下の 3 の目安で埋めて、入れたあとにファイルへ書き戻す)。メモ書きの 1 行 (「鉱山の町でストライキ。賃上げか弾圧か。弾圧すると数年後に地下組織」) でもよい。
3. 回の文で「docs/stories/○○.md を入れて」と頼む。入れたものは下の 5 の一覧に載せる。

見本: [`refugees.md`](refugees.md) (いまゲームに入っている「難民」の連作を、この型で書いたもの)。

## 2. 決まり (ゲームの仕組み)

| 決まり | 中身 |
|---|---|
| 段の数 | 1〜3 段。2 段目・3 段目は、前の段の返事が届いた年から **8〜15 年あと**に、**同じ星系で**起きる |
| 分かれ道 | 前の段の答えで、次の段の中身を変えてよい (A を選んだときの 2 段目・B を選んだときの 2 段目)。どちらかの答えで終わってもよい |
| 選択肢 | 1 つの段に **2 つ** (3 つ以上は相談)。**どちらにも得と損を付ける** (払えるならこれ、という明らかな最善を作らない。B-049) |
| 光の遅れ | 遠い星系の出来事は、光が地球に届いてから見え、返事も光速で届いた時点で効く。書き手は気にしなくてよい (仕組みが自動でやる) |
| 返事がないとき | 期限 (知らせが届いてから約 15 年) までに返事がなければ、現地が決める。どちらになるかを書く |
| 同じ出来事 | 1 試合に 2 回まで (目標 F19) |
| 首都 | 首都 (太陽系) は忠誠度を持たない。首都で起きる出来事の「忠誠度」は、その 3 分の 1 が議会の支持になる |
| AI | 観戦のときの地球 (と自動対戦のボット) が選ぶための「選びやすいとき」を書く (なければ Claude が決める) |

## 3. 使える効き目と目安の大きさ

いまのゲームで動かせる値です。ないものを使いたいときは、メモに書けば相談します (新しい仕組みが要ることがある)。

| 効き目 | 目安 | どう効くか |
|---|---|---|
| 忠誠度 (その星系) | ±3〜15 | 低いと指令を拒み、20 を切ると独立しやすい。首都では議会の支持に |
| 議会の支持 (国じゅう) | ±1〜4 | 低いと政権が倒れ、国家方針と政治力を失う (15 を切ったとき)。政治力の伸びにも効く |
| 恐怖度 (その星系) | +10〜20 | 独立しにくくなる。忠誠度とは別 |
| 資金を払う | 100〜400 cr | 選ぶときに地球から払い、届いた先で使う。AI は資金の 2 割までしか払わない |
| 政治力を払う・得る | 5〜10 | 指令に使う力 (上限 100) |
| 資源がその星系の備蓄に入る | 金属・燃料・希少元素・水・食料 80〜800 | 希少元素は 40〜120 くらいが目安 |
| 人口 | −2 割〜+5 万人 | 人口を減らす事故・新しい種族を足す移民 |
| 先住民の友好度 | ±10〜20 | 先住民のいる星系だけ |
| 自治 | 30 年 | その星系が指令を受けなくなる (要求をのんだときと同じ) |
| 疫病 | 5〜15 年 | 人口が伸びにくい |
| 小さな襲撃 | 戦力 1 | 守りの艦隊がいなければ被害が出る |
| 何も起きない | — | 「放っておく」の得は、払わずに済むこと |

## 4. チェック表 (書き終わったら)

- [ ] どの段の選択肢にも、得と損の両方がある (片方に損がないなら、その代わりに次の段で困ることがある)
- [ ] 払うものがある選択肢と、ない選択肢がある (お金があるときに迷わず選べる形にしない)
- [ ] 3 段まで。分かれ道は前の段の答えで分かれている
- [ ] 起きる星系が書いてある (いまの自国の星系で起きる。他国では起きない)
- [ ] 元ネタがあれば書いてある (講義で使うときの説明になる)
