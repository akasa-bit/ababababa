# 難民船

| 項目 | 中身 |
|---|---|
| 名前 (英字) | refugees |
| 段の数 | 3 |
| 起きる星系 | 首都 (太陽系)。首都のほかに自国の星系が 1 つもなければ、10 回に 3 回だけ |
| 起きる時期 | いつでも |
| 元ネタ (任意) | 難民の受け入れと統合 (ボートピープル・シリア難民)。同化か多文化か |
| ひとことで | 異星の難民を受け入れるか。受け入れると、定住地で元の住民と対立し、最後は同化の反発か自治の要求になる |

## 1 段目

**知らせ**: 異星の難民船が太陽系に現れ、(種族名) 5 万人が保護を求めている

**場面**: 異星の難民船が太陽系に現れた。(種族名) 5 万人が保護を求めている。受け入れれば、空きのある入植地へ送る。

| | 選択肢 A | 選択肢 B |
|---|---|---|
| ボタンの文字 | 受け入れる | 断る |
| 払うもの | | |
| 得 | 入植地の人口 +5 万人 (新しい種族) | 議会の支持 +2 |
| 損 | 議会の支持 −3 (反対派) | |
| 次の段 | 2 段目へ (移り住んだ入植地で) | ここで終わり |

- 返事がなかったら: B (5 年で期限)
- AI が A を選びやすいとき: 議会の支持が高い (55 より上) とき

## 2 段目

### 前の段で A を選んだとき

**場面**: (星系) に移り住んだ (種族名) と元の住民が、言葉と祭りをめぐって対立している。

| | 選択肢 A | 選択肢 B |
|---|---|---|
| ボタンの文字 | 同化政策をとる | 自治区を認める |
| 払うもの | | |
| 得 | 議会の支持 +2 | 忠誠度 +6 |
| 損 | この星系の忠誠度 −6 (移民の反発) | 議会の支持 −2 (「特別扱い」への批判) |
| 次の段 | 3 段目へ (同化の続き) | 3 段目へ (自治区の続き) |

- 返事がなかったら: B
- AI が A を選びやすいとき: 議会の支持が低い (50 より下) とき。B は忠誠度が低い (60 より下) とき

## 3 段目

### 2 段目で A (同化政策) を選んだとき

**場面**: 同化政策に反発した (種族名) の地下の抵抗が、(星系) で広がっている。

| | 選択肢 A | 選択肢 B |
|---|---|---|
| ボタンの文字 | 取り締まる | 和解金を出す |
| 払うもの | | 資金 250 cr |
| 得 | 恐怖度 +20 (独立しにくくなる) | 忠誠度 +10 |
| 損 | 忠誠度 −8 | 資金 |

- 返事がなかったら: A
- AI が A を選びやすいとき: 忠誠度が高い (60 より上) とき。B は資金に余裕があり、忠誠度が低いとき

### 2 段目で B (自治区) を選んだとき

**場面**: (星系) の (種族名) の自治区が、自前の議会を求めている。

| | 選択肢 A | 選択肢 B |
|---|---|---|
| ボタンの文字 | 認める | 拒む |
| 払うもの | | |
| 得 | 忠誠度 +10 | |
| 損 | 30 年の自治 (この星系は指令を受けない) | 忠誠度 −15 |

- 返事がなかったら: B
- AI が A を選びやすいとき: 忠誠度が低い (50 より下) とき

## メモ

- 1 段目の「断る」に続きがないので、断った国には何も起きない。「断った難民船が隣の国に受け入れられ、その国と仲良くなる」のような続きも考えられる (外交の協定とつなげる)。
