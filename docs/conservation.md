# 物質とエネルギーの保存 (S3 の 2)

縦切りの試作 S3 の 2 つめの段です。資源の備蓄が増えたり減ったりするときは、かならず「どこから来て、どこへ行ったか」を記帳するようにしました。その記帳で、物質とエネルギーの保存則を試験で確かめます。合わせる目標は R03 です (星系ごと・年ごとの (入った量 − 出た量 − 在庫の増加) ÷ 取扱量の絶対値の最大が 1e-9 以下)。

## 1. 直したこと

| 前 | 何が問題か | 今 |
|---|---|---|
| 備蓄の上限を超えた分は、域外へ基準価格の 5% で売れた | 売る先の「域外」がどこにもない。物が消え、お金が湧く | 上限を超えた分は捨てる (「捨てた」と記帳する)。お金にはならない |
| 艦隊の補給が足りないと、資金で「現地調達」できた (基準価格の 2 倍) | 物がどこからか湧く | 備蓄で足りなければ補給不足になる。補給は需要に数えるので、交易路で運ばれてくる |
| 工業品 1 の材料は金属 0.5 と燃料 0.2 | 単位の質量が同じなら、0.7 が 1 になって質量が増える | 工業品 1 単位を 50 万 t (金属 0.5 単位と同じ) にした。燃料は燃やして出ていく。入植船の構造などの質量も、この値で計算し直す (推進のエネルギーが下がる) |
| 備蓄を直接書き換える所が約 20 か所あった | 記帳がないので、保存を確かめられない | すべて `mv(星系, 資源, 量, 種類)` を通す |

## 2. 出入りの種類

| 入る | 中身 |
|---|---|
| extract (採掘・収穫) | 農場・鉱山・採掘基地・先住民の生産と交易・鉱脈の発見・漂流船の回収・奴隷工房 (働かされる人が地元で集めた原料から作る) |
| make (工業の産出) | 工場の工業品 |
| arrive (着いた) | 貨物船の荷・入植船が積んできた食料と水 |

| 出る | 中身 |
|---|---|
| consume (消費) | 人の食料・水・工業品、奴隷工房で使う奴隷 |
| use (工業の投入) | 工場が使う金属 |
| burn (燃やした) | 工場が使う燃料 |
| build (建設) | 施設・交易路・艦隊・歩兵・入植船の構造に使った資材 |
| ship (積み出した) | 貨物船の荷・入植船に積む食料と水 |
| supply (補給) | 艦隊の補給物資 |
| waste (捨てた) | 備蓄の上限を超えた分 |
| pirate (奪われた) | 海賊の略奪 |

スウォームを作る材料は、自己複製する機械が小惑星や惑星から直接取る設定なので、備蓄を通りません ([energy.md](energy.md) の 5)。

## 3. 測った結果

### R03 (試験 `tools/tests/conserve.js`)

試験では、1 年ごとに次を確かめます。

1. 星系ごと・資源ごとに、記帳した出入りの合計と備蓄の増加が一致すること (誤差 ÷ 取扱量)。
2. 運ぶ途中の物: 積み出した量 − 着いた量 = 運んでいる途中の量の増加 (貨物船・入植船の食料と水・積み込みを待つ入植船)。
3. 工業の質量: 工業品の産出の質量 = 投入した金属の質量。
4. 出入りの種類が、上の表のものだけであること。
5. エネルギー: 政府ごとに、記帳した出入りと蓄えの増加が一致すること。

| 試合 | 備蓄 | 運ぶ途中 | 工業の質量 | エネルギー | 判定 |
|---|---|---|---|---|---|
| ゲーム版・地球だけ・シード 5・150 年 | 2.9×10⁻¹² | 8.9×10⁻¹⁴ | 0 | 8.6×10⁻¹⁴ | 合格 |
| シミュレーション版・6 か国・シード 7・150 年 | 7.2×10⁻¹⁴ | 1.2×10⁻¹² | 0 | 3.5×10⁻¹³ | 合格 |

残る誤差は、浮動小数点の丸めだけです。

### 物質の流れ (ゲーム版・地球だけ・150 年の合計)

| 種類 | 質量 |
|---|---|
| 採掘・収穫 | 7.1×10¹⁵ kg |
| 人の消費 | 2.9×10¹⁵ kg |
| 捨てた | 3.3×10¹⁵ kg |
| 工業の投入 (金属) と産出 (工業品) | 4.6×10¹⁴ kg |
| 燃やした燃料 | 1.8×10¹⁴ kg |
| 建設 | 8.3×10¹³ kg |
| 船で運んだ | 2.1×10¹³ kg |

**掘った物の約半分を捨てています。** 入植地は方針 (自給・農業など) で決まった割合の人を農業・鉱業・工業に就けるので、使い道のない物まで作ってしまいます。前はこれが域外に売れてお金になっていました。人の振り分けを需要に合わせる仕組みは、第三次産業と研究を入れる S4 で作ります (余った人手がサービスと研究に回る)。

### 遊びへの影響 (6 つの銀河 × 150 年の平均。S3 の 1 のあとと比べる)

| | 前 (S3 の 1) | 今 |
|---|---|---|
| 地球の国の収入 (地球だけの試合) | 年 5,200 cr | 年 1,800 cr |
| 地球の国の資金 (同) | 11 万 cr (ほとんど使われずに積み上がる) | 2,700 cr |
| 総人口 (同) | 285 億人 | 255 億人 (−11%) |
| 入植した星系 (同) | 17.7 | 17.5 |
| 総人口 (6 か国) | 1,496 億人 | 1,390 億人 (−7%) |
| 入植した星系 (6 か国) | 68.2 | 69.3 |

- 売却が、地球の国の収入の約 6 割を占めていました。
- 人口が減ったのは、地球の国の資金が減って地球の居住区の拡張が遅れ (Lv 5 → 3〜4)、地球の人口の上限が下がったからです。ほかの星系の人口は変わらないか、少し増えました。広がり方 (星系の数) は変わりません。
- 前は資金が 10 万 cr 以上、使われずに積み上がっていました。今はお金の使い道を選ぶ意味があります。
- ここは「現実と遊びやすさがぶつかる所」なので、`docs/reality-check.md` の 4 の 6 に、税を上げて埋め合わせる案と並べて置きました。

## 4. 限界

- 奴隷工房の工業品は、地元で集めた原料からとして「採掘」に数えています (材料の金属は使いません)。
- 奴隷 1 単位の質量は 100 万 t としています (運ぶときのエネルギーの計算用)。人を運ぶなら、移民船と同じく 1 人あたり 250 t のほうが筋が通ります。S5 で船の設計を作るときに見直します。
- 捨てた物は、その星系から消えます (どこかに積もる・使い直すことは考えていません)。
- お金 (cr) の保存は、段 4 で入れました ([money.md](money.md))。お金の裏づけ (エネルギー本位・労働本位など) は、まだ決めていません。
