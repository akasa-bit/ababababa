# 講和と開戦の交渉 (段 8)

`docs/game-plan.md` の段 8 (区分は社会)、`docs/sessions.md` のセッション 2 (レーン A) です。AI の国の開戦と講和を、確率の表 (`PEACE`) から、Fearon (1995) の交渉の模型に置き換えます。交渉の型はユーザーが選びました (`docs/requests/2026-10-20-A.md` の A-1: おすすめの 1-b・2-b・3-b)。

## 1. 選んだ型

| 軸 | 選んだもの | 中身 |
|---|---|---|
| 1. 相手の強さの分からなさ (情報の非対称) | b. 幅つきの見積もり | 相手の艦隊は、首都に光が届いている記録 (段 3 の `seenShips`) × exp(読み違い × 幅) と見る。読み違いは戦争ごとに国ごとに引き、その国だけが知っている。幅は記録が古いほど広い。戦争中は、沈めた・沈められた艦隊の数で見積もりを直す (戦いながら分かっていく。Slantchev 2003、Filson & Werner 2002) |
| 2. 約束の問題 | b. 力の移り変わり | 相手の艦隊の伸び (光が届いている分) が自分より速いと、講和しても続かないと見て、講和の線を上げる。宣戦の見込みにも足す (予防の戦争。Powell 2006) |
| 3. 講和の決め方 | b. 交渉の範囲 | 両方の「受け入れる線」が重なれば、その真ん中で講和する。真ん中の値の大きさで、白紙講和・条約 (講和会議の持ち点)・全面降伏に分かれる |

## 2. 式 (表 `BARGAIN`)

国 r が、相手 e との戦争で受け入れる線 L(r) (r の取り分の戦勝点、−100〜100):

- 勝つ見込み p = (自分の艦隊 + 0.5) ÷ (自分の艦隊 + 見積もった相手の艦隊 + 1)
- 見積もった相手の艦隊 = `seenShips(r, e)` × exp(z × (sigma0 + sigmaAge × 光の遅れ))。z は読み違い (平均 0・分散 1)
- 戦争中: p ← (learn × p + n × (沈めた + 1) ÷ (n + 2)) ÷ (learn + n)。n = 両方が沈めた艦隊の合計
- 見込みの結果 = 戦勝点 + (2p − 1) × swing (−100〜100 に切る)
- 費用 = (cost + costEx × 戦争疲弊) × horizon
- 力の移り変わり = shift × max(0, 相手の伸び − 自分の伸び) × 100 (伸び = shiftYears 年の艦隊の年率。相手の分は光の遅れのぶん古い)
- L(r) = 見込みの結果 − 費用 + 力の移り変わり

講和: AI の国どうしでは、L(r) + L(e) ≤ 0 なら、x = (L(r) − L(e)) ÷ 2 (r の取り分) で結ぶ。|x| < 5 で白紙講和、90 以上で全面降伏、そのあいだは x を持ち点にした講和会議。相手がまだ開戦を知らなければ交渉できない (段 3)。

人間の国が相手のとき: AI の国は、いまの戦勝点が L 以上なら講和を申し入れる (5 年に 1 回まで)。人間の国からの申し入れには、いまの戦勝点が L 以上なら応じる。

宣戦: 平時の国は、年 `declareChance` の確率で、首都に届いている記録で 25 光年以内の独立国を見比べ、開戦したときの L (戦勝点 0、読み違いはその場で引く) が `declare` を超える相手のうち、いちばん良い相手に宣戦する。

戻し方: `BARGAIN.on` を false にすると、前の確率表 (`PEACE`) の判断に戻る。

## 3. 値の決め方

物理と社会の式の値です (補正ではない)。較正の目標は、戦争の多さ (COW 国家間戦争 4.0 と国家の一覧 2016 から計算した、国 1 つが 100 年のうちに新しく国家間戦争に入る回数 2.34。±30% の 1.64〜3.04 を目標にする。目標のファイルへの登録は、レーン C の目標の PR #120 のあとに出す) と R13 です。R14 は確認用なので、値を選ぶのに使っていません。

| 値 | 選んだ値 | 理由 |
|---|---|---|
| `sigma0`・`sigmaAge` | 0.8・0.01 | 読み違いが小さい (0.3) と、はっきり強いときにしか宣戦せず、相手が開戦を知った年にすぐ講和して、長さがほぼ距離になる。力の近い相手への読み違いの戦争が出るように広げた |
| `learn` | 30 | 戦闘のないあいだは見積もりがなかなか直らない (戦いながら分かっていく形を残す) |
| `cost`・`costEx`・`horizon` | 0.2・0.02・5 | 費用が大きいと、どの戦争も線がすぐ重なって長い戦争が出ない |
| `declare`・`declareChance` | 20・0.03 | 戦争の多さが COW に合う組 (6 の銀河で 2.33) |
| `swing`・`shift`・`shiftYears`・`capitulate`・`warDist` | 60・1・10・90・25 | 前の決まり (25 光年・5 倍の降伏) と同じ大きさにした。振っても結果はほとんど変わらなかった |

振った組み合わせ (6 の銀河 × 300 年 × 6 か国。国 100 年あたりの国家間戦争 / R13): 既定 (sigma0 0.3・cost 3) 2.59 / 1.07、sigma0 0.8 2.81 / 1.13、cost 0.5 2.60 / 1.02、shift 5 2.76 / 0.99、sigma0 1.2・cost 0.3・learn 50・declareChance 0.012 1.75 / 1.09、選んだ組 2.33 / 1.14。どの組でも R13 は 1.0〜1.2 だった。

- 人間の国が関わる戦争 (60): 白紙講和 75%・滅亡 24% (観戦用の手の判断は変えていない)
- **R14 (確認用) は不合格のまま**。UCDP の国家間 (停戦を除いて足し直す) は勝利 39%・活動低下 33%・和平合意 28% で、いちばん多いのは勝利。ゲームは条約 (和平合意) が 72% でいちばん多い。前の白紙講和 (活動低下) 74% から、いちばん多い終わり方が入れ替わった。確認用なので、これに合わせて値は動かしていない
- 試験はすべて合格

### R13 が合わない理由

長さの中央値が、相手の首都までの光の遅れ (10〜25 年) のあたりに固まる。相手が開戦を知るまでは交渉できず、知った年には多くの戦争で線が重なって講和するので、長さ ≒ 距離になる。COW の戦争は、知らせの遅れ (数日〜数週間) が戦争の長さ (中央値 5 か月) よりずっと短い時代のもので、ゲームはその逆になっている。

参考: 長さを「両方が開戦を知ってから」で数えると、交渉の型で平均 4.5 年・中央値 0.6 年・R13 7.37、main で 4.51 になる (12 の銀河)。4 割の戦争は、両方が知った時点でもう終わっている (攻め落とし、または知った年の講和)。こちらは幅の上を超える。

**扱い (2026-10-20 のユーザーの決定。`docs/requests/2026-10-20-A.md` の A-3)**: 案 A。ゲーム版では R13 を判定しない。光の遅れと両立しない目標として扱い、長い裾 (100 年を超える戦争) があるかだけを見る。測り方は、シミュレーション版を作るときに見直す (`docs/game-plan.md` の 6)。ほかの案は、B「長さを両方が開戦を知ってから数える (目標の変更。測ると 7.37 で幅の上を超える)」と、C「値をさらに動かす (振った範囲では動かなかった)」だった。
