## 1. いつもの約束 (ユーザーとの決まり)

- 報告は日本語で書く。
- 変更ごとに、コミット → プッシュ → PR → スカッシュマージまで行う。PR の本文にテンプレートはない。
- 機能を壊さない (下の「試験」をすべて通してからマージする)。
- 画面は Xiaomi Pad 8 Pro (3200×2136・144Hz、CSS で横 1280×780・縦 854×1200、画素の比 2.5) で確かめる。Playwright の viewport をこの大きさにして撮る。
- 「スキン 6」= グラファイト (黒に近い灰色)・白・NASA の赤橙の配色。配色の 10 案から選ばれた唯一の配色で、切り替えは削除した (下の 15)。
- 作業ブランチは、そのセッションで指定されたもの (例: `ccr-f641c31e-9hmryq`)。マージのあとは `git fetch origin main && git checkout -B <ブランチ> origin/main` で main に合わせ直し、`--force-with-lease` でプッシュする。
- リポジトリに入れるもの (コミット・PR・コード・文書) に、AI のモデルの名前を書かない。
- コミットの末尾の行と PR の本文の末尾は、そのセッションで与えられる案内 (共同作者の行・セッションへのリンク・「Generated with Claude Code」の行) に従う。
- 試験で書き出す画面の写し (`shots/`) と、作業用の台本は、リポジトリの外 (作業用のフォルダ) に置く。リポジトリに残すものは `tools/` に入れる。

## 6. 作業のこつと落とし穴

- `src/index.html` を直したら、かならず `node tools/build.mjs` で 2 つの版を作り直す。試験は公開用の HTML を開いて動かす。
- **決定性**: 試合の乱数は `Game.rand` (状態 `rs` はセーブに入る) だけを使う。`Math.random` は見た目にだけ使う。新しい乱数を増やすと試合の筋は変わるが、決定性の試験は通る。
- **セーブの互換**: 銀河は読み込みのたびにシードから作り直す。銀河の作り方を変えるときは、版の番号 (`GALAXY_GEN`) を上げ、古いセーブは古い作り方で読む (例: η⊕ の版 2)。
- **備蓄の出入り**はすべて `mv(星系, 資源, 量, 種類)` を通す (直接 `stockOf(...)[r] +=` と書かない。書くと `conserve.js` が落ちる)。新しい種類を足すときは、試験の IN・OUT の一覧にも足す。
- **エネルギーの出入り**は `bookE`、船の推進は `bookShip` を通す。
- **状態を変える操作**はすべて `issue(命令, 内容)` を通す (ネット対戦とホットシートのため)。艦隊への指令など政治力の要らない命令は `PC_FREE_ACTS`。
- **画面に出す値**は、光の遅れのぶん古い記録 (`known`) から作る。新しい値を出すときは、スナップショット (`known` を作る所) にも足す。
- **版ごとに違う値**は `EDITIONS` にだけ置く。版を分ける理由は `docs/reality-check.md` に書く。
- 自動対戦は CPU を食う (4 並列で 30 の銀河 × 300 年 × 2 つの版で約 15 分)。`run_in_background` で回し、待つ。
- `pkill -f` に、自分のコマンド行にも含まれる文字を使わない (自分のシェルが止まる)。

## 11. セーブとネット対戦の決まり

- **セーブ**: `buildSave` が書く `v: 2` の形。実在の銀河なら `galaxy: 'real'`、銀河の版 2 以上なら `gen` を入れる。読み込みでは、シードから銀河を作り直してから `restore` する。
- **保存の名前**: ゲーム版は前の名前のまま `moribin` (IndexedDB の名前・`moribin-save-v1` など)。Moribin のころのセーブをそのまま読むため。シミュレーション版は `nlu-sim`。
- **新しい状態を足すとき**
  - かならずセーブに入れる。入れないと、読み込んだあとに結果がずれ、決定性の試験とネット対戦の要約が合わなくなる (前に `ghosts.fleets` で起きた)。
  - プレイヤーごとに違う値は `PLAYER_KEYS` に入れる。ネット対戦の要約 (`Net.hash`) は `pi`・`savedAt`・`endShown`・`spectate`・`credits`・`PLAYER_KEYS` を除いて計算する。
  - 年 1 回の処理は、どの端末でも 1 人目のプレイヤーの立場で進む。「いま操作しているプレイヤー」によって結果が変わる処理を入れない。

## 13. 分かっている問題

- **戦争が多い**: 6 か国・300 年の自動対戦で、100 年あたりゲーム版 83・シミュレーション版 123 の戦争 (離反が増えて独立戦争が増えた)。終わり方は白紙講和が 9 割で、目標 R14 に合わない。S5 で戦闘と講和を作り直すときに直す。
- **仮の値**: 封建制・連邦制・自治領の離反の倍率、統治体制ごとの遠さへの敏感さ、離反のハザードの人口の比と忠誠度の項、強制労働の採掘 +30% と人口の増え方 ×0.7。
- **確かめられないもの**: 直接統治は人間の国だけが使うので、自動対戦ではハザード比を確かめられない。目標 R09 はゲームに本国の違いがないので判定できない。
- **AI の国の統治体制**は国号で決めている (帝国 → エンコミエンダ制など)。現実の根拠はない。
- **先住民と異星の国**は架空。シミュレーション版でも残っている (選んでほしいことの 4)。
- **版をまたいだ読み込み**: 書き出したセーブのファイルは、もう一方の版でも読める (その版の値で続く)。止めてはいない。

## 14. 試験の「合格」の見え方と、古い版との比べ方

- どの試験も、最後の `[]` はページの誤りがなかったこと。`[...]` に文字があれば誤り。
- `det.js`: 3 行とも「一致」で、`保存→読込→保存: true`。
- `hot.js`: 最後の 2 つの配列の先頭が `true`。他国の艦隊への命令は `{"ok":false,"reason":"他国の艦隊には命令できない"}` になるのが正しい。
- `net.js`: `sync2` の 2 つの要約 (2 番目の値) が同じ。最後の `1` は、わざと壊したあと 1 回で合わせ直したこと。
- `regime.js`: `regimes` が `federal, dominion, encomienda`、`revoke` が `[true, 32]`、`saveLoad` が `true`、`wide` の 2 つの値が同じ (はみ出しなし)。
- `energy.js`: 1 行目が「R07 合格」(|比 − 1| の最大が 1e-6 以下)。
- `conserve.js`: 1 行目が「R03 合格」で、「決まっていない出入り: なし」。
- 古い版と比べるとき (読み込みの互換・描画の違い) は、`git show <コミット>:index.html > /tmp/old.html` で古い公開用の HTML を取り出して渡す (例: `node tools/tests/rotate.js shots /tmp/old.html`)。

## 15. 画面の決まり (ユーザーと決めたこと)

- **配色**: スキン 6 だけ。色は意味にだけ使う (自国・敵・警告・良い知らせなど。`:root` の変数)。
- **見た目**: ボタンとタブは額縁のような枠。文字は古い報告書風の書体 (Google Fonts の Courier Prime・Special Elite・Zen Antique・Zen Old Mincho)。ボタンには動かない白い走査線。文字のぶれ (信号の揺れ) は設定の「画面の動き」で切り替える。
- **大きさ**: 文字の大きさは 4 段階、余白は 8px の倍数。ボタンは指で押せる大きさ (44〜48px)。文字のコントラストは基準を満たす。
- **説明文**: 長い説明は画面から外し、「説明」を押したときだけ出す (`helpify` が 50 字以上の説明文を自動で畳む)。
- **知らせ**: 出来事は地図の端の帯に流す。重大なものは消えずに残り、押すと地図がそこへ飛ぶ。イベントタブは履歴を探すときだけ使う。
- **情報の古さ**: 古い情報ほど薄く描き、「○年前の情報」を添える。
- **右の欄**: 星系を選んでいないときは出さず、地図を広げる。
- **押したボタンが指から逃げない**: 押して中身が増えても、押したボタンの位置は動かさない (増えた分は上へ伸ばす。交易路の連打のため)。
- **背景**: 星間マップは天の川の実写 (NASA)、星系マップは太陽系が北アメリカ星雲、ほかの星系はユーザーが選んだ 17 枚 (`assets/systems/`)。抑えめの明るさにする。
- **アイコン**: ユーザーが候補から選んだもの。出典とライセンスは README の「アイコンの出典」。
- **地図の描画**: 動かしているあいだは毎コマ描き、止まっていて何も変わらないときは描き直さない。
- **星間マップ**: いつも真上から見た平面 (回す・傾けるはやめた)。国境はステラリス風に、国の領土 (入植星系のまわり 5 光年、近いほうの国) を塗り分ける。それ以外の見た目はそれまでのまま (ユーザーの指示)。
