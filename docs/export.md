# データの書き出し (回 DO6・B-072)

ゲームの経済・財政・交易・戦争を、現実の統計と同じ形の表で書き出す道具です (`tools/export.js`)。経済学者や歴史学者が現実のデータに使っている台本を、そのまま当てられるようにする (`docs/econ-policy.md` の 6)。表の範囲と形は、回 DO6 の始めにユーザーに選んでもらった (`docs/requests/2026-10-23-DO.md` の DO-4。どちらもおすすめの案)。

- 画面なしの版 (`tools/headless.js`) で銀河を回す。ゲームの中身は変えない (出入りの関数を道具の側で包んで数えるだけ。`tools/fiscal-panel.js`・`tools/tests/ledger.js` と同じやり方)。
- 1 表 = 1 つの CSV (横に広い形)。列の名前は SNA 2008・GFS 2014 (COFOG)・BACI・COW の符号に合わせ、意味と単位はこの文書に書く。
- 前からある書き出し (`tools/fiscal-panel.js` = JST の形、`tools/market-panel.js`・`tools/sector-panel.js`・`tools/research-panel.js`・`tools/vassal-export.js`) は残す。目標 R10・R11・R19〜R28・R30〜R35 の台本が読むので。

## 1. 使い方

```sh
cd tools && npm ci && cd ..                                     # 初めのときだけ (Chromium は要らない)
node tools/export.js --out export-out --seeds 30 --years 150 --nations 6
node tools/export.js 設定.json                                   # 設定のファイル 1 つで、同じ書き出しをやり直せる
python3 tools/export_example.py export-out                       # 分析の例 (4)
```

設定のファイル (例):

```json
{ "out": "export-out", "seeds": 30, "years": 150, "nations": 6, "params": null }
```

- `seeds`: 銀河の数 (1 から数える) か、シードの配列 (`["1", "7", "12"]`)。
- `params`: 値のファイル (`tools/headless.js` の値の重ね書き。政策や補正を変えて同じ銀河を比べるとき) か、その中身。
- `HTML=<別の src/index.html>` で、別の版 (main など) を書き出せる。
- 1 銀河 × 150 年 × 6 か国で 5〜10 秒。30 銀河で 3〜5 分。
- 出力: 下の 9 つの CSV と `meta.json` (ゲームの版・シード・年数・国の数・値・行の数・書き出した時刻)。

## 2. 共通の列と単位

| 列 | 中身 |
|---|---|
| `galaxy` | 銀河のシード |
| `year` | ゲームの暦の年。流れ (出入り) は、その年までの 1 年の合計。残高は、その年の終わりの値 |
| `country` | 国の番号 (国の首都の星系の番号。独立した国も 1 つの国) |
| `name` | 国の名前 |

- **お金の単位は cr** (ゲームのクレジット)。帳簿は基準の値段で数える実質の値 (`docs/money.md` の 5.1)。名目にするときは `rates.csv` の `CPI` を掛ける。
- **人口の単位は 100 万人**。
- 国は年ごとに変わる (入植・独立・征服)。国の境目は、その年の終わりのもの。

## 3. 表ごとのコードブック

### sna.csv (国 × 年。国民経済計算 SNA 2008 の符号)

| 列 | SNA の符号の意味 | ゲームでの中身 |
|---|---|---|
| `POP` | 人口 | 国の入植地の人口の合計 (100 万人) |
| `B1GQ` | 国内総生産 (GDP) | 民間の付加価値 (税の土台と同じ所得: 物の産出 × 市場の値段 − 工業の投入 + サービス。`incomeOf`) + 政府が民間から買った分 (`P3_S13` + `P51G_S13`)。`tools/fiscal-panel.js` の `gdp` と同じ定義 |
| `P3_S14` | 家計の最終消費支出 | 家計が会社から買った物とサービスの代金 (種類 `spend`) |
| `P3_S13` | 一般政府の最終消費支出 | 政府が民間に払った行政サービス・維持費・予算・医療 (種類 `public`・`upkeep`・`welfare`・`security`・`military`・`education`・`health`) |
| `P51G_S13` | 一般政府の総固定資本形成 | 政府の建設 (種類 `build`) |
| `P51G_S11` | 会社 (非金融法人) の総固定資本形成 | 星系の会社の資本の投資 (種類 `invest`。回 KE6)。いまの投資は会社の利潤を建設の賃金として家計に移すだけで人も物も使わないので、`B1GQ` には足していない (`tools/fiscal-panel.js` と同じ)。総固定資本形成の合計は `P51G_S11` + `P51G_S13` |
| `P6` | 財とサービスの輸出 | ほかの国へ送った荷の額 (`trade.csv` の `v` を輸出国で足したもの) |
| `P7` | 財とサービスの輸入 | ほかの国から届けられた荷の額 (同じく輸入国で足したもの) |
| `D1` | 雇用者報酬 | 家計が会社から受け取った賃金 (種類 `wages`) |
| `D2` | 生産と輸入に課される税 | 消費税 + 関税 (`GR114` + `GR115`) |
| `D5` | 所得・富等に課される経常税 | 所得への税から研究開発の税額控除を引いたもの (`GR111`) |
| `B9_S13` | 一般政府の純貸出 (+) / 純借入 (−) | 国の政府の帳簿の、記帳した出入りの合計 (国債の出し入れと、国有化・民営化の株の売り買い (種類 `nationalize`・`privatize`。GFS の金融の取引) は除く。国の中の朝貢・資金援助は、届く途中の分だけ差が出る) |

### gfs.csv (国 × 年。政府財政統計 GFS 2014 と、支出の目的別分類 COFOG)

一般政府 = 国の首都と従属星系の政府をまとめたもの。

| 列 | 符号の意味 | ゲームでの中身 |
|---|---|---|
| `GR` | 収入 | `GR11` + `GR13` + `GR14` |
| `GR11` | 税 | `GR111` + `GR114` + `GR115` |
| `GR111` | 所得・利潤・キャピタルゲインへの税 | 所得への税 (種類 `tax`) から、研究開発の税額控除 (種類 `rdcredit`。回 KE6。会社の研究開発費の割合を政府が返す) を引いたもの (GFS 2014 の税額控除の扱い) |
| `GR114` | 財とサービスへの税 | 消費税 (種類 `ctax`) |
| `GR115` | 国際貿易と取引への税 | 関税 (種類 `tariff`) |
| `GR13` | 移転 (受け取り) | 家臣からの朝貢・主人からの資金援助を受け取った分 (種類 `tribute`・`grant`) |
| `GR14` | その他の収入 | `GR141` + 先住民からの収入 (種類 `natives`) + 国有企業の配当 (種類 `dividend` の政府の受け取り。GFS の 1412。回 KE9 の国有化から) |
| `GR141` | 財産所得 | 政府の預金の利子 (種類 `interest` の受け取り) |
| `GE` | 支出 | COFOG の 7 つ + `GF0107` + `GE_TR` |
| `GF01` | 一般公共サービス | 行政サービス (種類 `public`) と研究の予算 (種類 `research`。回 KE6。COFOG の基礎研究 GF0105。首都の家計に払うので `P3_S13` には入れない) |
| `GF0107` | 公的債務の取引 (利子) | 政府が払った利子 (種類 `interest` の支払い) |
| `GF02` | 防衛 | 軍の維持費と軍事の予算 (種類 `upkeep`・`military`) |
| `GF03` | 治安 | 治安の予算 (種類 `security`) |
| `GF04` | 経済業務 | 政府の建設 (種類 `build`) |
| `GF07` | 保健 | 医療 (種類 `health`。回 KE2。政府が会社から買う) |
| `GF09` | 教育 | 教育の予算 (種類 `education`。回 KE5) |
| `GF10` | 社会保護 | 福祉の予算 (種類 `welfare`) と年金 (種類 `pension`。回 KE2。家計への移転なので `P3_S13` には入れない) |
| `GE_TR` | 移転 (支払い) | 主人への朝貢・家臣への資金援助を送った分 |
| `GNLB` | 純貸出 / 純借入 (GFS の定義) | `GR` − `GE` |

- `GNLB` と `sna.csv` の `B9_S13` は、交易や不履行など、上の分類に入らない政府の出入りの分だけ違う。差は支出の合計の 1% より小さいことを、試験 `tools/tests/export.js` で確かめる (回 DO7。前は年金・医療・研究・研究開発の税額控除が分類から漏れていて、差が支出の約 40% あった)。
- 国の中の朝貢・資金援助は、送った側の `GE_TR` と受けた側の `GR13` の両方に出る (国でまとめても消さない。届くまでに年をまたぐため)。

### balance.csv (国 × 年の終わり。部門の貸借。SNA の部門 S と金融商品 F の符号)

| 列 | 中身 |
|---|---|
| `S14_F2_A` | 家計 (S14) の預金 (F2。資産) |
| `S14_F4_L` | 家計の借り (F4 貸出。負債) |
| `S11_F2_A` | 会社 (S11 非金融法人) の預金 |
| `S11_F4_L` | 会社の借り |
| `S13_F2_A` | 一般政府 (S13) の預金 (資金がプラスの政府の分) |
| `S13_F4_L` | 一般政府の借り (資金がマイナスの政府の、マイナスの分) |
| `S13_F3_L` | 一般政府の国債 (F3 債務証券。負債) |
| `S1N_F2_A` | 先住民 (ゲームだけの部門。SNA にはない) の預金 |
| `S1N_F4_L` | 先住民の借り |
| `S122_F2_L` | 銀行 (S122 預金取扱機関) の預金 (負債) = 部門の預金の合計 |
| `S122_F4_A` | 銀行の貸出 (資産) = 部門の借りの合計 |
| `S122_F3_A` | 銀行が持つ国債 (資産) |
| `S122_RES_A` | 銀行の中央銀行への準備 (資産) = `S122_F2_L` − `S122_F4_A` − `S122_F3_A`。銀河全体では試合の始めからあるお金 M₀ で、届く途中の荷の代金の分だけ動く (`docs/money.md` の 5.4) |

### rates.csv (国 × 年。物価と金利)

| 列 | 中身 |
|---|---|
| `CPI` | 国の物価の指数 (始め = 1。`cpiOf`) |
| `INFL` | 国の物価の上がり方 (年あたり。0.02 = 2%。`inflOf`) |
| `IRS` | 政策金利 (年あたりの名目。首都の中央銀行。`cbRateAt`) |
| `IRL` | 長期 (10 年) の国債の利回り (政府ごとの値を国債の額で重みをつけた平均。国債がなければ首都の値。`longYield`) |
| `CB_RULE` | 1 = 政策金利を中央銀行に任せている、0 = 自分で決めている |

### prices.csv (星系 × 年の終わり。市場の値段)

| 列 | 中身 |
|---|---|
| `system` | 星系の番号 |
| `food`・`water`・`metal`・`fuel`・`rare`・`goods`・`slaves`・`hitech` | 資源ごとの、その星系の市場の値段 (cr / ゲームの量の単位。`price`)。`goods` は低付加価値物品、`hitech` は高付加価値物品 (回 KE5。`docs/structure.md` の 9) |

`country` はその星系の国。

### trade.csv (年 × 輸出国 × 輸入国 × 品目。CEPII BACI の形)

| 列 | BACI の列の意味 | ゲームでの中身 |
|---|---|---|
| `t` | 年 | その年に送り出した荷 |
| `i` | 輸出国 | 荷を送った星系の国 |
| `j` | 輸入国 | 荷が届く星系の国 |
| `k` | 品目 (BACI は HS6) | 資源の名前 (`prices.csv` の列と同じ) |
| `v` | 額 (BACI は千ドル、本船渡し) | 送った星系の市場の値段 × 量 (cr) |
| `q` | 量 (BACI はトン) | ゲームの量の単位 |

- 国の中の輸送 (`i` = `j`) は入れない (BACI と同じく国の間の交易だけ)。
- 交易路の荷 (`shipCargo`) だけを数える。建設の資材と入植船の荷は入れない。

### wars.csv (戦争 1 つ = 1 行。COW の国家間戦争の形)

| 列 | 中身 |
|---|---|
| `WarNum` | 戦争の番号 (銀河の中だけ) |
| `WarName` | 2 つの国の名前 |
| `StartYear` | 宣戦の年 |
| `EndYear` | 終わった年 (続いていれば空) |
| `Initiator` | 宣戦した国の番号 |
| `Outcome` | `peace` 講和・`other` 国がなくなったなど・`ongoing` 試合の終わりに続いている |
| `BatDeath` | 艦隊戦と攻撃の戦死者の合計 (人。仮の値の乗員の数から。`docs/` の艦隊戦) |

- COW は 3 か国以上の戦争を 1 つに数えるが、ゲームの戦争は 2 国の組で宣戦と講和をするので、組ごとに 1 つの戦争にした。同じ 2 国がまた戦えば、別の戦争。
- 戦死者は戦争ごとの合計だけ (どちらの側の死者かを分けない)。

### wars_part.csv (戦争 × 参加国。COW の参加国の表の形)

| 列 | 中身 |
|---|---|
| `WarNum` | `wars.csv` の戦争の番号 |
| `ccode` | 参加国の番号 (`country` と同じ) |
| `StateName` | 参加国の名前 |
| `Side` | 1 または 2 |
| `StartYear`・`EndYear` | 参加した年と、終わった年 |
| `Initiator` | 1 = 宣戦した側 |

### policy.csv (政策の出来事。Romer & Romer の記録の形)

「何年に、どの国が、どの政策を、いくつからいくつに変えたか」を 1 件ずつ。年ごとに国の政策の値を比べ、前の年と違ったものを書く。

| 列 | 中身 |
|---|---|
| `policy` | 政策の名前 (下の表) |
| `from` | 前の値 |
| `to` | 後の値 |

| 政策の名前 | 中身 |
|---|---|
| `tax`・`ctax`・`tariff` | 所得への税・消費税・関税の率 |
| `cb_rule`・`rate` | 政策金利を中央銀行に任せるか (1 / 0) と、自分で決めたときの政策金利 |
| `deficit` | 赤字の上限 (GDP に対する割合) |
| `budget_welfare`・`budget_security`・`budget_military` | 機能ごとの予算 (税収に対する割合) |
| `policy` | 国家方針 (`expand`・`consolidate`・`military` など。ないときは空) |

- 国の財政は、首都で効いているもの (`fiscalFor(国, 首都)`)。変えた知らせが光速で遠い星系に届くまでの遅れは、この表には出ない。
- 人の国が画面で変えたものと、AI の国の決まりで変わったものの両方が入る。中央銀行に任せた政策金利の毎年の動きは、規則で決まるので出来事にせず、`rates.csv` の `IRS` に出す。

## 4. 分析の例 (`tools/export_example.py`)

| 例 | 使う表 | 現実のどれと同じ計算か |
|---|---|---|
| テイラー則 | `sna.csv`・`rates.csv` | 政策金利を物価の上がり方と景気のずれに当てる (Taylor 1993) |
| 国家間戦争の多さ | `wars_part.csv`・`sna.csv` | 国 100 年あたりの戦争の始まり (目標 R29。COW) |
| 財政と国債 | `gfs.csv`・`balance.csv` | 純貸出 ÷ GDP・国債 ÷ GDP (JST・IMF の GFS) |
| 交易の開き具合 | `sna.csv` | (輸出 + 輸入) ÷ GDP |
| 政策の出来事の数 | `policy.csv` | — |

手元の例 (10 銀河 × 150 年 × 6 か国、2026-10-23 の main。1 分ほど):

| 例 | 値 | 読み方 |
|---|---|---|
| テイラー則 | 政策金利 = 0.0100 + 1.683 × 物価の上がり方 + 0.001 × ずれ (10,041 国・年) | 物価の係数は Taylor の 1.5 に近い。ずれの係数がほぼ 0 なのは、ゲームの中央銀行のずれ (伸びの速さのずれ。`docs/money.md` の 5.3) と、この例のずれ (国の平均からの伸びの差) が違うため |
| 国家間戦争 | 国 100 年あたり 1.05 | 現実 (COW) は 2.338。目標 R29 は 6 か国・300 年の自動対戦で別に測る |
| 財政と国債 | 純貸出 ÷ GDP の中央値 −0.0029・国債と借り ÷ GDP の中央値 0.36 | |
| 交易の開き具合 | (輸出 + 輸入) ÷ GDP の中央値 0.0000 | 国の間の交易がない国が多い (交易路はほとんど国の中) |
| 政策の出来事 | 16 件 (どれも国家方針) | AI の国の財政は決まった値のまま (`aiFiscal`)、観戦の地球も財政を変えないので、税や金利の出来事は人が遊んだ試合でしか出ない |

## 5. 試験 (`tools/tests/export.js`。CI の export。落ちたら止める)

1 銀河 × 120 年で、表の列がこの文書にすべて載っていること、輸出の合計 = 輸入の合計 = 交易の表の額、GFS と貸借の表の恒等式、わざと変えた消費税が政策の出来事に 1 件出ること、戦争の参加国が 2 つであることを確かめる。

## 6. まだのこと

- ゲームの中の「データを書き出す」ボタン (同意の仕組みを通す) は、画面と最初の体験に頼んだ (`docs/notices/GA/2026-10-23-DO-export-button.md`)。
- 星系 × 年の SNA と財政は、まだ書き出さない (DO-4 で「国 × 年の核」を選んだので)。
- 通信の遅れを連続に動かす事前登録の実験 (B-109) は、この道具の上で行う。
