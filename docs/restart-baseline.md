## 7. すべての目標の合否 (版 11)

新しく測ったものと、各レーンの文書と PR に書いてあるいちばん新しい測った値を集めた。
「P6 の前」= #161 (物理をゲーム版に入れた) より前、「H3 の前」= #165〜#168 (従属国の型) より前、「C-22 の前」= #172 (人間でない国の財政を既定に戻した) より前に測った値。#173 と #174 は CI でゲーム版の遊びの数が main と ±0% だった (#173 は短い航路の遮蔽だけ変えた) ので、#172 で測った値はいまの main の値として使える。
