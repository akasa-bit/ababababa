# 首都と開拓星系の所得の差 (2026-10-24)

ユーザーの問い (2026-10-24):「人件費の概念を足したら、産業が給与の安い開拓中の星系に移って、首都との格差も下がるんじゃない？」。調べると、格差の主な原因は賃金の仕組みがないことではなく、**開拓星系に工業の原料が届かないこと**だった。原料の届け方を直す A を先にし (この文書の 2)、賃金と民間の資本 B は別の回 (KE5) にする (3)。測る道具は `tools/region-gap.js`。

## 1. いまの差 (回 KE4 のあとの main。8 銀河 × 150 年 × 6 か国、終わりの年)

| | 値 |
|---|---|
| 首都の 1 人あたりの所得 (人口の重みの平均) | 55,971 ドル (2011 年のドル) |
| 首都でない入植地 (人口 50 万人以上) の所得の 10%・50%・90% 点 | 66・115・1,917 ドル |
| 首都でない入植地の人口の重みの平均 ÷ 首都 | 0.6% |
| 国の中の星系どうしの β 収束 (10 年の伸びを初めの所得に当てる) | 年 0.13% |
| 首都でない入植地のうち、工業が動いているもの | 1% |

現実の国の中の地域の差は数倍で (正確な幅は B の目標で DOSE から計算する。3.3)、収束は年 約 2% (Barro & Sala-i-Martin 1992・Gennaioli ほか 2014)。ゲームの開拓星系は、生きていける水準 (年 数百ドル) も下回っている。

### 1.1 なぜ貧しいか (1 つの開拓星系を分けて見た)

1. **首都でない入植地は、どれも燃料の鉱脈が 0**。燃料は岩石惑星に少なく (148 のうち 6)、ガス惑星・氷の巨大惑星・ミニネプチューン (前哨基地) と首都にある。工業品 1 を作るのに燃料 0.2 が要る。
2. 燃料がないので工場が止まり、工業品の値段が上限 (1.0) に張りつく。食料は作りすぎて底値になり、作った分の 1〜4 割しか売れない。物価 (工業品を含む) で割ると所得が消える。人の 4〜6 割は自給 (`home`)。
3. 交易の注文は「実際に使った量」から決まる。工場が止まると使った量は 0 で、工業の人は下限の 0.1% しかいないので、要る量も注文の最小 (0.5) に届かない。注文が出ないので原料が来ない。
4. 注文が出ても、首都の売れる余りがマイナスだった。売り手は「自分の消費の 2 年分」を残してから売る (市場が入る前の値)。大きな首都は工業で燃料を年 6 万単位以上使うので、6 万単位の在庫があっても売れる分が残らない。買い手が目指す在庫の厚さ (`MARKET.cover`) は 0.28 年なので、売り手だけが 7 倍の厚さを抱えていた。 (A では直していない。揃えると R01 が崩れた。2.2)
5. 交易路のない開拓星系 (2〜3 割) は、そもそも取り寄せられない。

## 2. A: 原料の届け方を直す (回 KE4 のあと)

| 直したこと | 場所 |
|---|---|
| 工場が原料の不足で使えなかった金属と燃料を、交易の買い手が見る需要に足す (`flow.short`) | `market-economy.js` の 2・`trade.js` の `use` |
| 地元で作れば儲かる (工業品の値段 > 原料の値段) のに作れていない工業品 (市場の需要 − 星系の工場の生産) の原料も、取り寄せる合図にする (輸入の代わりに地元で作る) | `market-economy.js` の 2 のあと |

### 2.1 結果 (`node tools/region-gap.js`。8 銀河 × 150 年 × 6 か国)

| | main | A |
|---|---|---|
| 入植地・星系・総人口 | 64.1・34.8・76,859 | 65.9・34.8・77,749 |
| 首都でない入植地の所得の 10%・50%・90% 点 | 66・115・1,917 | 65・172・5,723 |
| 首都でない入植地の人口の重みの平均 ÷ 首都 | 0.6% | 14.8% (大きな入植地いくつかで上がった。中央値で見るほうが当てになる) |
| 人口 50 万〜500 万人の入植地の工業の就業 | 0.2% | 1.7% |
| 工業が動いている首都でない入植地 | 1% | 7% |
| 国の中の β 収束 | 年 0.13% | 年 0.88% |
| 止まっている理由: 交易路はあるが工業に人がいない・交易路がない・原料待ち | 80%・19%・— | 64%・23%・5% |
| R01 交易と距離 (30 銀河 × 300 年。幅 −1.174〜−0.574) | −1.006 ✓ | **−0.225 ✗** |
| 財政の目標 R19〜R22・R27・R28・R33〜R35 (30 銀河 × 150 年) | すべて合格 | すべて合格 (R21 0.57 → 0.67・R27 0.149 → 0.196) |

**R01 が外れる** (ユーザーの決定 2026-10-24: A を入れ、R01 は B で見直す)。燃料を持っているのは首都と前哨基地だけなので、開拓星系が燃料を買い始めると、距離に関係なく遠くの首都から買うことになり、「近い相手ほど多く交易する」形が薄まる。足りなかった原料を注文に数えるだけの、いちばん小さい版でも −0.39 で外れた。現実でも産地の限られた品 (石油など) は距離が効きにくいので、B では R01 を品ごとの距離の効き方と一緒に見直す (3.3)。

開拓星系の所得の効き目は控えめ。原料は届き始めたが、開拓星系の市場は小さく (人口 50 万〜500 万人)、工業品の需要も小さいので、工場が育つ前に止まる。差の大部分は B (3) で扱う。

### 2.2 試してやめたこと

| 試したこと | 結果 | やめた理由 |
|---|---|---|
| 工業に人がいないときの稼ぎを「最初の 1 人なら稼働 1」で見る | 変わらない | 工業の人は下限の 0.1% が必ずいるので、効く場面がなかった |
| 人が部門を選ぶとき、原料は「在庫 + 注文して届く予定の分」で 1 年動けるかで見る (`indPlan`) | 首都でない入植地の所得の人口の重みの平均は 4 倍 (首都の 2.2%)。だが人口 2〜10 百万人の開拓入植地が 3.4 → 1.6 / 銀河に減った | 原料が来る前に人が工業に移り、開拓星系が育ちにくくなる。見込みで先に動くのは、B の会社の投資 (原料の手配まで会社が持つ) で扱う |
| 売り手が売らずに残す在庫を、自分の消費の 2 年分から市場の在庫の厚さ (`MARKET.cover`。0.28 年) に揃える (1.1 の 4) | 首都の燃料が売れるようになり、取引の組が 3 倍。だが R01 (交易と距離) が −1.006 → −0.42 で不合格 (遠さが効かなくなる)。開拓星系の所得の中央値も 172 → 151 と、外した版より低い | 首都の大きな在庫が遠くまで売られ、交易の地図が変わりすぎる。売り手の残す量は、B で会社が在庫と販売先を決める形にするときに一緒に見直す |
| 人が部門を選ぶとき、工業の原料の不足を見ない | 開拓星系の所得 10 倍・入植した星系 25 → 8.6 | 原料のない工場に人が集まり、首都も含めて広がりが止まった |
