# 従属国の事例のデータと、型ごとの存続 (レーン H・セッション H2-1)

2026-10-21。H1 で決めた 19 型 (`docs/vassal-typology.md`) と、いまの「直接統治」にあたる植民地 (直轄、T20) の事例を集め、主権の束 (8 項目 × 法と実態の 2 層) で符号化し、型ごとの存続と移り変わりを推定した。**コードは変えていない** (`data/` だけ)。目標の登録は「目標の変更」の PR で別にする (H2-2)。

- 生データと符号: `data/raw/vassal/` (README・コードブック・事例 131 件・2 回の符号化・裁定・条件・ISD・Lake・Seshat・COW の従属の隣接)
- 加工: `python3 data/build/build_vassal.py` → `data/derived/vassal.json` (事例ごとの最終の束・一致の度合い・ISD と ICOW との突き合わせ)
- 解析: `python3 data/build/analyze_vassal.py` → `data/derived/vassal_survival.json` (Kaplan–Meier・Cox・移り変わり・暴力の割合・QCA・条件と型)

## 1. 事例の集め方

- 20 型 × 5〜8 件、合わせて 131 件。型が分かれるように、条約の本文と研究がそろう事例を選んだ (無作為の標本ではない)。続いているもの (自由連合の 5 件) は打ち切りとして扱う。
- 事例ごとに、始まりと終わりの年・終わり方 (独立・別の宗主や型へ・併合・宗主の消滅・合併・続いている)・終わりが暴力を伴ったか (終わりの前 5 年に従属国の側の組織的な武装闘争があったか。ICOW の IndViol に近づけた)。
- 条件 (H3-2 で AI の型を決める材料): 首都間の距離・人口の比の桁・文化の近さ・陸続きか・直前の状態・宗主の種類。手で符号化した (`data/raw/vassal/conditions.csv`)。

## 2. 符号化と一致の度合い

2 人の符号者が別々に符号化した。A は型の順に型の説明を手がかりに、B は始まりの年の順に**型を伏せて**符号化した。食い違いは、3 人目が 2 人の根拠と出典を並べて裁定した。

| | 値 |
|---|---|
| 符号の数 | 2096 (131 件 × 16) |
| 一致率 | 84% |
| Krippendorff の α (名義) | **0.754** (法 0.767・実態 0.742) |
| 一次史料の本文を読んだ事例 | A 27・B 23 |
| 食い違いの裁定 | 335 か所。A を採った 141・B を採った 194・不確か 12 |

α は 0.80 (Krippendorff の「確かな結論に使える」線) に届かず、0.667〜0.80 の「暫定の結論なら使える」水準。いちばん低いのは実態の継承 (0.64)・実態の軍事 (0.68)・法の任免 (0.68)。

食い違いの多くは、3 つの系統的な読みの違いだった (裁定者の報告):

1. **実態を法の層に持ち込む**: 冊封の儀礼・回賜で相殺される朝貢・宣教の学校・1 回の廃位などを法の列に入れた。裁定では、法は条約・勅許の文だけから決めた。
2. **宗主の軍の駐留と自前の軍が並ぶとき S か M か**: コードブックの例「自前の軍 + 駐留協定 = M」に合わせ、同意のない駐留・従属国の軍の禁止や上限・軍の直接の指揮だけを S にした。
3. **継承と任免の「統治者」はだれか**: 自治領と自由連合で、王位の継承が宗主の法に従う所は S、現地の統治者がいる所 (首長・大統領) は M にした。

裁定者が 2 人の挙げていない条約で決めた所が 3 か所ある (エジプト 1879 年のファーマーン・日満の経済委員会 1935・ロクナー協定の学校の約束)。H4 で史料の欄を作るときに原文で確かめる。

## 3. 生データとの突き合わせ

- **ICOW** (`data/raw/history/icow_colhist.csv`): 同じ出来事 (独立の年が ±3 年) を載せている 25 件のうち 24 件で、暴力の有無が一致した。食い違う 1 件はアフガニスタン (1919 年。ICOW は暴力なし、事例は第三次アフガン戦争を暴力ありとした)。ICOW はチュニジア・モロッコの 1956 年を独立と数えていない (1591 年・1666 年を独立とする) ので、保護国の終わりは ICOW で確かめられない。
- **ISD 2.2**: 1816 年以降の 85 件を国名で結びつけた (`vassal.json` の `checks.isd`)。ISD は「主権の曖昧さ」(Sovereignty_Am) を持つが、従属の型の変数はない。
- **Lake 2009**: 1950〜2000 年に重なる 19 件で、米に対する上下関係の指標を平均した。衛星国は米の指標が 0 で、ワルシャワ条約の加盟 (0.58〜0.88) でしか従属が見えない。Lake の指標は米の側の上下関係だけなので、ソ連の衛星国の実態は測れない。
- **Seshat Equinox-2020**: 1816 年より前の事例の宗主の政体の年代を添えた。「上位政体との関係」の符号は Equinox の公開版に入っていなかった (H1 の書き方を直した)。

### 条件と型の家族 (AI の型の決め方の材料)

- 陸続きの従属は、君主と封の網 (38%) と儀礼の宗主権 (28%) が多い。海を隔てた従属は、条約の保護 (30%)・直轄 (23%)・入植者の自治 (17%)。
- 海の帝国の従属は、条約の保護 (38%)・入植者の自治 (22%)・直轄 (21%) で、儀礼の宗主権はない。陸の宗主は、君主と封の網 (34%)・儀礼の宗主権 (26%)。
- 文化が遠い従属は、条約の保護 (36%) と直轄 (26%)。文化が近い従属は、君主と封の網 (30%)・入植者の自治 (19%)・儀礼の宗主権 (17%)。

## 5. 限界

- 事例は有名なものに偏る (無作為でない)。型ごとの件数が少なく (5〜8)、型ごとの値は目安。目標には家族ごとの値と、事例全体の Cox の係数を使う。
- 符号化の一致は α = 0.75 で、「暫定の結論なら使える」水準。文書館の史料には当たっていない。
- 「法」の層は期間の大半の条約の形で、途中の条約の変化 (保護国 → 併合など) は 1 組の符号に畳んだ。
- 条件 (距離・人口の比・文化) は桁と常識の判定で、正確な値ではない。
