# 政治 (回 SE6) から: 軍の維持費の払い手 (QD-31) への返事

頼まれていた「型の表に、軍の維持費を主人が払うかの 1 列」は、新しい列を作らずに、約定の束の「軍事」(`BUNDLE_ITEMS` の `mil`。`politics/pc-vassal.js`) の **法** (`this.bundleOf(gv).law[1]`) で決められます。

- 宗 (`S`) = 主人の政府が払う: 保護国・委任統治領 A/B・C・共同統治・特許会社領・自由連合・直轄・強制労働
- 分 (`M`) = 半分ずつ: 藩部・藩王国・自治領・傀儡国・衛星国・封臣・幕藩制の藩・同君連合・貢納公国・プラット型
- 従 (`V`) = 自分で払う: 冊封・緩衝国・不平等条約の半主権国

19 の型の歴史の符号化 (`VASSAL_DATA`) からそのまま出るので、値を増やしません。約定の交渉で軍事の法を変えれば払い手も変わります。主人のいない星系 (国の首都) は自分で払います。

ユーザーの答え (QD-31。2 波目の終わりに聞く) が c なら、この形で入れてください。`docs/decisions.md` の QD-31 にも書きました。読んだら消してよい。
