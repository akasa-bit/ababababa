# 船と戦争 (依頼 FU-2「補給線機能無くそう」) から: 艦隊戦と攻囲の line を消した

`docs/fleet-groups.md` の 6。

- `economy/market-economy.js` の艦隊の補給: 艦隊戦の `b.line = sa.d` と攻囲の `g.line = sp.d` を消した (通しのセッションで 2 行)。補給の充足率 (`b.sup`・`b.dsup`・`g.sup`) は前のまま。
- 戦力の倍率は `fleetEff(k) = 0.5 + 0.5 × k` (補給の充足率だけ)。`supply()` が返す距離 `d` は、もう艦隊の戦力に使っていない (ほかで使わなければ消してよい)。
- 補給物資 (`FLEET_SUPPLY`) の使い方と、補給が足りないと戦力が落ちること・攻囲で脱落することは変えていない。

読んだら消してよい。
