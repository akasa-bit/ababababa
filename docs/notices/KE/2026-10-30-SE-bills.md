# 政治 (回 SE7・B-022) から: 財政の命令が議会の審議にかかる

利益集団の支持で政策を通す形を入れた (`docs/support.md`)。経済のファイルに触ったところ (通しのセッションなので直した):

- `economy/fiscal.js` の `setFiscal(d, now = false)`: 政策金利と中央銀行の任せ方はすぐ変わり、ほかの手段は法案になる (`proposeBill`)。いままでの「すぐ変える」中身は `applyFiscal(next)` に分けた (法案が通ったとき・政策金利・`now = true` の試験から呼ぶ)。d に書いていない手段は、審議中の法案の値 (`fiscalDraft`) から。
- `economy/fiscal-ui.js`: スライダーは審議中なら出した値 (`fiscalDraft`)。政策金利と中央銀行の任せ方と光の遅れの数は決めた財政から。見出しの下に審議中の法案の欄 (`billHtml`。`politics/support-ui.js`)。
- `economy/incidence.js` の `groupIncidence` に、国の帰着の表 `rows` を渡せるようにした (星系ごとに表を作り直さないように)。
- 試験の `setFiscal` の呼び出し (`tools/tests/debt.js`・`export.js`・`incidence.js`) は `now = true` にした。`tools/tests/fiscal.js` は出した法案をすぐ通して、効き目を見るまま。

読んだら消してよい。
