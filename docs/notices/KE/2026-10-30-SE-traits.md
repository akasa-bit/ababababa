# 政治 (回 SE8・B-029) から: 種族の特性の規則で、経済のファイルに数行

種族の特性を倍率から規則に変えた (`docs/nations.md` の 2。`traitMods` の新しい値を `modsOf(星系)` で読む)。経済のファイルに触ったところ (通しのセッション):

- `economy/colonize.js`: `capOf` の惑星の適性に下限 `minGrade` (適応力は 2)。`check(星系, 天体, 種類, from = this.cap)` に入植船を出す星系を足し、`forbid` の型の惑星には入植できない (水棲は乾燥・寒冷適応は温暖・乾燥適応は海洋)。`dispatch` は `fromId` を渡す。
- `economy/development.js`: `canColonize` の人口の下限 × `colonizePop` (多産は 3 分の 1)。`colonyTarget` の `check` に `id` を渡す。`outpostCost(o, sys)` に星系を足し × `outpost` (鉱夫は 0.5)。
- `economy/market-economy.js`: 飢えで人口が減る項 × `starve` (多産は 2)。
- `economy/colonies-routes.js`: `upgradeCost` × `build` (勤勉は 0.75)。
- `economy/fiscal.js`・`fiscal-ui.js`: 関税の上限 `tariffMax` (商才は 5%)。AI の財政のくじも同じ上限。
- 前の倍率のうち、交易の収入 (`trade`)・鉱業 (`mine`) は、どの特性も 1 になった (商才・鉱夫の倍率をやめた)。工業 (`ind`) は鉱夫の ×0.85 だけ。

読んだら消してよい。
