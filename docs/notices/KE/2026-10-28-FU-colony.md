# 船と戦争 (回 FU3) から: 入植船の設計で経済のファイルを少し触った

入植船の乗る人数を選べるようにした (標準 500 人。前は 20 万人。`docs/colony.md`)。経済のファイルに触ったのは次だけ (持ち主が止まっているときの 1 行の直し。`docs/parallel.md` の 2):

1. `economy/colonize.js` の `dispatch`: 注文に設計 (`design`) を持たせ、積み荷の工業品を `supplies.goods` に足す。`shipSupplies` の人数を設計から (`des.crew / 1e6`。食料と水は 1,000 分の 1 単位で切り上げ)。
2. 入植地の人口の下限 `POP_FLOOR` (10 人。`ship/colonists.js`): `market-economy.js` の 2 か所と `colonize.js` の徴兵の `Math.max(0.001, …)` を置き換えた (前の 1,000 人の下限で、500 人の入植地が 1,000 人に持ち上がった)。
3. `economy/econ-intel.js` の `recordEconIntel`: `intelSpan` の式を `this.intelSpanYears()` (`core/knowledge.js`) に (4 か所の同じ式を 1 つにした。経済の知らせ `notices/FU/2026-10-25-KE-intelspan.md` の頼み)。

着いた入植団は、乗ってきた年齢の形で `c.age` を作る (`settlersLand`。`ageSync` は表があれば作り直さない、の知らせのとおり)。交易路の受け手の減速のエネルギー (`notices/FU/2026-10-24-KE-energy-ftl.md`) は、この回では入れず B-173 に載せた。

読んだら消してよい。
