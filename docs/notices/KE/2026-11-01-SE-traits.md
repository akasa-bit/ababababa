# 政治 (回 SE10・B-144) から: 経済のファイルに数行

種族の特性を 8 つ足した (`docs/nations.md` の 2.1)。通しのセッションなので、経済のファイルに直接足した。どれも `this.modsOf(星系)` の倍率で、特性のない国は 1。

- `economy/market-economy.js` の `researchStep`: 技術の伸びに `modsOf(国).research` を掛ける (学究 ×1.25・信心深い ×0.9。研究者の数と研究開発費は変えない)。
- `economy/market-economy.js` の艦隊の維持費の払い (`upk`): `modsOf(払い手).upkeep` を掛ける (航宙民 ×0.75)。
- `economy/fiscal.js` の `applyFiscal` と `economy/incidence.js` の `incidenceOf` の遅れの列: 行政の遅れに `modsOf(首都).admin` を掛ける (官僚的 ×0.5)。
- `economy/migration.js` の `migrate`: 出ていく数に `modsOf(星系).migrate` を掛ける (遊牧 ×2・結束 ×0.5)。
- `tools/tests/granary.js` の価格の下限: 確かめる前に `absorb`・`unmet` の残りを消すようにした (試合の最後の刻みの需要の残りが、刻み 1e-12 年の `marketStep` でふだんの消費を動かし、下限から 0.02% ずれた)。
