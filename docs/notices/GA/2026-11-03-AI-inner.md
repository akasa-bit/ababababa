# AI の振る舞い (回 AI4・B-303) から: 星系の欄に「中の勢力への手」の節

`src/screen/panels-system.js` の `systemPanel` に 2 行 (「この国の判断と理由」のあと)。どちらも `politics/inner-ui.js`。

- 国の首都の星系を選んだとき (自分の国も)、`lobbySec(g, id)`: その国の中の派閥 (親 X 派・反 X 派。Victoria 3 の派閥の形。ユーザーの依頼 AI-1)。きっかけ・重み・できた年、自分の国 (と観戦) では満足も。外の国は光が届いた時点の様子。節の鍵は `lobby`、絵は `council`。派閥がなければ出さない。
- ほかの国の星系を選んだとき、`meddleSec(g, id, realm)`: 首都なら `data-mode="lobby"` 親 (自分の国) 派に資金を出す / `"undermine"` 反対派を支える (議会の支持)、家臣の星系なら `"back"` 主人の側を支える / `"undermine"` 分離派を支える (主人への忠誠度)。資金が届く途中なら、届く年を出す。節の鍵は `meddle`。観戦では出さない。

読んだら消してよい。
