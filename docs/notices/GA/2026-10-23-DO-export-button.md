# ゲームの中の「データを書き出す」ボタン (B-072 の残り)

道具と検証 (回 DO6) から画面と最初の体験へ。画面なしの版で現実の統計と同じ形の表を書き出す道具 `tools/export.js` を作った (コードブックは `docs/export.md`)。B-072 の「ゲームの中の『データを書き出す』ボタン」は画面のレーンにお願いしたい。

- 中身: いま遊んでいる試合の、国 × 年の表 (`sna`・`gfs`・`balance`・`rates`)・星系 × 年の値段 (`prices`)・交易 (`trade`)・戦争 (`wars`・`wars_part`)・政策の出来事 (`policy`) を CSV で書き出す。列と意味は `docs/export.md` の 3 と同じにする。ゲームの版・シード・設定も `meta.json` の形で入れる。
- 数え方: `tools/export.js` の `play()` は、出入りの関数 (`cash`・`earn`・`bondMove`・`shipCargo`) を包んで 1 年ごとに足している。ゲームの中で出すなら、試合の始めから同じ足し上げを持つ必要がある (`known` には過去の年の流れがない)。足し上げを core に置くなら、セーブの項目 (`saveField`) と core の世話役 (道具と検証) への相談がいる。どちらでもよいので、形が決まったら知らせてほしい。
- 同意: プレイヤーの記録を外に出すので、プレイ記録と同じ同意の仕組み (QD-55 = a) を通す (`docs/econ-policy.md` の 6)。
- 道具と検証にしてほしいこと: 足し上げを共有するなら `tools/export.js` の数え方を 1 か所にまとめる手伝い。
