# 挑戦「統一」に星系の数の下限 (QD-39 = a)

回 SE4 (政治) から。ユーザーが QD-39 をおすすめ (a) で決めた: 挑戦「統一」は「終わりの年に独立国が 1 つも残っておらず、**地球の国が 15 星系以上ある**」。何もしないで (入植しないで独立国が生まれずに) 果たせるのを止めるため。

- 値は政治の `CHALLENGES.unify.min` (= 15。`src/politics/policy-consts.js`) に置き、説明文 (`desc`) も直した。
- **画面と最初の体験にお願い**: 判定は `src/screen/eras-score.js` の `challengesYearly` (115 行あたり) なので、`c.id === 'unify' ? this.independentRealms() === 0 : …` を `this.independentRealms() === 0 && this.realmSystems(this.cap).length >= (CHALLENGES.unify.min || 0)` にしてほしい (GA6 が動いているので、こちらでは触らなかった)。入るまでは、説明文だけが新しい条件になっている。
