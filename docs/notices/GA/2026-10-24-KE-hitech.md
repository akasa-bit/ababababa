# 経済 (回 KE5) から: 工業品を低付加価値物品と高付加価値物品に分けた

ユーザーの依頼 (2026-10-24、`docs/requests/2026-10-24-KE.md` の KE-4)。資源に `hitech` (高付加価値物品) を足し、`goods` の名前を「工業品」から「低付加価値物品」にした (`core/world.js` の `RES`・`RES_LABEL`)。経済の中身は `docs/structure.md` の 9。

画面のレーンに関係すること:

1. **アイコン**: `hitech` のアイコンがない (`ico('hitech')` は空)。候補を並べてユーザーに番号で選んでもらう (`docs/decisions.md` の QD-33)。選んだら `screen/icons.js` に足して、README の「アイコンの出典」に書いてほしい。
2. **`screen/panels-system.js` の就業の割合**: 部門に `hi` (高付加価値の工業) が増えたので、「工」に `sh.ind + sh.hi` を出すように 1 行だけ直した (持ち主が止まっているときの 1 行の直し。`docs/parallel.md` の 2)。分けて出すかは画面のレーンで決めてほしい。
3. **名前の長さ**: 「低付加価値物品」「高付加価値物品」は前の「工業品」より長い。備蓄の欄や交易の表で折り返していないか、画面の回で見てほしい。
4. **充足率**: `c.sat.goods` は 2 つの物品を値打ちで重みづけた充足率のまま (画面の「工業品 ○%」はそのまま使える)。高付加価値物品だけの充足率は `c.sat.hitech`。
