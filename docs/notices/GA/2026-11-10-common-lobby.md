# 共通 (依頼 2026-11-10 の common-3) から: 国家選択に「ネット対戦の部屋を作る」・ホームの案内

`docs/online.md` の 4。通しのセッションで画面のフォルダを数行直した。

- `screen/nation-pick.js`: 下のボタンに「〈国の名前〉でネット対戦の部屋を作る」を、人間の国の数にかかわらず出す (前は「＋人間」が 2 つ以上のときだけ「人間 N 人・ネット対戦」)。
  押すと、自分の国 (選んでいるカード) だけを人間の席にして部屋を開く (`Net.openHost(true)`)。ほかの人は部屋の中で国を選ぶので、「＋人間」はホットシートだけのものになった。説明の文も直した。
  「歩みはじめた」の知らせと遊び方の記録 (`home`/`nation`) は、ネット対戦では、ホストが始めたとき (`Net.start`) に出す。体験版にはこのボタンを出さない。
- `screen/home.js`: マルチプレイの頁の「ホストになる」は、国が 2 つ以上ある続きのゲームなら出す (前は、人間の席が 2 つ以上のとき)。マルチプレイ・友達と遊ぶの頁の手順を部屋の流れに直した
  (ホストの 2・3 つめ、参加する人に「部屋に入ったら、動かす国を選ぶ」を足して 4 つに)。
- `screen/page.html`: 部屋の国の行 (`.lobby`・`.lrow`)・ホストの国の一覧 (`.lobbynat`) の CSS。
- `screen/nation-pick.js` の続き: 難しさの目安 (★ 1〜3) の数え方を `nationRating(g, n)` に切り出した (中身は同じ。`{ near, crowd, size, stars }` を返す)。国家選択のカード (`nationCard`) と、
  ネット対戦の部屋の国の一覧 (`outward/net.js` の `nationList`) の両方で使う。数え方を変えるときは、ここだけ直せば両方に効く。部屋の国の行の手がかりの字は `screen/page.html` の `.lrow .facts`。
- 部屋の画面は `outward/net.js` の `render` (参加者: 国の行と「この国にする」「やめる」。ホスト: 「部屋にいる人」(名前・選んだ国・「外す」) と国の一覧)。見た目の直しは歓迎。
