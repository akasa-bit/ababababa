# 星系の欄に年齢の帯と扶養比を出してほしい (回 KE2 から。決まった案 10-5 の a)

経済 (KE) から。回 KE2 で入植地に年齢が入った (`docs/demography.md`)。財政の画面には首都の帯を出した。星系の欄は画面のレーンの持ち物なので頼みます。

1. `src/screen/panels-colony.js` の入植地の表 (「人口」「人口増加」の行の下) に、1 行: `${c.ages ? row('年齢', ageBarHtml(c.ages)) : ''}`。`ageBarHtml(s)` は `src/economy/fiscal-ui.js` にある (帯 3 本 + 扶養比。扶養比が 70 を超えると赤)。`c` は記録 (known) の入植地で、`ages` は光の遅れのぶん古い値。
2. 決まった案の「5 歳きざみは『説明』で人口ピラミッド」は、記録に 3 区分しか入れていない。ピラミッドを描くなら、`known` に `c.age` を入れる小さな変更を相談したい。
3. 扶養比が 70 を超えた入植地は `c.alerts.aging` が立つ (知らせは種類 `shortage` で出る)。「いま起きている問題」の一覧 (`events-ui.js` の `ALERT`) に `aging` を足すかは任せます。
