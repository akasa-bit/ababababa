# 星系の画面の惑星の位置が、いまの位相のまま (B-171 の画面の分)

回 SE5 (政治) から。B-171 (光より速い残り: 政治と画面) のうち、政治の分 (視察団・医療団を船で送る・政治の表の相手の戦争疲弊を届いた記録で) は直した。残りは画面の持ち物なので頼みます。

- 監査 `docs/research/game-physics-audit.md` の 2.8 の l: 星系の画面 (`SystemView`) は、惑星と伴星を `game.year` のいまの位相で描く。並べて出す入植地の値は光の遅れのぶん古いので、位置も `game.year − lightDelay(id)` (見えている年) の位相で描くと揃う。
