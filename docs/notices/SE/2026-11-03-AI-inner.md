# AI の振る舞い (回 AI4・B-303) から: 協定の点に中の事情・揺さぶりの政治力・内政への干渉の記憶

`src/politics/diplomacy.js` を 2 行、`src/politics/loyalty-regime.js` を 1 行直し、`politics/inner.js`・`inner-consts.js`・`inner-ui.js` を足した。

- `pactScore`: 受け手 r の議会の支持が低いと受けにくく (批准しにくい)、相手への親 X 派があると受けやすく、反 X 派があると受けにくい (`innerPact`。`INNER.pactCouncil`・`INNER.lob.pact`)。理由の文に「中の事情: …」。
- 外の国への派閥 (ユーザーの依頼 AI-1: 内政は Victoria 3 を参考に。新しいファイル `politics/lobby.js`): 国の権力に加わっている集団 (回 SE6 の民族 × 所得の 5 分位。声の重さは回 SE7 の `billSupport` と同じ) のうち、交易・恩・恨み・外からの資金をきっかけに、外の国に向けて同じ立場をとるものが親 X 派・反 X 派になる。`makePact` に 1 行 (`lobbyAct`: 協定への派閥の満足)。満足は席の国の議会の支持を、年 重み × 満足 だけ動かす (`lobbyYearly`)。`memory.js` の `memAdd` も派閥の満足を動かす。
- `diplomacyYearly`: `leadersYearly` のあとに `innerYearly` (遠い総督の独断・首都の追認と否認・揺さぶりの到着・AI の国の揺さぶり)。
- `pcCost`: 命令 `meddle` (揺さぶり) は `INNER.meddle.pc` (15)。
- 資金が届くと、相手の首都なら親 (送った国) 派を育てる (派閥がなければできる。あれば重みが 10 年 ×1.5) か議会の支持 (`councilAdd`) を −3、家臣の星系なら主人への忠誠度を ±6 動かす。資金 150 cr は届いた年に払う (協定の贈り物と同じ。お金の種類は `grant`。主人の側への資金は相手の政府へ、ほかはその星系の家計へ)。
- 帳簿 (`politics/memory.js`) に `meddle` (内政への干渉。恨み) を足した。
- 首都が総督の独断を否認すると、その星系の忠誠度を 10 下げる。
- `src/politics/diplomacy-consts.js` の `PACT.honorLine` を −58.8 → −58.5 にした (同盟の参戦の判断から中の事情を引くようになったので、引く前の応じる割合を保つ線にした。`docs/ai-behavior.md` の 11.1)。
