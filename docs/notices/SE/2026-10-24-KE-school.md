# 経済 (回 KE5) から: 入植地ごとの学歴 (就学年数) の表を作った。SE6 の集団に使える

学歴と生産性を経済に入れた (ユーザーの依頼 2026-10-24: 「あとから SE6 と混ぜられるようにして」。`docs/hcap.md`)。政治のファイルは触っていない。

## 表の形

- `c.edu = { 鍵: { p: [21], s: [21] } }`。5 歳の区分 (年齢の表 `c.age` と同じ 21 区分) ごとの人数 `p` [百万人] と平均の就学年数 `s` [年]。区分ごとの人数の合計は、毎刻み `c.age` (男女の和) に合わせる。就学年数を持つのは 25 歳の区分 (`SCHOOL.bin` = 5) から上 (それより下は 0)
- 鍵はいまは**生まれ**だけ: `away` = よそ生まれ (入植者と移民)、`here` = ここ生まれ (この入植地で 25 歳の区分に入った人と、始めからいる人)。SE6 の決まった案の「本国生まれ / 入植地生まれ」に近い (いまの `away` は、本国以外の入植地から来た人も含む)

## 読む関数 (`economy/demography.js`)

- `schoolBy(c)`: 表そのもの (なければ作る)
- `schoolOf(c)`: 大人 (25 歳〜) の平均の就学年数
- `schoolAges(c)`: 区分ごとの、集団を合わせた平均
- `schoolMean(c, f, a0, a1)`: 区分 a0〜a1 の人の f(就学年数) の平均 (生産性は 25〜64 歳の exp(φ(s)) の平均)

## SE6 で集団を細かくするとき

- 鍵を「生まれ × 階層 × 価値観」に細かくし、それぞれの集団が `{ p, s }` を持てば、生産性と平均の決め方 (人数の重み) は変わらない
- 経済の側で人数が動く所: `eduStep` (年をとる・生まれる・c.age に合わせる)、`eduMix` (移民と入植者が来る。core の `addPeople` から呼ぶ)、`addColony` (入植者の表)。集団を細かくするなら、ここで新しい人をどの集団に入れるかを決める
- 階層 (所得の 5 分位) ごとの就学年数の差は作っていない (国の中の学歴の不平等のデータを SE6 で使う想定。`docs/hcap.md` の 2.1)

## 追記 (2026-10-25): 学力も持つようになった

学力 (教育の質) を足した (ユーザーの決定 2026-10-24「学力も効く形を足す」。`docs/hcap.md` の 4)。

- 表の集団は `{ p, s, q }` になった。`q` は区分ごとの平均の学力 (調和された試験の点数の物差し。300〜625 点)。人数で混ぜる決め方は就学年数と同じ (`eduAdd`)
- 読む関数を足した: `learnOf(c)` (大人の平均の学力)・`learnAges(c)` (区分ごとの平均)・`eduAges(c)` (`{ s, q }`。移民と入植者が運ぶ形)。`schoolMean(c, f, a0, a1)` の f は `(s, q)` を受け取る
- 学歴と学力を決める所得は、市場で測った 1 人あたりの実質の所得を 5 年でならした `c.incU` (前は生産力 `c.inc`)。SE6 で階層ごとに分けるなら、階層の所得をここに入れる形になる
