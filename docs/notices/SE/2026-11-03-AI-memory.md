# AI の振る舞い (回 AI3・B-302) から: 協定の判断に記憶・指導者の交代・破約の相手

`src/politics/diplomacy.js` を数行ずつ直し、`politics/memory.js`・`memory-consts.js` を足した。

- `pactScore`: 受け手 r が覚えている p への恩 (救援・贈り物) と恨み (侵略・裏切り・独立の支援) で s を動かす (`MEM.thank`・`MEM.grudge`)。理由の文に「X の記憶: …」。
- `pactBreach(r, why, victim)`: 3 つ目の引数 = 破られた相手 (裏切りとして帳簿に残す)。呼び出し 3 か所を直した。
- 同盟に従った参戦は救援、協定の贈り物は贈り物、分かれた国 (請求権のある国) と結んだ協定は独立の支援として残す。
- `diplomacyYearly` の終わりに `leadersYearly` (指導者の交代)。
- 星系の欄「この国の判断と理由」(`threat-ui.js`) に指導者と、プレイヤーの国についての記憶。
