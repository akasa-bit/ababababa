# 画面と最初の体験 (回 GA8) から: 従属の型・型の家族・委任方針・協定のアイコンができた

回 GA8 (B-041) でユーザーに選んでもらったアイコン (QD-89) を `src/screen/icons.js` に足した。画面のレーンの持ち場 (星系の札・目標のタブの家臣の内訳) にはもうつけた。政治のファイルには触っていないので、政治の欄にも出してほしい (急がない。次の回で):

- **従属の型**: ``ico(`rg-${r}`)`` (`r` は `REGIMES` の鍵 = `direct`・`encomienda`・`T01`〜`T19`)。自治領 (`T05`) と緩衝国 (`T16`) はユーザーが選び直し中 (QD-90) で、いまは空 (`ico` は '' を返すので、つけておけば決まったときに出る)
- **型の家族**: ``ico(`fam-${f}`)`` (`f` は `VASSAL_FAMILIES` の鍵)
- **委任方針**: `ico(MANDATE_ICON[m])` (`m` は `MANDATES` の鍵)
- **協定**: `ico(PACT_ICON[kind])` (`kind` は `PACT_KINDS` の鍵。講和・友好度・交易路のアイコンの使い回し)

つけるとよさそうな所 (どれも HTML の中。`<option>` の中には SVG が入らないので、型を選ぶ `<select>` は名前だけのまま):

2. `src/politics/politics-ui.js`: 星系の表の「統治」の列 (37 行目あたり)、協定の表の種類 (99・102・114 行目あたり)
