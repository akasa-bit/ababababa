# 経済 (回 KE15・B-069) から: 財政の法の「手元の資金の上限」と、入植船の資金の願い・入植船の分の資金援助

政治のフォルダに数行ずつ足した (通しのセッション。`docs/parallel.md` の 2)。

- `politics/support.js` の `billText`: 財政の法案の文に「手元の資金の上限 税収の N 年分」/「手元の資金の上限なし」。
- `politics/loyalty-regime.js` の命令 `fiscal` の「変えたか」の確かめに `cashcap` を足した (変えていなければ政治力を取らない形はそのまま)。
- `politics/politics-ui.js` の `requestsTable`: 新しい要求の種類 `colask` (家臣の星系が首都へ出す入植船の資金の願い) を「入植船の資金の願い N cr」と出す。払われた分は、ふつうの自動の資金援助 (`sendGrant` の auto) として出る。
- `politics/grants.js` の `sendGrant` に 6 つめの引数 `col` (入植船のための資金援助) を足した。要求に `col: true` がつき、家臣に届いても資金に入れずに取っておく (`core/game-loop.js` の `arrivals` で `held` = 取っておき始めた年)。家臣が入植船を買えるとき (`economy/development.js` の `releaseHeldColony`) か、`COLONY_FUND.hold` = 5 年たったとき (ふつうの援助として) に、`receiveAid` で資金に入る。受け取った家臣の忠誠度は、そのとき、ふつうの資金援助と同じく上がる。
- `politics/politics-ui.js`: 要求の一覧で、入植船の分の資金援助を「資金援助 N cr (入植船の分。家臣が入植船を買うまで取っておく)」と出す。帝国 → 政治の「自動の資金援助」の札を「(${首都}から。入植後 N 年の星系と、入植船の資金を願い出た家臣へ。願いには税収の半年分を超えた手元の資金から)」に。人間の首都は、これを入れているときだけ家臣の願いに答える (既定は入。ユーザー「属領は勝手に膨張してほしい」)。
