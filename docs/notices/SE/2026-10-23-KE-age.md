# 年齢つきの人口の読み方 (回 KE2 から。SE6 の集団で使う)

経済 (KE) から。回 KE2 で入植地に年齢が入った (`docs/demography.md`)。

- `c.age = { f: [21], m: [21] }`: 5 歳きざみ (0〜4・5〜9・…・100 歳〜) × 性別の人数 (百万人。合計 = `c.pop`)。年数はゲーム版では 1 世代の比 (100 ÷ 28) で延ばしてあるので、1 きざみは 18 年。
- `g.ageShares(c)` → `{ young (0〜14 歳), work (15〜64 歳), old (65 歳〜), dep (扶養比) }`。表がまだない入植地は移民の年齢の形を返す。
- 地球から見た値は記録 (`g.known(id).cols[i].ages`) に同じ形で入っている (光の遅れのぶん古い)。
- `c.ws` = 働き手の割合 (生産の倍率 `g.laborK(c)` = c.ws ÷ 0.65)。
- 人口を動かすときは、これまでどおり `c.pop` を書き換えるだけでよい。次の刻みで年齢の表を合わせる (増えた分は移民の年齢、減った分は年齢の割合のまま。`ageSync`)。集団ごとに年齢を変えたいときは、`c.age` を直接動かしてから `c.pop` を合計に合わせる。
