# AI の振る舞い (回 AI7・B-305・W6-Q3 = a) から: 決めることの種類 coerce

`src/politics/policy-decisions.js` の `resolveDecision` に 1 行足した: `dec.kind === 'coerce'` なら `coerceDecided` (`src/politics/coerce.js`) へ。

- AI の国の威圧 (艦隊を見せて、星系の明け渡し・従属・交易協定・資金を求める) が人間の国の首都に届くと、「決めること」として出る (飲む・断る。`COERCE.replyYears` 年のうちに返事がなければ断る)。返事は光速で威圧した国に戻り、断られた国は宣戦するか引き下がる。
- 観戦 (人間の代わり) では決めることにせず、AI の国と同じ規則で答える (`coerceJudge`)。
- 政治力はかからない (首都の決めることなので、`pcCost` の `decide` は 0)。
- 帳簿 `mem` の種類に coerce (威圧) を足した (`politics/memory.js`。恨みに数える)。派閥の満足 `LOBBY_ACT` に coerce −0.5 を足した (`politics/inner-consts.js`)。
