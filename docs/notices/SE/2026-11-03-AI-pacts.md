# AI の振る舞い (回 AI2・B-301) から: 防衛同盟の判断に均衡と便乗・協定の理由の記録

`src/politics/diplomacy.js` を直し、新しいファイル `politics/threat.js`・`threat-ui.js`・`ai-consts.js` を足した (W5-Q6 = a で補正なし)。

- `pactScore` の防衛同盟: いちばん脅威な国 (`alignOf`。式は `pactThreat` と同じ) に、味方になりそうな国 (その国より弱く、両方から宣戦できる距離) と合わせた艦隊で届けば**均衡** (前と同じ共通の脅威の項。脅威の国そのものとは組まない向きに −脅威)、届かなければ**便乗** (脅威の国と組む向きに +脅威)。Walt 1987 の 5 章・Schweller 1994。理由の文は「共通の脅威: 国の艦隊・自分・光年」「便乗: …」。
- `makePact` に 5 つ目の引数 `info` (受けた国の判断): 協定に `th` (共通の脅威の国) と `mode` (balance・bandwagon) を覚える (R91・F29 で数える)。`docs/registry.md` に足した。
- `pactAnswerAi`・AI の申し入れ: 受けた・断った・申し入れたときに理由を記録 (`aiNote`)。乱数の引き方は前と同じ。
- 防衛同盟の参戦: AI の国 (席のない国は `diplomacyYearly`、席の国は `pactAiReply`) は、同盟国の艦隊を足した見込む戦勝点が `PACT.honorLine` (−58.8) 以上なら参戦し、下回れば断る (破約・協定は切れる)。前は必ず参戦した。Leeds・Long・Mitchell 2000 の 74.5% に較正 (30 銀河では 68.7%)。
- 同盟に従った参戦は、`warBy` を元の仕掛けた国のままにする (守り。元の国の防衛同盟が呼ばれて連鎖していた)。人間の国の「参戦する」も同じ。
- 協定の値の較正 (区分は社会): `aiPropose` 0.04 → 0.3・`napBase` 0.2 → 0.4・`allyBase` −0.3 → −0.05。R90 1.05 → 7.02・R91 74.7% (帯の上を 0.8 点越える)。測りは `docs/ai-behavior.md` の 9.1・9.2。
