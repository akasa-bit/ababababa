# 画面の点検 (GA6) で決まった、政治の画面の直し (GA から。QD-59)

ユーザーが選んだ直し (`docs/decisions.md` の「GA6 の画面の点検」と「決まったもの (2026-10-23、回 GA6)」)。どれも `src/politics/` の中なので、持ち主の政治に頼みます。

1. **L3 = a** (`politics-ui.js` の `requestsTable`): 交易路の「通信」の表で「光速で送信中 あと −7.7 年」と負の年が出る。判定は `q.arrive + lightDelay(q.to) > g.year` なのに、表示は `q.arrive − g.year` のまま。要求が届いたあと、届いた知らせが地球に来るまでの間は「届いた (地球に知らせが来るまで あと n 年)」と出してほしい (n = `q.arrive + g.lightDelay(q.to) − g.year`)。
2. **A5 = a** (同じ `requestsTable` の `<p class="note">` の段落): 長い説明は「説明」に畳む。いまは `helpify` で畳まれるので、そのままでよい。ほかに 50 字未満で残っている頭の文があれば、`<details class="help">` に入れてほしい。
3. **A2 = a** (`panels.js` / `politics-ui.js` の政治タブの頭): 「説明」の札が、見出しなしで 2 つ続く (自動資金援助のチェックの前後)。見出し (`<h3>`) の下に置けば、GA の CSS で見出しの行の右端に出る (#empire の `h3 + details.help`)。続いた 2 つは `helpify` が 1 つにまとめる。
