# 共通 (依頼 2026-11-10 の common-1・common-2) から: 自動の試験は本物の Firebase につながない

`docs/online.md` の 3 の終わり。

- ネット対戦の画面を開くだけで、招待コードの部屋を作り、ゲストで自動ログインするようになった。そのままだと、ネット対戦の画面を開く試験 (`tools/tests/net.js` など) が、
  回すたびに本番の Firebase にゲストのアカウントと部屋を作ってしまう。そこで `outward/cloud.js` の `CLOUD_ROBOT` で、自動操作のブラウザ (`navigator.webdriver`。Playwright) では、
  偽物 (`window.__FB_FAKE`) を差しこんだときだけオンラインの機能を出すようにした。差しこまない試験は、Firebase の JS も読まない (前は、ページを開くたびに gstatic.com から読んでいた)。
- `tools/tests/cloud.js` を新しい流れに直した: ホストも参加者もログインなしで始める・招待コードの形 (4 文字・英字と数字)・コードの衝突・ない部屋と期限切れ・同じコードで入り直す・
  始めたら部屋が消える・メールでログインしていた人はそのまま・偽物のないページは本物につながない (`robot`)。合否の線 (`exports.ci`) にも足した。
- `tools/tests/net.js` (長いコードの手渡し) は変えていない。合格のまま。
