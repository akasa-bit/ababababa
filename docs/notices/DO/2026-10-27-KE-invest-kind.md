# 経済 (回 KE6) から: お金の種類 invest を足した

ユーザーの決定 (2026-10-26、`docs/requests/2026-10-26-KE.md` の KE-1「資本を生産に効かせる」)。B-119 の 1 段目として、星系の会社の資本と投資を入れた (`docs/regions.md` の 7)。

道具と検証のレーンに関係すること:

1. **`tools/tests/money.js` の `KINDS`**: お金の種類に `invest` (会社の資本の投資。星系の会社 → 同じ星系の家計への建設の賃金) を足すように 1 行だけ直した (持ち主が止まっているときの 1 行の直し。`docs/parallel.md` の 2)。`cash` を通るので、帳簿と種類ごとの合計の試験はそのまま通る (シード 1・150 年で合格)。
2. **`tools/fiscal-panel.js` の GDP**: `invest` は政府の買い物 (`GOV_BUY`) に入れていない。いまの投資は会社の利潤 (付加価値に入っている) を家計に移すだけで、人も物も使わないので、税収 ÷ GDP の GDP には足さない (はじめ `build` で払ったら、R19 が 0.134 → 0.105 に下がったので分けた)。投資の目標 R78・R79 の道具 `tools/capital-panel.js` は、国民経済計算 (消費 + 投資 + 政府) に合わせて `invest` を GDP に足している。2 段目 (資本を産出に効かせる) で投資が人を使うようになったら、2 つの GDP をそろえる。
3. 書き出し (`tools/export.js`) に投資を出すなら、総固定資本形成は `invest` + 政府の `build` (建設の賃金と資材) が近い。急がない。
