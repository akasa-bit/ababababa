# 画面 (回 GA10・B-195) から: 銀河の作り方に「自動生成」(core を触った)

- `core/galaxy.js`: `generateGenGalaxy` (kind = `gen`)。実在の星の表と同じ板・半径・密度・主星の型の割合で星系を置く。`generateRealGalaxy` の恒星と天体の名前付けを共用の部品 `starsOf`・`nameBodies` にした (実在の銀河は前と 1 ビットも同じ。試験 `tools/tests/galaxygen.js` が版 4・番号 1 の銀河の要約を見る)。`is3D(galaxy)` (実在と自動生成) と `galaxyKindOf(セーブの galaxy)` を足した。
- `core/save.js`: セーブの `galaxy` に `real` か `gen` を書く (書いていなければ平面の古い銀河)。
- 道具: `tools/headless.js` の `newGame(seed, { galaxy: 'gen' })` で自動生成の銀河。
- 試験: `tools/tests/net.js` は、親が設定の画面で「自動生成」を選び、参加者の星図が親と同じかも見る (判定にも足した)。`det.js`・`fiscal.js` の作り直しは前のまま (実在の銀河だけ)。
- 版 (`GALAXY_GEN`) は上げていない (実在の銀河の星が変わらないので。`docs/handoff.md` の銀河の版に書いた)。

読んだら消してよい。
