- `EDITIONS.game.physics.pv` を `false` → `'auto'` にした (core の `base.js` の 1 語。物理の切り替えは船と戦争が持つ)。ゲーム版の試合の筋が変わる: スウォームの発電と広がる速さが、星系の恒星のフレアの陽子で減る (M 型星で強い)。CI の自動対戦と面白さの数は main と同じ筋にならない。
- `tools/tests/physics.js` のゲーム版の分 (CI で落ちたら止める行) を書き直した: 物理の切り替えが `pv: 'auto'`・自動の作り (太陽 a・バーナード星 c)・スウォームが自動の作りの速さで広がる・発電が出力の残りの分だけ減る・星系の政府の作り (`pvd`) と試合の既定 (`pvPolicy`) が効かない・指令 `pvdesign` が通らない。シミュレーション版の分は前のまま。
- 物理の切り替えのない古いセーブは、前のとおり物理なし (`PHYSICS_OFF`。`pv: false`) で読む。
- core の `galaxy.js` の `starsOf` を 1 行直した (物理のフレアの値。船と戦争の持ち物の行): フレアの表 (`FLARES.stars`。表を作ったときの |z| ≤ 2 光年の星系だけ) にない M 型星を、0 でなく測れた M 型星の中央値 (`FLARES.mMedian`) にした。表を作る台本 (`data/build/build_flares.py`) で TESS の光度曲線がない星と同じ扱い。銀河の M 型星 120 個のうち 57 個がフレアのない星になっていた。入植適性はどちらの版でも変わらず (銀河 1・7)、変わるのは惑星の欄の地表の線量と、太陽電池の劣化。試験 `physics.js` に、表の値・中央値の確かめを足した (直さない版で落ちるのを確かめた)。

  - `tools/tests/debt.js` の「資金が多すぎる政府」: 入植船のために取っておく資金 (資本の予算 `gv.saveFor`・国の入植の予算 `gv.colFund`。`economy/fiscal.js` の `debtStep` の `res` と同じ式) を引いてから比べる。M 型星の小さな政府 (税 0) が入植船の資金を取っておいたまま試験の終わりを迎え、3 つ数えていた。
