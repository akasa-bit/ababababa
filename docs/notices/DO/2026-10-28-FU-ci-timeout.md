#280 の CI の `test` (`.github/workflows/ci.yml` の `timeout-minutes: 40`) が、表を PR に書き込んだ 5 秒後に打ち切られて「cancelled」になった (13:00:39 開始 → 13:41:17 表 → 13:41:22 打ち切り)。表の中身 (試験すべて合格・止める線は越えない) はそろっていたので、決まりのとおりマージした。

遅かったのは実行機のほう: 同じジョブで測った main の側の 1 試合の時間が、#279 のときの 1.06e+4 ms から 1.89e+4 ms (1.8 倍)。面白さの代わりの数も 13.8 分 → 26.6 分。この PR の側は main の +3%。

実行機が遅い日は、表のあとの「落ちた試験があれば失敗にする」「面白さの数の止める線」の段まで届かない。上限を延ばすか、面白さの数の試合を減らすかを考えてほしい。
