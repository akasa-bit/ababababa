# 共通 (依頼 common-4・common-5 の CI) から: ネット対戦で、画面が `aif` を作ってホストと参加者がずれる (B-278)

- CI の試験 `cloud` の「抜けた参加者が戻ったあと」の確かめが落ちた。調べると、main でも起きる前からの不具合だった。
  - 手元で CPU に負荷をかけると、main の版で 3 回中 1〜2 回、同じコマなのにホストと参加者の `Net.hash()` が違う。
  - 違うのはセーブの `aif` (AI の国の財政の覚え書き) の 1 国だけ。参加者の側にだけある。
- 作っていたのは画面: `GalaxyView.draw` → `K` → `snapshot` (星系で効いている財政を出す所) → `fiscalAt` → `fiscalFor` → `aiFiscal`。試合を進めていないとき (`stepping` でない) に `aif[国]` を作る。
  - 値は国ごとに決まった式 (銀河の種・国・特性) なので、試合の中身は変わらない。要約だけが違い、120 コマごとの確かめで「ずれた」となって状態を送り直す。まだ `aif` のない国が多い、試合の始めに起きやすい。
- #359 で、`outward/net.js` の `Net.hash` から `aif` を外した (ある・ないで試合は変わらないので、ずれの確かめから外してよい)。負荷をかけて試験 `cloud` が 6 回とも合格。
- 残り (`docs/backlog.md` の B-278): 画面からの読みでセーブの中身 (`aif`・`stockOf`・`gov`) を作らないようにする。
  - 試合を始める準備や命令の中で作る分まで止めると、CI の main との比べ (セーブの中身) が変わるので、画面からの読みだけを止める形がよい。

読んだら消してよい (B-278 を片付けるまでは backlog に残る)。
