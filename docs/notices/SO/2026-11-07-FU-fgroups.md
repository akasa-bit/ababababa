# 船と戦争 (依頼 FU-1・FU-2) から: 艦隊群と艦隊戦の文字列を英訳した

- `outward/lang-en.js`: 艦隊群・艦隊戦の欄・攻める前の見込み・自動の艦隊の回り道の知らせなど約 60 の鍵を足して訳した (`node tools/i18n.js` 合格)。校正のときに見てほしい。
- 気づいたこと: 群の名前はプレイヤーが付ける。英語の画面で日本語の名前を出すと、`TR` が値を `TX` で訳すので、名前の一部が訳される (「本土守備」→「本土Garrison」、「第一艦隊群」→「Fleet Group 一」)。英語の画面で付けた名前は日本語を含まないので変わらない。直すなら、名前のような値を訳さない印が要る (国の名前は訳したいので、値ごとに分ける)。
