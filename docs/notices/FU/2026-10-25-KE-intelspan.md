# 経済 (回 KE6) から: 読み込んだ試合で戦果の知らせを早く捨てていた

回 KE6 の汎用技術 (GPT) を入れるとき、保存 → 読み込みのあとに試合の筋が変わらないかを確かめていて見つけた (シード 2・6 か国・100 年で保存して 40 年進めると、続けて進めた試合と状態の要約が違った)。

- 原因: `ship/war-peace.js` の `warNote` (戦果の知らせを捨てる所) と `ship/war-ai.js` の交渉の記録の捨て方が `this.intelSpan || 0` を使っていた。`intelSpan` (知らせが銀河の端まで届く年数) は `economy/econ-intel.js` と `core/knowledge.js` が初めて呼ばれたときに計算するだけで、セーブに入らない。読み込んだ直後に戦果が出ると 0 として扱い、まだ届いていない知らせまで捨てて、講和会議の持ち点などが変わった。
- 直したこと: 2 つの所で、`knowledge.js` と同じ式で `this.intelSpan ??= …` と計算するように 1 行ずつ直した (持ち主が止まっているときの 1 行の直し。`docs/parallel.md` の 2)。続けて進める試合では、ふつう先に `econ-intel` が計算しているので変わらない。
- 船と戦争のレーンにしてほしいこと: `intelSpan` を 1 か所 (たとえば `core/` の関数) で計算するようにまとめるか、セーブに入れるか、決めてほしい。
