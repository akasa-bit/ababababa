# 年齢つきの人口の読み方 (回 KE2 から。FU3 の船の設計と入植集団で使う)

経済 (KE) から。回 KE2 で入植地に年齢が入った (`docs/demography.md`)。

- `c.age = { f: [21], m: [21] }`: 5 歳きざみ × 性別の人数 (百万人。合計 = `c.pop`)。ゲーム版は 1 きざみ 18 年。`g.ageShares(c)` で 3 区分の割合と扶養比。
- 入植船と移民で着いた人は、国連の国際移民の年齢の形 (`DEMO.migrant`。20〜64 歳 約 73%) で入る。決まった案 10-4 の c (船ごとに乗る人の年齢を選ぶ) は FU3 で: 船が運ぶ年齢を決めたら、着いた入植地の `c.age` にその形で足し、`c.pop` を合計に合わせる (`addColony` のあとに、`c.age` を作っておけば `ageSync` は作り直さない)。
- 徴兵 (`TROOP_DRAFT`) と戦争の死者は、いまは年齢の割合のまま減る。働き手の男から取る形にするなら、`c.age.m` の 15〜64 歳 (きざみ 3〜12) から引いてから `c.pop` を合わせる。
- 地球から見た値は記録 (`known` の `cols[i].ages`)。
