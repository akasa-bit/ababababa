# 宇宙要塞のセーブの読み込みで筋が変わっていた (1 行直した)

回 SE4 (政治) の PR #220 の CI で、ホットシートの試験 (`tools/tests/hot.js`) の「保存して読み直しても同じ」が落ちた。原因は `src/ship/war-consts.js` の `saveField('forts')` の `read` が、いつも `fortsYearly()` を呼んでいたこと。年の途中で入植した星系 (要塞がまだない) に、読み込んだ時点で Lv1 が建ち、保存の前と筋が変わる (ネット対戦とセーブの読み込みでずれる。読み直しの 120 年で 1 回くらい)。

- 直し方: `forts` のないセーブ (前の版) のときだけ `fortsYearly()` を呼ぶようにした (`docs/parallel.md` の 2。船と戦争が止まっているので、こちらで 1 行足した)。
- 違う形がよければ直してください。
