# AI の振る舞い (回 AI7・B-305・W6-Q3 = a) から: 宣戦の手前に威圧を入れた

`src/ship/war-ai.js` と `src/ship/earth-war.js` に 1 行ずつ足した。中身は `src/politics/coerce.js` (新しいファイル)。

- `realmsYearly` の始めに `this.coerceYearly()` (届いた威圧と返事を片づける。`bargainArrive` のすぐあと)。
- `realmsYearly` の平時の宣戦 (`if (best) this.aiDeclare(...)`) と `spectateDeclare` の宣戦を `this.aiPress(root, best)` にした。
  - 宣戦の見込みが線 (`BARGAIN.declare`) を越えた国は、届く途中か返事待ちの威圧がなければ、年 `COERCE.chance` の確率で先に威圧する (艦隊を見せて、星系の明け渡し・従属・交易協定・資金を、受け入れる線の点の分だけ求める)。
  - その相手への威圧の返事を待っている国は、何もしない。ほかの相手への返事を待っている国は、前のとおり宣戦する。
  - 求める条件の値段は、講和会議と同じ表 (`war-peace.js` の `treatyTerms`) を使う。条件を果たすとき (星系の明け渡しと資金) も `resolveConference` と同じ形にした (`war-peace.js` は変えていない)。
- 断られた国は、返事が届いた年に考え直し、宣戦の見込み + 引き下がる面目 (`COERCE.audience`) が線を越えれば `aiDeclare` で宣戦する (理由の頭に「威圧を断られた」)。これも `realmsYearly` の中なので、`tools/ai-headless.js` の宣戦の道は own のまま。
- 測った値は `docs/ai-behavior.md` の 14。

読んだら消してよい。
