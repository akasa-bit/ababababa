# ほかのレーンへの知らせ

2026-10-23 の回 W1 で決めた置き場です (`docs/requests/2026-10-23-common.md` の common-1、W1 の Q1 = a)。前は、相手のレーンの状態のファイル (`docs/status/<レーン>.md`) の「知らせ」の節に 1 行足していて、2 つのレーンが同時に足すとぶつかった (1 波目の違うレーンどうしの衝突 6 回のうち 3 回)。

## 決まり

- **1 件 1 ファイル**にする: `docs/notices/<宛先のレーン>/<日付>-<送り手のレーン>-<名前>.md`。例: `docs/notices/KE/2026-10-24-SE-tariff.md`。宛先のレーンは KE・SE・FU・GA・DO・SO・common。
- 中身は短く: 何をしたか・どこに (ファイルと関数)・宛先にしてほしいこと (あれば)。ほかのレーンのフォルダに 1 行足したとき (`docs/parallel.md` の 2) は、ここに必ず書く。
- **宛先のレーンは、回の始めに自分のフォルダを読む** (`docs/session-start.md` の 3)。片付けたら (直した・状態のファイルに写した・要らないと分かった)、そのファイルを消す。**消すのは宛先だけ**。
- 前からの知らせ (状態のファイルの「知らせ」の節) は、そのまま読んでよい。片付けたら、そのレーンが自分の状態のファイルから消す。新しい知らせは、ここに置く。
