# 2026-10-26 の依頼 (common: 段取りと決まり)

### common-1.

```text
このゲームのファイルを、
・コンテンツの更新/追加がしやすいようにして。
・ゲームの処理速度を、１０倍にして。
・でも、ゲームの内容は、一切変更しないで。
```

(Claude の解釈と、したこと: 「内容を変えない」= 同じシード・同じ手順なら、試合の筋が 1 ビットも変わらないこと (節目ごとの状態の要約 hash が前と同じ) とし、それを確かめながら速くした。試合を進める処理はブラウザで約 1.8 倍、画面なしの版は約 4.4 倍で、10 倍には届いていない (理由とさらに速くする道は `docs/perf.md` の 3)。コンテンツは、足し方の案内 `docs/content.md` と、一覧と点検の道具 `tools/content.js` (CI の `tools/tests/content.js`) を足した。ゲームの中身・セーブの中身は変えていない)
