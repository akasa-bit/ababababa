# 2026-11-07 の依頼 (船と戦争)

### FU-1.

(依頼 common-4・common-5 (#359) と Steam 版の質問のあとに来た依頼。そのまま)

```text
艦隊戦の最中に自動防衛配備かなんかで抜けてくのなくしてほしい。

あと、艦隊戦で何が起こってるか星間地図からわかるようにしてほしい。

撤退する/しないの判断も、どこでどう動くか分かりにくい。

攻撃中の艦隊に自動防衛配備が行くのどうにかしてほしい。じゃあ、HOI4の軍団制(師団をまとめる)を参考にしたような、役割の割り振り機能を作って
```

(受け取ったこと:
1. 艦隊戦の途中で艦が抜けていくのをなくす。調べると、主な元は 2 つ: 組織力の下がった艦が自動で退く仕組み (退いた艦は「自動」扱いになり、そのあと自動防衛配備にばらばらに回される) と、
   自動防衛配備が光の遅れのぶん古い記録で動くので、着いたらもう敵に取られていた星系へ 1 隻ずつ攻め込むこと。
2. 艦隊戦で何が起きているか (両軍の数・勝つ見込み・沈んだ艦・退いている艦とその行き先・攻囲の進み) を星間地図で分かるようにする。
3. 撤退する/しないの決まり (どの艦が・いつ・どこへ退くか) を分かるように見せ、選べるようにする。
4. HOI4 の軍 (師団をまとめて役割を与える) を参考に、艦隊をまとめた「艦隊群」に役割 (攻撃・守備。予備にあたるのは群に入っていない艦) と撤退の決まり・拠点を割り振る。自動防衛配備は群に入っていない艦だけを動かし、
   攻撃中の艦隊には手を出さない。退いた艦は群の拠点へ戻って群に残る。光速の遅れは守る (群への出し入れは光速の指令、群の決まりの変更は光が届いた所から効く)。
作ったものは `docs/fleet-groups.md` と `docs/status/FU.md`、PR の説明)

途中の質問 (そのまま):

```text
あと、敵首都(艦隊数1)に２０艦隊で殴り込んでも一向に攻囲に移らず、相手の１艦隊が沈まないままこっちの艦隊が全部撤退しちゃった。どういうことなの?
```

(答え: 戦争中の AI の国の首都は宇宙要塞 Lv3 で、要塞の区画 3 つ (艦の 3 倍の耐久・退かない) が守りにいる。攻囲は、守りの艦と区画がすべていなくなってから。
20 艦隊で攻めても 4 回に 1 回 (前の補給線で遠いと 10 回に 4 回) は、攻めの艦が組織力が尽きて退き、負ける。`docs/fleet-groups.md` の 7。
地図と星系の欄に要塞と見込みを出し、艦隊群に「退かない」を足した。要塞の強さと戦いごとのくじは変えていない (変えるかは、作り終えてから案を出して聞く))

### FU-2.

```text
補給線機能無くそう
```

### FU-3.

(FU-1・FU-2 の PR #360 をマージしたあとに来た依頼。2026-11-08。そのまま)

```text
>あと、敵首都(艦隊数1)に２０艦隊で殴り込んでも一向に攻囲に移らず、相手の１艦隊が沈まないままこっちの艦隊が全部撤退しちゃった。どういうことなの?

こいつを踏まえた上で、４つも続きやって
要塞もダメージを食らい、壊れるようにしてほしい
```

(「４つ」は、PR #360 のあとに聞いた QD-48 の 4 つの案 ((a) 変えない・(b) 要塞の区画の耐久 3 → 2・(c) 戦争中の AI の首都の要塞 Lv3 → Lv2・(d) 戦いごとのくじを半分) と受け取り、「(b)(c)(d) を全部入れる、で合ってる？」と聞いた (どれにしても要塞の傷が残る仕組みは作る、と添えた)。
返事は「(b)(c)(d) 全部入れる」。そのあと作っている途中に、もう一度来た返事 (そのまま):

```text
いや、やっぱaで
```

→ QD-48 = (a) 変えない。要塞の区画の耐久・AI の首都の要塞・戦いのくじは今のまま。「要塞もダメージを食らい、壊れるようにしてほしい」は、要塞の傷が次の戦いにも残り、攻め続ければ壊れる仕組みとして作った (`docs/fleet-groups.md` の 8)。
注文の見込みの知らせが要塞を数えていなかったので (20 艦隊で 1 艦隊の首都を攻めると、見込みが高く出ていた)、それも直した)
