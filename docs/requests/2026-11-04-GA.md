# 2026-11-04 の依頼 (画面と最初の体験)

### GA-5.

(回 AI6 の途中、実行機の測りを待つあいだに来た依頼。「いまどこまで行ってるの？」と一緒に。そのまま)

```text
あと、AIの国、スポーン位置ランダムにしてほしい。
```

(受け取ったこと: AI の国の首都は、銀河の番号から決まるくじ (`core/game-base.js` の `planNations`) で引いていて、同じ番号なら毎回同じ場所。くじには重み (進んだ先住民の星・住みやすい星ほど選ばれやすい) があり、実在の星の銀河は星の位置がどの番号でも同じなので、同じ場所に寄りがち (40 試合で、いちばん多い場所は 6 回首都になった)。
a. 同じ銀河の番号でも、新しい試合ごとに引き直す。b. くじの重みを外す。c. 両方。を聞いた (おすすめは a))

答え (QD-116 と並べて聞いたあと。そのまま):

```text
aでお願い
```

(受け取ったこと: GA-5 = a と QD-116 = a。画面から新しい試合を始めるたびに、置き場所のくじの番号を変える (`core/game-base.js` の `foundNations` の `natDraw`・`screen/hotseat.js`)。同じ銀河 5 で番号 a と b を引くと、5 か国の首都はすべて違う場所になった。番号を渡さない画面なしの道具と試験は前のまま再現できる。決まった国はセーブに入るので、読み込みとネット対戦の参加者も同じ置き場所。くじの重みは外していない)

### GA-6.

(GA-5 のすぐあとに来た依頼。そのまま)

```text
自動生成でも地球の国が真ん中なのが気に入らない。自動生成の場合、地球が端っこにもなりうるようにしてほしい。
```

(受け取ったこと: 自動生成の銀河 (回 GA10) は、太陽系を原点に置き、そのまわりの円盤に星を置いていたので、地球の国がいつも真ん中だった。
銀河の版 6 で、自動生成の銀河だけ、星を置く円盤の中心を太陽系からずらした (`core/galaxy.js` の `generateGenGalaxy`)。太陽系は円盤の中の一様な場所になり、半分ほどの銀河で中心から半径の 0.7 倍より外 (端の側) にある。
実在の星の銀河は、太陽からの距離で星を選んでいるので、太陽系が真ん中のまま (版 5 と同じ星図)。版 5 までのセーブは前の銀河のまま読む。地図の初めの視点は円盤の中心にした (`screen/galaxy-view.js` の `fit`))
