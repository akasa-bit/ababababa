# 国債と財政の反応 (段 4 の 3)

[fiscal.md](fiscal.md) の 3.5 の案 d の続きです (ユーザーの決定 C-14「いいぞ、進んで」)。1〜4 は最初の版 (#138)、5 はユーザーが 4 の 3 つを選んだあとの作り直し (C-15) です。前の版の政府は借りられず、税収の何十年分もの資金を積んでいました。そのため、黒字の年が多すぎ (R20)、政府の債務は 0 で (R21)、黒字の分だけ民間が銀行から借りていました (R22)。ここでは、現実の政府と同じく国債を出せるようにします。どれだけ出すかは、現実のデータから推定した財政の反応の式で決めます。

## 1. 現実の政府はどうしているか (推定)

Bohn (1998) は、「債務が増えると、政府は基礎収支 (利子の払いを除いた収支) を良くする」を、債務を持続できる条件として示しました。同じ形の式を、JST R6 の 18 か国 1870〜2020 年について国ごとに最小二乗で当てました。戦争の年には、Correlates of War の国家間戦争 v4.0 の参戦の期間を使っています。

基礎収支 ÷ GDP = a + ρ × 前の年の債務 ÷ GDP + β × GDP の傾向からのずれ + γ × 戦争の年 + u

- 基礎収支は (revenue − expenditure) ÷ gdp + 長期の利子率 × 前の年の債務 で求めた。利子の払いは JST にないので、この式で近づけている。
- GDP の傾向は、実質 GDP の対数に HP フィルター (λ = 100) をかけたもの。
- 計算は `data/build/analyze_fiscal.py`。

| 係数 | 国のあいだの中央値 | 意味 |
|---|---|---|
| a | −0.0023 | 債務がなく、平時で景気がふつうのときの基礎収支 ÷ GDP |
| ρ | 0.0336 (10%〜90% 点 −0.020〜0.062) | 債務 ÷ GDP が 0.1 増えると、基礎収支 ÷ GDP を 0.0034 良くする。目標 R28 |
| β | 0.056 | 景気が傾向より 1% 良いと、基礎収支 ÷ GDP が 0.00056 良くなる (自動安定化) |
| γ | −0.017 | 戦争の年は、基礎収支 ÷ GDP が 0.017 悪くなる (戦費を国債でまかなう。Barro 1979 の税の平準化) |
| u のばらつき | 0.027 | 式で説明できない分 (政治・災害など) |
| u の 1 年の自己相関 | 0.70 | その分は何年か続く |

ρ は、Bohn (1998) の米国の推定 (0.054) や、Mauro ほか (2015) の 55 か国の推定と同じくらいの大きさです。

## 2. ゲームの仕組み (最初の版 #138。5 で変えた所がある)

| 部分 | 中身 |
|---|---|
| 国債 (`gv.bond`) | 星系の政府ごとの残高。銀行が国債を買い、同じ額の預金を政府に作る。政府の純額 (資金 − 国債) は変わらないので、お金は湧かない (Godley & Lavoie 2007 の銀行と同じ形) |
| 国債の利子 | 政府はその星系で効いている利子率で利子を払う。銀行はそれを、民間の借りの利子と一緒に預金の額に比べて分ける (`interestStep`) |
| 出す額 (`debtStep`) | 毎刻み、目標の基礎収支 s* × GDP の分 (マイナスなら借りる) と国債の利子の分だけ、国債を出す。s* は 1 の式で、係数は推定した中央値 (`DEBT`)。u は試合の乱数で作る (1 年の自己相関 0.70) |
| 返す | s* が利子を上回れば、手元の資金から返す (国債は 0 より下にならない) |
| 行政サービス (`public`) | 手元の資金が税収の 3 年分を超えたら、超えた分を 1 年ほどで行政サービス (民間の賃金と買い付け) に使う。これで、使い道のないまま積んでいた資金が民間に戻る |
| GDP | その星系の民間の所得 (`incomeOf`) を 1 年ほどでならしたもの |
| 景気の傾向 | ln GDP の水準と伸びを、10 年ほどでならす (Holt の線形の平滑化)。伸びを追わずにならすと、若い植民地が速く伸びるあいだ、いつも傾向より上 (「好景気」) に見え、黒字を求めすぎた (直す前の試し: 30 銀河で R28 −0.006)。傾向からのずれは、JST の HP フィルターのずれの 1%〜99% 点 (−0.176〜0.145) に収める |
| 返しきれない分 | 手元の資金が足りずに返せなかった分は、次の刻みから先に返す (`gv.due`) |
| 資金が 0 を割ったとき | 軍の維持費は、駐留する星系の政府が払う。税収の少ない小さな政府では、維持費のせいで資金が 0 を割ることがある。そのときは、割った分だけ国債を出す (式の外の借り。戦費を国債でまかなうのと同じ) |
| 戦争 | 国がどこかと戦争をしていれば γ を足す |
| 人間の首都 | 前のまま (国債を出さず、行政サービスも自動では払わない)。観戦では AI と同じ。下の 4 で選んでもらう |

手元に置く資金 (税収の 3 年分) は、現実のデータでは決めていない仮の値です。現実の政府の手元の資金は、もっと少なく、税収の 1 年分よりずっと下です。ゲームの AI は、施設や船を買うときに費用の 1.2〜2 倍の資金を求めます。そのため、手元の資金を減らしすぎると、何も建てられなくなります。

### 3.3 財政の反応が式より弱い理由

ゲームの政府も、式どおりに国債を出し入れしています。それでもパネルで測った ρ が −0.0008 と弱いのは、次の 2 つのためです。

1. 基礎収支を動かすのが、国債の出し入れだけではないから。AI の建設や船の支払いは、手元の資金の範囲で決まった時期にまとまって出る。
2. 小さな政府の維持費の借り (2 の「資金が 0 を割ったとき」) が、債務の水準と関係なく増えるから。

ρ の幅は現実の国のあいだでも広く (−0.020〜0.062)、ゲームの値はその中にあります。

## 5. 決めたあとの作り直し (C-15)

### 5.1 変えた所

| 部分 | 中身 |
|---|---|
| 手元に置く資金 (`DEBT.cash`) | 税収の 0.161 年分 (約 2 か月)。Eurostat の一般政府 (S13) の現金・預金 ÷ 総収入の、30 か国 1995〜2025 年の国ごとの中央値の中央値 (10%〜90% 点 0.080〜0.295)。生データは `data/raw/fiscal/eurostat_*.json`、計算は `data/build/analyze_fiscal.py` (`data/derived/fiscal.json` の params) |
| 使える資金 (`funds`) | 手元の資金 + 国債で借りられる額。AI の政府の買い物 (施設・船・交易路・兵・入植船) と、資材の代金の確かめ (`lack`・`procure`) は、これで比べる。買って資金がマイナスになった分は、刻みの終わりに国債で埋める |
| 借りられる上限 (`DEBT.limit`) | 国債 ÷ GDP が 0.4687 になるまで。JST の国ごとの債務の中央値の中央値 (R21 の estimate) |
| 行政サービス | 式で決まる使える額 (税収 − s* × GDP) から、ふだんの支出 (1 年ほどでならした建設・船・維持費・予算など) を除いた残り (投資が先、行政サービスが後)。手元の資金が税収の 0.161 年分を超えたら、まず国債を返し、国債がなければ行政サービスに使う |
| 人間が動かす首都 | 財政の画面で「赤字の上限」(なし・GDP の 1%・3%・5%・10%/年) を選ぶ。既定は「なし」(前と同じく国債を出さない)。上限を選ぶと、資金が足りない分を、この 1 年に出した国債がその額に届くまで国債で借りる (国債 ÷ GDP は 0.4687 まで)。手元の資金が税収の 0.161 年分を超えると、超えた分で国債を返す。変えるには政治力 5 (税・利子率と同じ)。行政サービスは自動では払わない |
| 画面 | 財政の表に「赤字の上限」の行 (国債の残高・いま借りられる額)。星系の「政府と資金」に国債の残高 |

借りられる上限の試し (6 銀河の入植地の平均と、10〜30 銀河の R21):

|---|---|---|---|---|
| 0 (借りない) | — | 10.0 | — | 何も買えなくなる |
| 0.914 | JST の国ごとの 90% 点の中央値 | 40.0 | 1.13 (30 銀河) | 幅を超える (どの政府も上限まで借りる) |
| **0.4687** | **JST の国ごとの中央値の中央値** | 30.8 | 0.474 (30 銀河) | 合格 |
| 0.3 | — | 30.7 | 0.325 (10 銀河) | 合格 |

直す途中で、資材の代金の確かめ (`lack`) が手元の資金だけを見ていて、借りられる額を数えていなかった。そのため、AI がほとんど何も買えなかった (入植地 8)。

## 6. R28 を幅に戻す (回 KE1・B-003)

main (#213) の 30 銀河 × 150 年 × 6 か国で、R28 は 0.088 (幅 −0.020〜0.062 の上)、R21 は 0.175 (幅 0.202〜0.730 の下) だった。

原因は、手元の資金が税収の 0.161 年分を超えたときの使い道だった。国債のある政府は余りで国債を先に返し、ない政府は行政サービスに使っていたので、債務の多い政府ほど余りの分だけ黒字になり、パネルで測る財政の反応が式 (ρ = 0.034) よりずっと強く出ていた。返すのを式 s* の分だけにし、余りはいつも行政サービスに使うようにした (`DEBT.repay = 0`。1 で前の返し方に戻る)。

同じ回で、利子を実質の利子率で受け払いするようにした (`docs/money.md` の 5)。パネルは JST と同じ名目の収支にするため、expenditure に 物価の上がり方 × 国債、revenue に 物価の上がり方 × 政府の預金 を足し、ltrate を長期の国債の利回りにした (`tools/fiscal-panel.js`)。

## 7. R22 (民間の信用) を幅に (回 KE3・B-002)

前は、家計と会社の手持ちと借りを差し引いた 1 つの値しか持てず、預金と借りを同時に持てなかったので、R22 は 0 でした (`docs/structure.md` の 7.1)。家計の借り (住宅など。`gv.hm`) と会社の借り (設備投資など。`gv.bl`) を、預金と差し引かない残高にしました (`LOANS`。`fiscal.js` の `creditStep`)。

| 部分 | 中身 | 値の出どころ |
|---|---|---|
| 残高の目安 | 家計 GDP の 0.214、会社 0.26 | JST R6 の 18 か国の民間の信用 ÷ GDP の中央値の中央値 (0.474。R22 の estimate) を、家計 (thh) と会社 (tbus) の中央値の比で分けた値 (`analyze_fiscal.py` の params の `loans_hh`・`loans_fm`) |
| 借りる・返す | 毎年 GDP (ならした値) の 残高の目安 ÷ 年数 を新しく借り、残高の 1 ÷ 年数 を返す。定常では残高 ÷ GDP = 目安 (伸びる星系ではそれより低い) | 返す年数: 家計 15 年 (住宅ローンと消費者の借りの間)・会社 5 年。仮の値 |
| 使い道 | 家計は借りた分で会社から住宅を買う (`housing`。会社の売上 → 賃金として家計へ)。会社は借りた分を設備に使う (会社の手持ち → 賃金として家計へ) | — |
| 利子 | その星系の実質の利子率 (`rateAt`) で、ほかの借りと同じく銀行に払う | — |

借りる・返すは銀行が預金を作る・消すだけなので、家計と会社の純額は変わりません (お金の試験の出入りに載せない)。貸借の表 (`tools/tests/ledger.js`) と お金の試験 (`money.js`) は、`hm`・`bl` を貸出に数えます。
