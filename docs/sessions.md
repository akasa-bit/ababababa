# セッションの分け方と、最初のメッセージ

`docs/game-plan.md` の段を、この順で 1 セッションずつ進めます。**レーン (A〜E) に分けて、違うレーンは同時に進めてよい** (決まりは `docs/parallel.md`。2026-10-20 のユーザーの決定。`docs/requests-log.md` の 134〜136 と `docs/requests/2026-10-20-common.md`)。どのセッションも、下の「最初のメッセージ」をそのまま送ります。どの文も「docs/session-start.md の 3 に従って」で始まり、約束・始め方・終わり方はそこにあるので、ここには「何をするか」だけを書きます (Project は使わない。requests-log の 137)。

## 1. 順番の考え方

- **① 戦争まわりを先に片付ける (段 3 → 8)**: 段 3 (AI も光の遅れで判断する) で、終わりの年に続いている戦争が +136% になった。開戦の知らせが届くまで講和を考えないためで、それを直すのが段 8 (講和と交渉)。Fearon の交渉のモデルも「相手の本当の強さが分からないこと」が芯なので、段 3 の上に作る。
- **② 面白さを測る道具を前に出す (12 と 11 の最小版)**: 社会の段を積んでから面白くないと分かると、直す範囲が大きい。必勝法を探す AI と面白さの代わりの数を CI に入れ、以後の段で毎回見張る。
- **③ 経済 (4 → 5)**: お金の保存の帳簿の上に、需要と産業を作る。つり合いが最も動く所。
- **④ 人口 (6 → 7)**: 年齢のあとに集団。集団の不満は離反と戦争につながるので ① のあと。
- **⑤ 船 (9 → 10)**: 入植集団は 6 の年齢を使う。物理はフレーバー。
- **⑥ 仕上げ (12 本番 → 11 本番 → 13)**: 必勝法をつぶしてから試遊、それから Steam の形。
- **③ の続き: 現実の経済政策 (C の最後。19〜25)**: ユーザーの依頼で、レーン C の 9 のあとに続ける。D は待たない。つり合いの本番 (15) と試遊 (16) は、経済が大きく変わり終わってからにする (中身は `docs/econ-policy.md`)。

## 2. どのセッションでも同じ進め方

1. **目標を先に固定する**: その段で合わせる目標 (R 系・F 系) は、作る前に「目標の変更」の PR で決めて `node tools/check-targets.js --lock` で固定する。作ってから幅を決めない。
2. **補正なしで作って測る**: 物理と社会の式だけで作り、画面なしの版で回して、目標の幅に入るかを見る。
3. **困ったら補正を足す**: 遊びが崩れたら、`docs/game-plan.md` の補正の台帳に 1 行足して `EDITIONS.game` で補正する。「現実的」と「面白い」がぶつかる所は表にしてユーザーに選んでもらう。
4. **CI で両方を見る**: 現実の目標と、面白さの代わりの数 (セッション 4 から) の両方が大きく崩れていないかを見てからマージする。
5. **PR は区分ごとに小さく**: 社会・物理の PR と補正の PR を分ける (補正だけを戻せるように)。
6. **終わらなかったら**: 残りを `docs/wip/` と `docs/status/<レーン>.md` に残し、次のセッションの最初のメッセージの頭に「前のセッションの残りを先に片付けてから」と足して送る。表の番号は進めない。
7. **ユーザーに決めてもらうこと**がある回 (下の表の「先に決めること」) は、セッションの最初に表で見せて、返事をもらってから作る。前のセッションの終わりに、次の回で決めることを先に見せておくとよい。
