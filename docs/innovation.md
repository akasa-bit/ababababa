## 1. 学力で決まる研究者 (B-120)

### 1.1 現実の目標 (目標の版 21)

作る前に固定した (`docs/targets.md` の版 21)。生データは前からある WDI の研究者 (SP.POP.SCIE.RD.P6)・所得 (NY.GDP.PCAP.PP.KD)・HCI の試験の点数 (HD.HCI.HLOS)。

| 目標 | 統計量 | 実データ |

| R66 研究者の数と所得 | 所得 (2021 年の国際ドル) の 5 分位ごとの、研究者 (人口 100 万人あたり) の 25%〜75% 点 (138 か国・1,930 国・年) | 中央値 95.9・696.0・1,571.8・3,220.4・4,642.0 人 |

### 1.2 作り (`STRUCTURE.research`。`economy/market-consts.js`・`economy/market-economy.js`)

| | 中身 | 値の出どころ |

| 研究者の曲線 | ln 研究者 [人/100 万人] = a + b ln y + c × 学力 ÷ 100。a = −6.3481、b = 0.7712、c = 1.2098 (`researchers(y, q)`) | R67 と同じ当てはめ (`data/build/build_innovation.py` → `data/derived/innovation.json` の `game.research`)。R² 0.745。前は所得だけ (exp(−6.3424 + 1.3536 ln y)) |

- 学力を入れると、所得の係数が 1.37 から 0.77 に下がる。研究者の所得の勾配の大半は学力の勾配で、学力の高い国ほど同じ所得で研究者が多い。予算の「教育」(学力を上げる) は、研究者を通して技術の伸びにも効くようになった。
- **試してやめたもの**: 学力を大人 (25〜64 歳) の平均や、学校を出たばかりの世代 (25〜29 歳の区分) の平均にする形。どちらも、所得の伸びに遅れて学力が低めに出るので、豊かな国の研究者が R66 の幅より少なかった (25〜29 歳では 30 銀河で 5 分位のうち 3 つ、上の 2 分位が幅の下)。
- **直したもの**: 研究のパネル (`tools/research-panel.js`、R11) の分野の重みに、回 KE5 で足した hi (高付加価値の工業) が入っていなかった。伸びが NaN になり、R11 を測れていなかった。
- 測るための技術革新の国・年のパネル `tools/innovation-panel.js` を足した (→ `data/build/build_innovation.py --game`)。

技術水準の目標 (R68〜R72。目標の版 22。伝播を入れる前の値): R68 不合格 (1/5。前線比の中央値 0.75〜0.97 で、データの 0.18〜0.89 より前線に近い)・R69 合格 (−0.005)・R70 不合格 (+0.004。追う国が離れていく)・R71 不合格 (0.19)・R72 不合格 (0.091)。main は R68 2/5・R69 合格・R70 +0.008・R71 0.26・R72 0.077。

- **研究者が現実の数になった**: main の研究者は、生産力 (`c.inc`。売れ残りを数えない) の 1.35 乗で決まり、豊かな国では人口 100 万人あたり 1 万〜2 万人と、現実の大きな国でいちばん多い韓国 (9,472 人、2023 年。WDI) を超えていた。この版は分位の中央値で 154〜3,619 人で、R66 の幅に入る。
- **そのぶん技術の伸びが遅くなり、所得が下がった**: 150 年で、中ほどの国の技術は main の 3.2 倍に対して 1.5 倍、前線の国は 7.4 倍に対して 3.9 倍 (年 0.9%)。星系・年の所得の 10%・50%・90% 点は 234・20,432・125,960 ドル → 150・8,314・46,624 ドル、首都の所得は 159,161 → 59,247 ドル (2022 年の米国は約 58,000 ドル)、首都でない入植地の中央値は 3,162 → 500 ドル、総人口は 103,338 → 86,859 百万人 (8 銀河)。豊かな国の所得は現実に近づいたが、首都でない星系は貧しくなった。前線から離れていく国を引き上げるのが、次の伝播 (2) の役目。
- **R11 が外れた理由**: Jones の式では研究の生産性の下がり方は −β × 技術の伸びで、幅に入るには前線の国が年 0.83% 以上伸びる必要がある。研究者の数の曲線は国と国の比較 (国・年の断面) から取ったもので、時とともに研究者の割合が上がる分 (米国の研究者は 1930〜2000 年代に 22 倍。断面の曲線と所得の伸びでは説明しきれない) が入っていない。研究開発の政策 (3。研究開発費 ÷ GDP が所得で上がる目標 N7) で直す見込み (B-004)。
- **R61 が下がった理由**: 研究者は分野に付加価値の比で分かれるので、研究者が減ると小さい高付加価値の工業の技術が伸びず、R61 の 2 番目の分位 (4,850〜10,803 ドル) の中央値が 0.189 → 0.016 になった。
- **R33 が合格した**: 伸びが遅く落ち着いたので、景気のずれ (1 年の伸び − 5 年の伸び) が負に偏りにくくなった見込み (B-118 の見立てと同じ向き)。

## 2. 光速で遅れる技術の伝播 (B-121)

### 2.1 現実の目標 (目標の版 22)

作る前に固定した (`docs/targets.md` の版 22)。生データは Penn World Table 11.0 (`data/raw/tfp`) と WDI の LAYS (`data/raw/hcap/hci_lays.csv.gz`)。ゲームの A は働き手 1 人あたりの産出に掛かるので、TFP を労働増大的な形 a = ln ctfp ÷ (その国と米国の労働分配率の平均) に直して比べる。

| 目標 | 統計量 | 実データ |
|---|---|---|
| R68 技術水準の前線比と所得 | 所得の 5 分位ごとの前線比 exp(a) の 25%〜75% 点 (118 か国・3,479 国・年。1990〜2019 年) | 中央値 0.175・0.295・0.446・0.627・0.894 |
| R69 技術の規模効果のなさ | 2015〜2019 年の a を ln 人口と ln 人的資本に当てた ln 人口の係数 (120 か国) | −0.032 (幅 −0.089〜0.028) |
| R70 技術の収束 | 1995〜2019 年の a の年率の伸びを 1995 年の a に当てた傾き (120 か国) | −0.0175 (幅 −0.026〜−0.009) |
| R71 技術の伸びと LAYS | 所得をそろえた 2000〜2019 年の a の伸び [%/年] の LAYS の係数 (116 か国) | 1.61 (幅 0.80〜2.41) |
| R72 所得の差のうち学歴の分 | cov(ln hc, ln y) ÷ var(ln y) (120 か国) | 0.21 (幅 0.10〜0.31) |
| R11 研究の生産性の低下 | 前線の国 (最後の 10 年の技術の水準がいちばん高い国) で測るように変えた | 幅は前のまま |

### 2.2 作り (`DIFFUSE`。`economy/market-consts.js`・`economy/market-economy.js` の `diffuseStep`)

| | 中身 | 値の出どころ |
|---|---|---|
| 前線 | 分野ごとに、ほかの国の技術の、首都どうしの光の年数だけ前の値 (`techSeen`) のいちばん高いもの F。知らせは光速でしか届かない | 首都どうしの距離 (`sysDist`)。1 年 = 1 光年 |
| 追いつく | dA/dt += κ × max(0, θ × F − A)。前線より上の国には働かない ([·]⁺) ので、前線の国の伸び (本星の始めの伸び g0 = 年 1.67% の決め方) と R11 は変わらない | κ = 0.0247/年。PWT 11.0 の 1995〜2019 年の技術の伸びを、初めの水準と LAYS に当てた条件つきの収束の速さ (116 か国。5%〜95% 点 0.019〜0.032。2000〜2019 年では 0.033) |
| 吸収の上限 θ | min(1, exp(0.1824 × (LAYS − 前線の国の LAYS)))。LAYS はその年に学校を出る世代の学力で調整した就学年数 (就学年数 × 学力 ÷ 625。人口の重みの平均。`laysOf`) | 0.1824 は、技術の前線比の ln を WDI の LAYS に当てた傾き (116 か国、相関 0.64)。条件つきの収束の式の LAYS の係数 ÷ κ = 0.17 とも合う |
| 前線の国との差にした理由 | ゲームの国の LAYS (5〜8 年) は、データの豊かな国 (11〜13 年) より低い。データの切片 (−2.42) のままでは前線の国でも θ が 0.4 になり、どの国も追いつけない | |
| 記録 | 国の技術に `h` = [[年, A_farm, A_mine, A_ind, A_hi], …] を 2 年ごとに 120 年分持つ (6 桁に丸める)。いちばん遠い首都どうしは 100 光年ほど | 1 年ごと・丸めなしではセーブが 2.3% 増えた。いまは 0.4% |

- 独立した国は前のとおり元の国の技術を持っていく (`politics/loyalty-regime.js`)。記録はその年から始まる。
- 試してやめたもの: データの切片のままの θ = min(1, exp(−2.422 + 0.1824 × LAYS)) (どの国も θ × F が自分の A より低く、伝播が働かなかった)。
