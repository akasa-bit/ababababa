## 1. terms.json の形

```json
{"id": "regime-type.T01", "group": "regime-type", "ja": "冊封朝貢国", "en": "Tributary state (investiture)", "zh-Hans": "册封朝贡国",
 "src": "VASSAL_DATA.types[\"T01\"].label", "note": "明・清の冊封。中国語は史料の用語のまま"}
```

| 欄 | 意味 |
|---|---|
| `id` | 用語の名前 (`<group>.<キー>`)。T1 の文字列の表で、この用語を指すときに使う。変えない |
| `group` | まとまり (下の表) |
| `ja` | ゲームの日本語。**ゲームの画面の言葉と 1 字も違わない** (`src` のある用語は `check.mjs` が確かめる) |
| `en`・`zh-Hans` | 訳。いまは**すべて下書き** (`"status": "draft"`)。英語は Claude の案、中国語も Claude の案で、訳者 (QD-17) が直す前提。空の所は訳者が決める (いまは `star.keid` の中国語だけ) |
| `src` | ゲームの中で、この言葉を持つ所 (JS の式)。文字列か、文字列の配列 (配列なら `ja` が入っていればよい) を返す。`null` は、表になく文の中に出てくる用語 (光速・政治力・戦争疲弊 など) |
| `note` | 訳すときの注意 |

### まとまり

| group | 中身 | 数 |
|---|---|---|
| `title` | 題・副題・版の名前 | 4 |
| `core` | 光と時間・画面の大きな名前 (星間マップ・指令・時代の課題・観戦 など) | 23 |
| `rule`・`bundle`・`bundle-code`・`family`・`regime-type`・`elite`・`governor`・`mandate`・`policy`・`unrest`・`end` | 統治と従属 (従属国の 19 の型 + 植民地・主権の 8 つの束・法と実態) | 90 |
| `war`・`fleet-kind`・`challenge`・`handicap` | 戦争と講和・艦隊・挑戦・難しさ | 26 |
| `econ`・`res`・`facility`・`focus`・`budget`・`tax`・`ledger`・`stage`・`slave`・`trait`・`tech`・`event`・`tier`・`tab` | 経済・エネルギー・物理・研究・帳簿・出来事 | 105 |

数の合計と、訳のない用語の数は `check.mjs` が書く。

### rules (名前の作り方)

作った星系・種族・国の名前は、試合ごとに乱数で作るので、用語として並べられない。`rules` に、訳での作り方を書いた:

- **星系の名前**: カタカナは英字の音節 (`SYL_A`・`SYL_B`・`SYL_C`。`src/core/galaxy.js`) を同じ順にカタカナにしたもの。英語・中国語では英字の形 (セリス = ce + lis → Celis)。T1 では、名前を作るときに英字の形も残す (カタカナからは戻せない場合がある)。
- **種族・国の名前**: 種族 = `KANA_A` + `KANA_B` + 「人」(`src/core/world.js`)。国 = 語幹 + 接尾辞 (`suffix.*` の型)。
- **実在の星**: 固有名は `star.*` (IAU の名前)、なければ星表の番号 (GJ 65) のまま。惑星は「星の名前 + b・c…」。
- 単位と記号 (ly・cr・J・QJ・AU・スペクトル型) は訳さない。
- 統治の型と史料の用語は歴史学の用語にそろえる (`docs/vassal-typology.md` の出典)。
- 文の調子は「古い報告書」(`docs/handoff.md` の 15)。

## 2. 翻訳の本番 (T1) での使い方

回 T1 では、表の値を `id` に置き換えず、日本語の文そのものを鍵にした (`docs/i18n.md` の 1)。用語集の訳は、英語の表 (`src/outward/lang-en.js`) の最初の訳に使った (`src` のある用語 247 は、表の同じ鍵にそのまま入れた。国の接尾辞は表の最後の区切りの `{stem}…` の型)。下の 1 は、そのときの計画。

1. **文字列の表を作るとき (B-073)**: 表の値にこの `id` を使う所 (型の名前・資源の名前 など、`src` のある用語) は、`src` の表の値を、文字列の表の `id` に置き換える。T1 は全部のファイルに触る回 (`docs/parallel.md` の 2) なので、`src` の表を持つレーンの所も、このときに一緒に直す。
2. **訳すとき (B-075・B-076)**: 文の中に `ja` の言葉が出てきたら、`en`・`zh-Hans` の訳を使う。訳者に渡すときは、この JSON か、ここから作った表を一緒に渡す。訳者が直したら、ここを直して `"status"` を用語ごと (`"status": "fixed"`) に進める。
3. **用語を足すとき**: ゲームに新しい型・資源・施設が足されたら `check.mjs` が「拾い残し」として出す。`terms.json` に 1 行足す (`id` は `<group>.<キー>`。表のキーと同じにする)。
4. **ストアの文 (B-077)**: `store/page-ja.md` を訳すときも、この訳にそろえる (タグは Steam の英語の名前のまま)。

## 3. 確かめ方

```sh
node docs/glossary/check.mjs
```

- 食い違い: `src` の式の値が `ja` と違う (ゲームの言葉が変わった)。用語集の `ja` を直し、訳も見直す。
- 拾い残し: `check.mjs` の `COVER` の表 (型・束・資源・施設・出来事・天体・国の接尾辞 など 34 の表) の値で、用語集にないもの。
- 合格なら「用語集 合格」(終了コード 0)。CI には入れていない (ゲームの言葉を変える PR が、用語集のために落ちないように)。T1 の前と、外向きの回で回す。
- 2026-10-22 (main の `de69fc8`): 合格。用語 315・`src` つき 227・英語のない用語 0・中国語のない用語 1。
- 2026-10-29 (回 T1 の前): 不合格だった (回 KE2・KE6 で「工業品」が「低付加価値物品」に変わり、高付加価値物品・教育・年金・医療が足された)。用語集を直して合格。用語 319・`src` つき 231。
