### 数え方

- 対象: 1 波目の PR 34 本 (#179〜#212。2026-10-22 06:44 〜 10-23 10:07 UTC。34 本ともマージ)。数え方は `docs/conflicts.md` の 1 と同じ。PR の最後の形 (`refs/pull/<番号>/head`) から、その PR だけのコミット (main と、同じブランチの前の PR に入っていないもの) を取り出した。
- (a) 取り込み直し: 親が 2 つのコミット。(b) 衝突: その取り込みを `git merge-tree` で同じ 2 つの親からやり直し、手で直す必要のあったファイル。相手の側は、共通の祖先からそのファイルを変えた main の PR。(c) core を触った回数: main のスカッシュのコミットで `src/core/` の変わったファイル。
- 限り: 作り直し (rebase) や強制プッシュをしたブランチの取り込み直しは、PR の最後の形からは見えない。返事待ちの時間は、コミットと PR の時刻から出した上限で、作る時間とユーザーがいない時間を含む。
