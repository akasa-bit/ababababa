## 前のレーン C から写したもの

### 気をつけること

- **財政の値は数** (セッション 20): `fiscal.tax` は税率そのもの (0.155 など)。消費税 `fiscal.ctax`・関税 `fiscal.tariff` (既定 0)。新しい輸入の経路を足すときは、ほかの国からなら `tariffFor(買い手, 売り手)` で関税を買い手の政府に入れる。前の段階の名前 (`heavy` など) は `taxRateOf` で税率に直す。幅と刻みは `TAX_RANGE` などの定数 (`docs/policy-ranges.md`) で、`setFiscal` が `onStep` で確かめる。画面はスライダー (`data-act="fiscal"`、`input` で値の表示・`change` で命令)。人間でない国の財政は `aiFiscal(root)` (セーブの `aif`)。
- **main の数を測るとき**は `HTML=<main の src> node tools/fiscal-panel.js …` (`market-panel.js` も)。PR の前後で同じシードの筋が同じかは `tools/ci-report.js` の「試合の筋が main と同じだった銀河」で分かる (財政の表し方が変わると要約は違うが、遊びの数が ±0% なら筋は同じ)。
- **国債の仕組み** (`docs/debt.md` の 5): AI の政府の買い物は `funds(id)` (手元の資金 + 借りられる額) で比べる。新しく AI の買い物を足すときは `gv.credits` でなく `funds` を使う (`lack`・`procure` の資材の代金も)。人間が動かす首都は、財政の「赤字の上限」が「なし」なら前と同じ。
- **レーン P からの知らせ (2026-10-21、セッション P6)**: ゲーム版に物理 (遮蔽と加速の時間) が入った (`docs/physics.md` の 11)。30 銀河 × 150 年で、R21 政府債務 ÷ GDP が 0.179 → 0.208 (不合格 → 合格)、R28 財政の反応が 0.078 → 0.063 (幅の上の端 0.062 のすぐ外のまま)。ほかの R19〜R27 は判定が変わらない。**交易路の 1 年の輸送量が半分ほどに減った** (24 銀河の平均 1,067 → 532、中央値 592 → 80、15 / 24 の銀河で減少。交易路の数は −3%)。人の乗る船の遮蔽と加速の分のエネルギーで蓄えが減り、`routeRoom` が絞られた見込み (確かめていない)。R01 (交易と距離) を測り直すときは物理ありの版で。
- **ほかのレーンへの知らせ (A)**: 構造転換で入植地が +162%、始まった戦争が +39% (8 銀河)。R29 (国家間戦争の多さ) の測定とぶつかるかもしれない。
- **就業の部門** `SECTORS` に自給 (home) が増えた。就業の割合を触る所は 5 つの部門を前提にする。`MARKET_SECTORS` が市場の 4 部門。
- **お金の帳簿**は家計 (`{ hh }`・`gv.hh`) と会社 (`{ fm }`・`gv.fm`) に分かれた。`{ pv }` は家計の別名。民間への支払いを足すときは、賃金・給付なら家計、物の代金なら会社へ。
- **生産は需要で決まる** (`util`。economy の 1)。新しい需要の種類 (消費・建設・輸出・補給のほか) を足すときは、`mv` の種類を `ABSORB` に入れるか、足りなかった分を `unmet` に記録する (記録しないと、その需要のために作られない)。
- **所得の 2 つの測り方**: `incomeUSD` (R10 の測り方。市場の値段) と `potentialUSD` (曲線に入れる生産力。基準の値段)。曲線に `incomeUSD` を入れると経済が振れる (`docs/structure.md` の 6)。
- **研究の α は試合の始めに決めてセーブに入る** (`alpha`)。古いセーブ (alpha なし) は、読み込んだあとの最初の刻みで決め直す。
- **小さな政府の軍の維持費**: 駐留する星系の政府が払うので、税収の少ない政府は維持費のために国債を出し続ける。国の政府が払う形にするかは、軍のレーンと相談。
- **regime と fiscal の試験**は、観戦のあとに家臣ができるまで進める形にした。経済が遅くなると、ほかの画面の試験も「家臣・従属星系がない」で落ちることがある。そのときは同じ直し方にする。
- 交易の注文の先払いが大きい件 (前からの気づき) は、まだ見ていない。
