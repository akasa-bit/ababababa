## 気をつけること

- 画面の決まりは `docs/parallel.md` の 7 と `docs/handoff.md` の 15。
- 時代の課題・挑戦・点数は `src/screen/eras-score.js` (`Game` のメソッドの一部)。手引きにするときは、ここを直す。
- 画面に新しい値を出すときは、光の遅れの記録 (`known`。`src/core/knowledge.js`) から作る。足すときは core を触る小さな変更にして PR に書く。
- 新しいゲームの 2300 年 1 月 1 日は、スウォームの蓄えが 0 J で恒星間の入植船を送れない。止めて始めるときは `pauseForFirstMove` (`screen/hotseat.js`) が 1 日ずつ進めてから止めている。蓄えの始めの値を持つのは船と戦争 (`ship/energy.js`) なので、そちらで初めから蓄えを持たせたら、この進める所は要らなくなる。
- ホームの試験 (`tools/tests/` の home・hot・net・cloud・edit・lib・pick) は `?seed=` で開き、「詳しい設定」の中の銀河の番号・国の数と `data-home="new"` (2 回押し) を使う。ホームを変えるときは、この形を残すか、道具と検証と突き合わせる。
- 知らせの帯の決まりは `src/screen/events-ui.js` の `railNews` (自国に関わる・状態の種類は除く・束ねる・予算)。帯や「次の知らせまで進む」に新しい種類の知らせを足すときは、ここを通す。予算の値 `NEWS_BUDGET` は試遊のあとで見直す。
- 節目の見つけ方 (`milestonesNew`) は知らせの文を見ている (入植の「設立」・独立の「への従属をやめ」・講和の「白紙講和を結んだ / 講和条約が結ばれた」・時代の「新しい時代が始まった」)。政治・船と戦争・経済がこの文を変えたら、輪と音が出なくなる。
- GA3 で: FU の知らせにある星間マップの自国の艦隊の矢印 (`galaxy-view.js` の `f.to`) を `game.seenLeg(f).to` にする (進路変更が光より速く見えている)。
