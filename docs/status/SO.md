### 回 T1 で分かったこと・気をつけること

- 試合の状態 (出来事・記録・名前) には日本語のまま入れ、出すときに訳す形にした (`docs/i18n.md` の 1)。状態を英語にすると、セーブ・状態の要約・ネット対戦が言語で変わり、`groups.js` の「税」「福祉の予算」のように文で決めている所が英語で壊れるため。
- 状態から来た文は、`JA` で作ったときの鍵と値で訳すのがいちばん確か。つないだ文 (`why += JA`…`` や、日本語のないテンプレートで名前と文を並べた所) とセーブを読み直したあとは、区切りと表の言葉で訳すので、まれに語順の不自然な英語になる。`node tools/i18n-scan.js` で見つけたら、つないでいる所を 1 つの `JA` の文にするのが根本の直し方。
- 英語の画面は、表の値を TR の外で差し込んだ所を安全網 (`MutationObserver` と `canvas` の `fillText`) で訳している。書き換えの直後は 1,120 種類残っていた日本語が、安全網と `TX` の手直しで 0 になった (`i18n-scan.js 200`)。
- 英語は長いので、上のタブと日付の行が詰まる (日付が資金に重なったので `#date` を縮めないようにした。月は `Jan 2450` の形)。狭い画面の札の折れは、画面と最初の体験の次の回で見る。
- 表の値のうち、文の中でも札でも使う言葉は小文字の形で持ち、札 (要素の文字の頭) と訳の頭に来た値だけを大文字にしている (`i18nCap`)。
- 訳は 8 つに分けて Claude が下書きし (用語集にそろえる手引きつき)、`{0}` と HTML の札と日本語の残りを道具で確かめた。友好度 = friendship・威圧 = intimidation・資金援助 = subsidy・統治体制 = form of rule にそろえた。

### 回 SO3 で分かったこと・気をつけること

- 観戦のまま進めるだけでは、地球の国が勝つ講和会議は起きない (観戦の AI は守り寄り。銀河 60 個 × 200 年で 0 回)。人の操作で遊ぶ台本 (`play.mjs`) にした。ゲームが変わると筋 (宣戦の年・相手・講和の年) も変わるが、台本は筋を見て場面と字幕を決めるので、そのまま動く。筋が講和会議まで届かなかったら (160 年)、止まって遊んだ筋を出す。
- 地球が知る戦勝点は光の遅れのぶん古いので、相手からの申し入れを地球で受けると、地球に届いている戦果 (0 のことが多い) で白紙講和になる。こちらの申し入れを相手の首都に届かせると、首都に届いている戦果で講和会議になる (`makePeace` の `from`)。遊び方を決めるときに気をつける。
- 予告編の 1 コマは 0.7 秒ほどかかる (1920×1080 の画面の写し)。答え合わせの早回しのように実時間で動くものは、台本が 1 コマずつ動かす。
- 地図の視点は、右の欄の開け閉めのあと地図の大きさが変わって寄せ直されるので、少し待ってから決める (`cam`)。
