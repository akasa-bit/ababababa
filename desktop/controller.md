# コントローラー (Steam Deck) で足りない操作の一覧と案

調べた日: 2026-10-20 (セッション S1)。ゲームの中 (`src/index.html`) は直さず、一覧と案までにする (`docs/parallel.md` のレーン S の決まり)。直すのは、ゲームの中に触れる回 (下の「案」の B)。

Steam Deck には、タッチの画面 (1280×800)・2 つのトラックパッド・スティック・ボタンがある。Steam Input は、ゲームがコントローラーに対応していなくても、ボタンをキーボードとマウスに割り当てられる。Valve は、コントローラーに対応しないゲームには、キーボードとマウスに割り当てた設定を公式の既定として出すことと、文字の入力には画面のキーボードを出すことをすすめている (Verified の条件。https://partner.steamgames.com/doc/steamdeck/recommendations 、2026-10-20 に確かめた)。

## 1. いまの操作と、Deck での状態

| # | 操作 | いまの入力 | Deck のタッチ | Deck のボタン (Steam Input でキーとマウスに割り当て) | ゲームパッド (Gamepad API) |
|---|---|---|---|---|---|
| 1 | 地図を動かす | ドラッグ | ○ | ○ (右トラックパッドをマウスに) | × |
| 2 | 拡大・縮小 | ホイール・ピンチ | ○ (ピンチ) | ○ (トラックパッドのスクロールをホイールに) | × |
| 3 | 地図を回す・傾ける | Z/X・R/F キー、「回す」ボタン、中ボタン・Alt+ドラッグ、2 本指のひねり | ○ | ○ (Z/X/R/F をボタンに) | × |
| 4 | 星系を選ぶ・開く | クリック・ダブルクリック | ○ | ○ | × |
| 5 | 艦隊を範囲で選ぶ | **Shift+ドラッグ** | **×** (タッチには範囲選択がない) | △ (Shift を押したままトラックパッドでドラッグ。2 つを同時に押す) | × |
| 6 | 艦隊を動かす | 右クリック・右ドラッグ (経由地)・タッチは選んだあとのタップと長押し | ○ | ○ (右クリックを L2 などに) | × |
| 7 | 速さ・止める | Space・1〜7 キー・ボタン | ○ | ○ | × |
| 8 | 画面の切り替え | G/S/E キー・Esc・上のタブ | ○ | ○ | × |
| 9 | 指名の取り消し | Delete・Backspace | ○ (ボタンがある所は) | ○ | × |
| 10 | ボタン・チェックボックス・一覧 (`<select>` が 22 か所) を順に選ぶ | マウス・タッチ | ○ | △ (マウスで指すだけ。十字キーで次のボタンへ動く仕組みがない) | × |
| 11 | 説明を見る (`title` の吹き出しが 29 か所、地図の上のホバー) | マウスを重ねる | **×** (タッチにはホバーがない) | △ (トラックパッドのマウスなら出る) | × |
| 12 | 文字を入れる (銀河の番号・部屋のコード・Firebase の設定) | キーボード | △ (Game Mode では Steam のキーボードを手で出す) | △ | × |
| 13 | セーブの書き出し・読み込み (ファイル) | `<a download>`・`<input type=file>` | △ (Game Mode でファイルの窓は使いにくい) | △ | × |

○ = できる、△ = できるが不便、× = できない。

## 2. 案

| 案 | 中身 | 触る所 | おすすめ |
|---|---|---|---|
| A. Steam Input の既定の設定 | 右トラックパッド = マウス、R2 = 左クリック、L2 = 右クリック、右トラックパッドのクリック = 左クリック、左スティック = 地図を動かすキー (ゲームにキーがないので、いまはマウスのドラッグを割り当てられない → B の 1 が要る)、L1/R1 = Z/X (回す)、十字キーの上下 = R/F (傾ける)、A = Space (止める・動かす)、B = Esc、Y = G (銀河)、X = S (星系)、メニュー = E (帝国)、左スティックの押し込み = Shift (範囲選択) | Steamworks の設定だけ (ゲームは変えない) | **先にやる** (出す前の必須。S2 の手順に入れる) |
| B. ゲームの中でゲームパッドに対応 | 1) スティックで地図を動かす・回す、トリガーで拡大縮小。2) 十字キーでボタンを順に選ぶ (今どれを選んでいるかの枠を出す)、A で押す・B で戻る。3) 範囲選択のかわりに「この星系の艦隊を全部選ぶ」ボタンと、タッチの範囲選択 (2 本指の長押しなど)。4) ホバーの説明を、選んだときに出す (タッチとコントローラーで同じ) | `src/index.html` (Gamepad API と、`GalaxyView` の入力) | 試遊の前に。ゲームの中に触るので、レーン E かセッション 18 の前後に 1 回 |
| C. 文字の入力に画面のキーボード | 入力欄を選んだとき、Steamworks の `ShowFloatingGamepadTextInput` を呼ぶ (包装から。ゲームには入力欄に入ったことを知らせる小さなつなぎが要る) | 包装 + ゲームの中の 1 か所 | Steamworks をつなぐとき (Verified の条件) |
| D. セーブをファイルでなくスロットと Steam Cloud に | 書き出しと読み込みのファイルの窓を使わずに済むように、スロットのセーブを Steam Cloud で同期する | 包装 (Steam Cloud は Steamworks の設定で、保存の場所を指すだけでも動く) | Steamworks をつなぐとき |

## 3. まだ確かめていないこと

- `<select>` の一覧は、Game Mode (gamescope) の上で別の窓として開く。Electron と Tauri のどちらでも、Deck の上で正しく出るかは実機で確かめる。
- Deck の上で Gamepad API がコントローラーを見つけるか。Chromium (Electron) では、Steam Input の配置が「ゲームパッドとマウスのトラックパッド」のときだけ見つかるという報告がある (https://www.gamingonlinux.com/2022/03/chrome-on-steam-deck-now-supports-the-deck-controller-with-geforce-now-working/)。
- 一番小さい文字の大きさ (Valve は 1280×800 で読めることを求める)。いまの地の文は 14px。地図の上の小さな文字を実機で見る。
